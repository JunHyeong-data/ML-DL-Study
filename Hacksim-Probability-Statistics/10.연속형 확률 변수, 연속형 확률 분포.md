# Continuous Random Variable & Probability Density Function

## 1. 연속형 확률변수 (Continuous Random Variable)
<img width="1537" height="1131" alt="image" src="https://github.com/user-attachments/assets/8aaa93a9-be57-43df-bc1b-5a697a2c0463" />

연속형 확률변수는 셀 수 없는 실수 값들을 가질 수 있는 확률변수를 의미한다.  
예를 들어 다음과 같은 값들이 있다.

* 사람의 키
* 몸무게
* 소득
* 주식 지수
* 시간

이러한 값들은 정수처럼 하나씩 셀 수 있는 값이 아니라 실수 범위 전체에서 값이 존재한다.

## 2. 구간 표현 방법
연속형 변수는 보통 구간(interval) 으로 표현한다.

* **(1) 열린 구간**: $(0,1) \implies 0 < x < 1$ (0과 1을 포함하지 않음)
* **(2) 닫힌 구간**: $[0,1] \implies 0 \le x \le 1$ (0과 1을 포함)
* **(3) 혼합 구간**: $[0,1) \implies 0 \le x < 1$
* **(4) 전체 실수 범위**: $(-\infty, \infty)$ (모든 실수 값 포함)

## 3. 확률밀도함수 (PDF: Probability Density Function)
연속형 확률변수에서는 확률질량함수(PMF) 대신 **확률밀도함수(PDF)** 를 사용한다.
<img width="1530" height="1135" alt="image" src="https://github.com/user-attachments/assets/95985643-d0ce-455d-80a0-d02a39a60210" />

* **표기**: $f(x)$
* **특징**:
    * 입력: 실수 $x$
    * 출력: 확률밀도 값
    * 하지만 $f(x)$는 확률 자체가 아니라 밀도이다.

## 4. 연속형 확률에서 확률 계산 방법
<img width="1504" height="1005" alt="image" src="https://github.com/user-attachments/assets/3a517acf-b2bd-4464-893c-bd8d5484be9b" />

이산형에서는
$$P(a \le X \le b) = \sum p(x)$$
처럼 합(sum) 으로 계산한다.  

하지만 연속형에서는
$$P(a \le X \le b) = \int_{a}^{b} f(x) \, dx$$
즉 적분(integral) 으로 계산한다.

## 5. PDF의 성질
<img width="1524" height="1037" alt="image" src="https://github.com/user-attachments/assets/88e9ca4b-3a1e-406c-8b81-bc6c1fd6b430" />
<img width="1516" height="923" alt="image" src="https://github.com/user-attachments/assets/7ade4064-f588-494a-92b5-cd7fe93bb8c4" />

**(1) 항상 0 이상**
$$f(x) \ge 0$$
**(2) 전체 확률은 1**
$$\int_{-\infty}^{\infty} f(x) \, dx = 1$$
**(3) 특정 값의 확률은 0**
연속형에서는
$$P(X = a) = 0$$
* **이유**: 한 점의 면적은 0이기 때문
* **따라서**: $P(a \le X \le b)$, $P(a < X \le b)$, $P(a \le X < b)$, $P(a < X < b)$ 모두 동일하다.

## 6. 특정 값 근처 확률
특정 값의 확률은 0이므로 작은 구간을 만들어 계산한다.
$$P(a - \epsilon < X < a + \epsilon)$$
($\epsilon$은 매우 작은 값이다.)

## 7. 예제 1 (PDF 상수 찾기)
<img width="1513" height="1027" alt="image" src="https://github.com/user-attachments/assets/2ea6f610-477a-47ff-9989-5dfee70e31d4" />

* **주어진 PDF**:
    * $f(x) = \lambda e^{-x/100} \quad (x > 0)$
    * $f(x) = 0 \quad (x \le 0)$
* **PDF 조건**: $\int_{0}^{\infty} f(x) \, dx = 1$
* **계산**: $\int_{0}^{\infty} \lambda e^{-x/100} \, dx = 1$
* **결과**: $100\lambda = 1 \implies \lambda = 1/100$

## 8. 예제 2 (확률 계산)
<img width="1531" height="1055" alt="image" src="https://github.com/user-attachments/assets/e8499431-0323-4ff7-ae34-4af31b678ea1" />

* **문제**: 컴퓨터가 50~150시간 작동할 확률
* **PDF**: $f(x) = \frac{1}{100}e^{-x/100}$
* **확률**: $P(50 \le X \le 150)$
* **계산**: $\int_{50}^{150} \frac{1}{100}e^{-x/100} \, dx$
* **결과**: $\approx 0.384$

## 9. 누적분포함수 (CDF: Cumulative Distribution Function)
<img width="1497" height="853" alt="image" src="https://github.com/user-attachments/assets/51a2b691-4489-41ec-8708-c66f4e872447" />

* **표기**: $F(x)$
* **정의**: $F(x) = P(X \le x)$
* **의미**: $x$ 이하의 확률을 누적한 값
* **CDF 계산**: $F(x) = \int_{-\infty}^{x} f(t) \, dt$

## 10. PDF와 CDF 관계
* **적분 관계**: $F(x) = \int f(x) \, dx$
* **미분 관계**: $f(x) = F'(x)$
* **즉**: CDF 미분 $\to$ PDF / PDF 적분 $\to$ CDF

## 11. CDF 성질
<img width="1542" height="1132" alt="image" src="https://github.com/user-attachments/assets/d4803873-7e89-4512-ab69-33888cd915b0" />
<img width="1537" height="1120" alt="image" src="https://github.com/user-attachments/assets/418f6a1c-1829-43a7-8028-47e33a207a50" />

1. $0 \le F(x) \le 1$
2. **단조 증가 함수**: $a < b$ 이면 $F(a) \le F(b)$
3. **확률 계산**: $P(a \le X \le b) = F(b) - F(a)$

## 12. 기대값 (Expected Value)
<img width="1522" height="1035" alt="image" src="https://github.com/user-attachments/assets/78826746-1a10-4562-ba7d-0fcd0a323640" />

연속형 기대값:
$$E[X] = \int_{-\infty}^{\infty} x f(x) \, dx$$
* **예제 (PDF $f(x) = 2x, 0 \le x \le 1$)**:
    * $E[X] = \int_{0}^{1} x(2x) \, dx = \int_{0}^{1} 2x^2 \, dx = 2/3$

## 13. 함수의 기대값
<img width="1515" height="1130" alt="image" src="https://github.com/user-attachments/assets/bd514f02-1832-4254-a6d8-17b5d4302715" />
<img width="1530" height="1120" alt="image" src="https://github.com/user-attachments/assets/ef448e27-bdf7-44e3-82ee-3f1e6edb2654" />

함수 $g(x)$의 기대값:
$$E[g(X)] = \int_{-\infty}^{\infty} g(x) f(x) \, dx$$
* **예**: $E[X^2] = \int x^2 f(x) \, dx$

## 14. 분산 (Variance)
<img width="1495" height="923" alt="image" src="https://github.com/user-attachments/assets/077df264-85f8-4430-98f1-84d7d0c29465" />
<img width="1536" height="1000" alt="image" src="https://github.com/user-attachments/assets/43be735e-2c07-4ef5-8834-fd3e52a83d60" />

* **정의**: $Var(X) = E[(X - \mu)^2] \quad (\mu = E[X])$
* **계산 공식**: $Var(X) = E[X^2] - (E[X])^2$

## 16. 전체 개념 흐름
* **확률이론의 구조**: 표본공간 $\to$ 확률변수 $\to$ 확률함수 $\to$ 확률분포
* **확률변수 종류**: 이산형 $\to$ PMF / 연속형 $\to$ PDF

---
💡 **정리**
연속형 확률변수에서는
* 합(sum)이 아니라 **적분(integral)**
* PMF가 아니라 **PDF**
* 확률은 그래프 아래 **면적**
* 특정 값의 확률은 **0**
