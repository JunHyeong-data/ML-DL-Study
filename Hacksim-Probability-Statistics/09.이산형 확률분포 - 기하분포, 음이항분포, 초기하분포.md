## 1. 베르누이 시행 (Bernoulli Trial)

베르누이 시행이란 결과가 두 가지 중 하나로 나오는 실험이다.

**예시**
- 동전 던지기 → 앞면 / 뒷면
- 시험 합격 여부 → 합격 / 불합격

이를 보통 다음과 같이 표현한다.
- 성공(Success) → $1$
- 실패(Failure) → $0$

또한 성공 확률을 다음과 같이 정의한다.
$$P(\text{Success}) = p$$
$$P(\text{Failure}) = 1-p$$

## 2. 기하분포 (Geometric Distribution)

### 개념
기하분포는 다음과 같은 상황에서 사용된다.
> **첫 번째 성공이 나올 때까지 필요한 시행 횟수**

즉, 확률변수 $X$를 다음과 같이 정의한다.
$$X = \text{첫 번째 성공이 나올 때까지 필요한 시행 횟수}$$

**예시**
5번째 시행에서 처음 성공하는 경우

```

1 2 3 4 5
F F F F S

```

**확률 계산**
$$P(X=5) = (1-p)^4 p$$

**일반적인 확률질량함수 (PMF)**
$$P(X = m) = (1-p)^{m-1}p$$

**의미**
- 앞의 $(m-1)$번 → 실패
- $(m)$번째 → 성공



### 기대값과 분산
기하분포의 평균과 분산은 다음과 같다.

**기대값**
$$E(X) = \frac{1}{p}$$

**분산**
$$Var(X) = \frac{1-p}{p^2}$$

## 3. 기하분포 예제

항아리에 
- 흰 공 : $m$
- 검은 공 : $n$
이 들어있고 복원추출로 공을 뽑는다.

**확률변수**
$$X = \text{첫 번째 검은 공이 나올 때까지 필요한 횟수}$$

**확률**
$$P(X=m) = \left(\frac{m}{m+n}\right)^{m-1} \left(\frac{n}{m+n}\right)$$

## 4. 음이항분포 (Negative Binomial Distribution)

<img width="1518" height="1120" alt="image" src="https://github.com/user-attachments/assets/8ce50f1c-311b-4483-a187-22bf0ce440a7" />

### 개념
기하분포는 **첫 번째 성공까지 시행 횟수**였다. 음이항분포는 이를 일반화한 것이다.
> **$k$번째 성공이 나올 때까지 필요한 시행 횟수**

**확률변수**
$$X = k\text{번째 성공이 나올 때까지 필요한 시행 횟수}$$

**확률질량함수**
$$P(X=x) = \binom{x-1}{k-1} p^k (1-p)^{x-k}$$



**의미**
- $(x-1)$번 시행 동안 $(k-1)$번 성공
- 마지막 $(x)$번째 시행에서 성공

### 기대값과 분산
**기대값**
$$E(X) = \frac{k}{p}$$

**분산**
$$Var(X) = \frac{k(1-p)}{p^2}$$

## 5. 음이항분포 예제
<img width="1507" height="1019" alt="image" src="https://github.com/user-attachments/assets/a34780a7-fe76-42b3-9fb6-99d6bd79ef36" />
<img width="1527" height="1123" alt="image" src="https://github.com/user-attachments/assets/ffc0de5b-68a7-4f63-ba19-bb7d229ae257" />

주사위를 던져 **6이 3번 나올 때까지 던진다.**

**확률변수**
$$X = 6\text{이 3번 나올 때까지 필요한 던진 횟수}$$

**문제**
5번째 시행에서 3번째 6이 나올 확률

**조건**
- 성공확률 ($p = 1/6$)

**계산**
$$P(X=5) = \binom{4}{2} (1/6)^3 (5/6)^2$$

## 6. 하이퍼지오메트릭 분포 (Hypergeometric Distribution)

### 개념
하이퍼지오메트릭 분포는 다음 상황에서 사용된다.
> **비복원 추출 (without replacement)**

**예시**
- 전체 공 ($N$)
- 흰 공 ($M$)
- 샘플링 ($n$)

**확률변수**
$$X = \text{샘플에서 흰 공의 개수}$$

**확률질량함수**
$$P(X=i) = \frac{\binom{M}{i} \binom{N-M}{n-i}}{\binom{N}{n}}$$



**의미**
- 분모 → 전체 경우
- 분자 → 원하는 경우

제품 30개 중
- 불량품 : 5개
- 정상품 : 25개
샘플 4개를 비복원 추출한다.

**확률변수**
$$X = \text{샘플에서 불량품 개수}$$

**문제**
샘플 4개 중 불량품이 2개일 확률

**계산**
$$P(X=2) = \frac{\binom{5}{2} \binom{25}{2}}{\binom{30}{4}}$$

## 8. 확률분포의 전체 구조

확률 이론의 구조는 다음 순서로 연결된다.

$$\text{실험} \rightarrow \text{표본공간} \rightarrow \text{확률변수} \rightarrow \text{확률함수} \rightarrow \text{확률분포}$$

### 1️⃣ 실험 (Experiment)
데이터를 생성하는 모든 과정
- 예: 동전 던지기, 주사위 던지기, 제품 검사

### 2️⃣ 표본공간 (Sample Space)
실험에서 나올 수 있는 모든 결과의 집합
- 예: 동전 던지기 → $S = \{\text{앞면, 뒷면}\}$

### 3️⃣ 확률변수 (Random Variable)
표본공간의 결과를 숫자로 대응시키는 함수
- 예: 앞면 → $1$, 뒷면 → $0$

### 4️⃣ 확률함수
확률변수가 특정 값을 가질 확률
- 예: $P(X=x)$

### 5️⃣ 확률분포
확률값들의 전체 패턴
- 예: 이항분포, 포아송분포, 기하분포, 음이항분포, 하이퍼지오메트릭 분포
