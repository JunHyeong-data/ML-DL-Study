# 📘 결합확률, 주변확률, 독립성 완전 정리 (심화)

---

## 1️⃣ 결합확률함수 (Joint Probability Function)
<img width="1514" height="1009" alt="image" src="https://github.com/user-attachments/assets/629d16c2-b6e2-4f1b-9706-8699817b5fa3" />

### ✔ 정의
두 확률변수 $X, Y$가 동시에 특정 값을 가질 확률
$$P(X=x, Y=y)$$
👉 **핵심 키워드**: "동시"

### ✔ 직관적 이해
- $X=1$일 확률 $\rightarrow$ 단일 사건
- $X=1$ AND $Y=2$ $\rightarrow$ 결합 사건
👉 **결합확률 = 여러 조건을 동시에 만족하는 확률**
<img width="1469" height="1065" alt="image" src="https://github.com/user-attachments/assets/b08a5977-95ee-444b-ae8b-67d4358cef61" />

### ✔ 예시
| X \ Y | 0 | 1 |
| :--- | :--- | :--- |
| **0** | 0.2 | 0.3 |
| **1** | 0.1 | 0.4 |
👉 $P(X=0, Y=1) = 0.3$

### ✔ 성질
$$\sum_x \sum_y P(x,y) = 1$$
👉 **모든 확률의 합 = 1**

## 2️⃣ 결합 누적 분포 함수 (Joint CDF)

### ✔ 정의
$$F(a,b) = P(X \le a, Y \le b)$$

### ✔ 의미
👉 **X와 Y가 동시에 특정 범위 이하**
- $X \le a$
- $Y \le b$
👉 둘 다 만족해야 함 (AND 조건)

### ✔ 직관
👉 평면에서 보면: **$(a, b)$ 기준으로 왼쪽 아래 영역 전체 확률**

---

## 3️⃣ 결합확률분포 (Joint Distribution)

### ✔ 정의
결합확률들을 모아놓은 전체 구조

### ✔ 이산형 특징
- 테이블로 표현 가능
- 경우의 수 = $|X| \times |Y|$

### ✔ 핵심 포인트
👉 **교수님 강조**: "테이블 자체가 분포다"

---

## 4️⃣ 확률 계산 방법

### ✔ (1) 이산형
$$P(a \le X \le b, c \le Y \le d) = \sum_{x=a}^{b} \sum_{y=c}^{d} P(x,y)$$
👉 그냥 해당 영역 다 더하기

### ✔ (2) 연속형
$$P(a \le X \le b, c \le Y \le d) = \int_{a}^{b} \int_{c}^{d} f(x,y) \, dy \, dx$$
👉 합($\sum$)이 적분($\int$)으로 바뀜

⚠️ **시험 함정**: 이산형인데 적분 쓰거나, 연속형인데 $\sum$ 쓰면 감점!

## 5️⃣ 주변확률 (Marginal Probability)
<img width="1521" height="1074" alt="image" src="https://github.com/user-attachments/assets/16e0f898-fff1-476b-8a1c-9823dca1a63b" />

### ✔ 개념
👉 **"다른 변수 제거하고 하나만 남긴 확률"**

### ✔ 왜 필요함?
$X$에만 관심 있고 $Y$는 필요 없을 때, $Y$의 영향을 제거하기 위해 사용한다.

### ✔ (1) 이산형
- **X의 주변확률**: $P_X(x) = \sum_y P(x,y)$ (Y를 전부 더해서 제거)
- **Y의 주변확률**: $P_Y(y) = \sum_x P(x,y)$ (X를 전부 더해서 제거)

### ✔ (2) 연속형
- **X의 주변확률**: $f_X(x) = \int f(x,y) \, dy$
- **Y의 주변확률**: $f_Y(y) = \int f(x,y) \, dx$

### ✔ 핵심 암기
| 구하려는 것 | 제거(합/적분)할 변수 |
| :--- | :--- |
| **X** | **Y** |
| **Y** | **X** |

### ✔ 테이블에서 해석
| X \ Y | 0 | 1 | **합 (Marginal X)** |
| :--- | :--- | :--- | :--- |
| **0** | 0.2 | 0.3 | **0.5** |
| **1** | 0.1 | 0.4 | **0.5** |
| **합 (Marginal Y)** | **0.3** | **0.7** | **1.0** |
👉 행 합 $\rightarrow P(X)$, 열 합 $\rightarrow P(Y)$

### ✔ 왜 "Marginal"인가?
👉 **의미**: 가장자리. 테이블의 끝(행/열 합)인 가장자리에 위치하기 때문에 "주변 확률"이라 부름.

## 7️⃣ CDF와 주변확률 연결

### ✔ 식
$$F_X(a) = \lim_{b \to \infty} F(a,b)$$
👉 **의미**: $Y$를 무한대로 보내면 $Y$의 영향이 제거되어 $X$의 누적확률만 남음.

## 8️⃣ 독립성 (Independence)
<img width="1517" height="863" alt="image" src="https://github.com/user-attachments/assets/07be0edf-db2f-43f4-875d-7a049d965ade" />
<img width="1505" height="1116" alt="image" src="https://github.com/user-attachments/assets/fcfc3d9d-89f4-4c9a-ab9c-5927a6548f42" />

### ✔ 정의
$$P(x,y) = P(x) \cdot P(y)$$
👉 **결합확률 = 각각 주변확률의 곱**

### ✔ 직관
👉 $X$가 발생해도 $Y$에 영향 없음 (예: 주사위 vs 동전)
👉 반대로 키와 몸무게는 서로 영향이 있으므로 **종속(Dependent)**

### ✔ 일반화
$$P(X_1, X_2, \dots, X_n) = \prod_{i=1}^n P(X_i)$$

## 9️⃣ 독립성 판별 (🔥시험 핵심🔥)
<img width="1533" height="1028" alt="image" src="https://github.com/user-attachments/assets/02b8524b-d2be-4bd9-9fff-4b7bf8a57242" />

### ✔ 판별 프로세스
1. **Step 1**: 테이블에서 특정 결합확률 $P(x,y)$ 값 확인
2. **Step 2**: 해당 행/열의 주변확률 $P(x)$와 $P(y)$를 곱함
3. **Step 3**: 두 값을 비교

### ✔ 예제
$P(X=0, Y=1) = 0.2$ 인데, $P(X=0)=0.3, P(Y=1)=0.4$ 라면?
👉 $0.3 \times 0.4 = 0.12 \neq 0.2$
👉 **결론**: 독립 아님 (종속)

## 🔟 매우 중요한 추가 개념

- **독립이면 항상 성립**: $f(x,y) = f_X(x) f_Y(y)$
- **기억법**: "수식이 곱으로 **쪼개지면 독립**이다."

---

## ⚠️ 자주 하는 실수 (Mistake Note)

1. **결합 vs 주변 구분**: Joint는 변수 2개($x, y$), Marginal은 변수 1개($x$ 또는 $y$)임을 명심할 것.
2. **제거 방향**: $X$를 구할 때는 반드시 **$Y$를 더하거나 적분**해야 함. (반대로 하지 말 것)
3. **독립성 검증**: 테이블 내의 단 **하나의 조합이라도** 곱셈 법칙이 성립하지 않으면 전체는 **종속**임.

---

## 🎯 시험 대비 핵심 요약

⭐ **공식 3개만 기억하면 끝**
1. **결합확률**: $P(x,y)$
2. **주변확률**: $P_X(x) = \sum_y P(x,y)$
3. **독립성**: $P(x,y) = P(x)P(y)$

💡 **최종 한 줄 정리**
👉 **결합**: 같이 일어남 / **주변**: 하나만 남김 / **독립**: 곱으로 쪼개짐
