## 1. 📌 지수분포 (Exponential Distribution) 복습
<img width="1523" height="1012" alt="image" src="https://github.com/user-attachments/assets/3102ed3f-a3d4-44b6-8044-8a72c80e14c2" />
<img width="1518" height="1112" alt="image" src="https://github.com/user-attachments/assets/873d4ca8-eb21-43ce-8454-6e3b8d827b97" />
<img width="1513" height="1012" alt="image" src="https://github.com/user-attachments/assets/0b9dea1e-4ae0-4528-823a-1399eb48207a" />
<img width="1518" height="994" alt="image" src="https://github.com/user-attachments/assets/d850bb4b-f25c-41cf-a876-82a8e8601c15" />

### ✔ 정의
확률변수 $X$의 PDF:
$$f(x) = \lambda e^{-\lambda x}, \quad x > 0$$

### ✔ 특징
- **시간 기반** 확률분포
- $x > 0$ (시간은 음수가 될 수 없음)
- $\lambda$ (람다): 단위 시간당 이벤트 발생 평균 횟수 (Rate)

### ✔ 의미
- 이벤트 간 **시간 간격** 모델링
- 포아송 분포와 수학적으로 밀접하게 연결됨

## 2. 📌 감마분포 (Gamma Distribution)
<img width="1520" height="1122" alt="image" src="https://github.com/user-attachments/assets/559cca88-0bec-450c-be26-0cfed55b82a0" />

### ✔ 정의
확률변수 $X \sim \text{Gamma}(\alpha, \lambda)$
- $\alpha$: Shape parameter (형상 모수) - 이벤트 발생 횟수
- $\lambda$: Rate parameter (척도 모수) - 단위 시간당 발생률

### ✔ 의미
> **$\alpha$개의 이벤트가 발생할 때까지 걸리는 총 시간**



### ✔ 감마함수 (Gamma Function)
$$\Gamma(\alpha) = \int_0^{\infty} x^{\alpha-1} e^{-x} dx$$
<img width="1525" height="1130" alt="image" src="https://github.com/user-attachments/assets/de61b5ab-e718-4ecc-b48f-84f069177743" />

**주요 성질**:
- $\Gamma(1) = 1$
- $\Gamma(1/2) = \sqrt{\pi}$
- $\Gamma(\alpha) = (\alpha - 1)\Gamma(\alpha - 1)$
- $\alpha$가 정수($n$)일 때: $\Gamma(n) = (n-1)!$

### ✔ 기대값 & 분산
<img width="1479" height="702" alt="image" src="https://github.com/user-attachments/assets/7488c80f-7f66-430e-9d0b-f225032d1cd8" />

- **기대값**: $E[X] = \frac{\alpha}{\lambda}$
- **분산**: $Var(X) = \frac{\alpha}{\lambda^2}$

### ✔ 핵심 관계 (시험 중요 ⭐)
<img width="1496" height="1055" alt="image" src="https://github.com/user-attachments/assets/d9322413-6554-4d2c-afc7-73d6c7d9acd8" />

**감마분포는 지수분포의 일반화이다.**
- $\alpha = 1$ 일 때 $\rightarrow$ **지수분포**와 동일함.

| 분포명 | 의미 |
| :--- | :--- |
| **지수분포** | **1번째** 이벤트가 발생할 때까지 걸리는 시간 |
| **감마분포** | **$\alpha$번째** 이벤트가 발생할 때까지 걸리는 시간 |

### ✔ 예제 (물고기 낚시 문제)
<img width="1530" height="1121" alt="image" src="https://github.com/user-attachments/assets/891db6fb-8578-4fa5-9e02-e165375ee409" />

- **조건**: 30분에 1마리 $\rightarrow$ 1시간에 2마리 ($\lambda = 2$)
- **상황**: 4마리 잡을 때까지 걸리는 시간 ($\alpha = 4$)
- **구하는 것**: $P(2 \le X \le 4)$
- **결과**: 약 **0.3**

## 3. 📌 베타분포 (Beta Distribution)
<img width="1526" height="1040" alt="image" src="https://github.com/user-attachments/assets/5e5d6b67-7155-40b2-8abb-8f5e109eb3e9" />

### ✔ 정의
확률변수 $X \sim \text{Beta}(\alpha, \beta)$
- **범위**: $0 \le x \le 1$ (확률 또는 비율의 범위)

### ✔ 의미
> **비율(Proportion) 또는 확률(Probability) 자체를 모델링**
- 예: 제품의 불량률, 마케팅 성공 확률, 특정 현상의 발생 비율 데이터



### ✔ 베타함수
$$B(\alpha, \beta) = \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)}$$

### ✔ 기대값 & 분산
<img width="1497" height="874" alt="image" src="https://github.com/user-attachments/assets/628c47e0-e0cf-473a-9013-ee1311ec6b9e" />

- **기대값**: $E[X] = \frac{\alpha}{\alpha + \beta}$
- **분산**: $Var(X) = \frac{\alpha \beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$

### ✔ 분포 모양 특징
<img width="1529" height="1140" alt="image" src="https://github.com/user-attachments/assets/85bf1289-d437-4a15-a5c7-7d636ff981d7" />

| 조건 | 형태 |
| :--- | :--- |
| $\alpha = \beta$ | 평균 0.5를 기준으로 **대칭** |
| $\alpha > \beta$ | **오른쪽**으로 치우침 (평균이 커짐) |
| $\alpha < \beta$ | **왼쪽**으로 치우침 (평균이 작아짐) |
| $\alpha, \beta < 1$ | **U-shape** (양 끝값이 나올 확률이 높음) |

### ✔ 예제 1 (DVD 불량률)
<img width="1519" height="1032" alt="image" src="https://github.com/user-attachments/assets/17ac0be9-ac4b-432f-a182-325e484379d6" />

- **분포**: $X \sim \text{Beta}(2, 5)$
- **구하는 것**: $P(0.2 \le X \le 0.3)$
- **결과**: 약 **0.235**

### ✔ 예제 2 (여왕벌 추종 비율)
<img width="1522" height="984" alt="image" src="https://github.com/user-attachments/assets/57b15860-423c-4faa-b8d6-d456363e7eb5" />

## 4. 📌 전체 정리 (시험 핵심 ⭐)

### ✔ 연속형 확률분포 종류 요약
1.  **Uniform**: 모든 구간 확률 동일
2.  **Normal**: 평균 중심 종 모양 (자연 현상)
3.  **Exponential**: 다음 이벤트까지의 **시간**
4.  **Gamma**: 여러 번의 이벤트까지의 **시간**
5.  **Beta**: **비율이나 확률** 값 자체의 분포

### ✔ 핵심 포인트 정리
- **지수분포** $\rightarrow$ 이벤트 **1개**까지의 시간
- **감마분포** $\rightarrow$ 이벤트 **여러 개($\alpha$)**까지의 시간
- **베타분포** $\rightarrow$ **비율 / 확률** 모델링
- **수학적 도구**: 감마함수의 성질($(n-1)!$)을 이용해 정수 파라미터 계산 가능
