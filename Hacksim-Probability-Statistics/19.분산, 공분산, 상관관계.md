# 📘 확률통계 강의 노트: 기대값의 특성 (Properties of Expectation)

## 1. 기대값의 정의 복습 (Review of Expectation)
<img width="1511" height="1122" alt="image" src="https://github.com/user-attachments/assets/b658e6d7-134d-4383-b9fb-c9b158003562" />

기대값은 확률변수가 가질 수 있는 값들에 각각의 확률을 곱하여 모두 더한 값입니다.

### 1.1 이산형 확률변수 (Discrete RV)
$$E[X] = \sum_{x} x P(X=x)$$
* 확률변수의 함수 $g(X)$에 대한 기대값: $E[g(X)] = \sum_{x} g(x) P(X=x)$

### 1.2 연속형 확률변수 (Continuous RV)
이산형의 $\sum$이 적분 기호 $\int$로 바뀝니다.
$$E[X] = \int_{-\infty}^{\infty} x f(x) dx$$
* 확률변수의 함수 $g(X)$에 대한 기대값: $E[g(X)] = \int_{-\infty}^{\infty} g(x) f(x) dx$

### 1.3 분산의 정의 (Variance)
분산 또한 기대값의 형태로 정의됩니다.
$$Var(X) = E[(X - E[X])^2]$$
* **의미**: 데이터가 기대값(평균)으로부터 얼마만큼 떨어져 있는지를 제곱의 스케일로 나타낸 척도입니다.

---

## 2. 독립 확률변수의 기대값 특성
<img width="1507" height="1121" alt="image" src="https://github.com/user-attachments/assets/f8be6889-9ffa-47b7-b584-1d62a11aa975" />

두 확률변수 $X, Y$가 **독립(Independent)**일 때, 각 함수의 곱에 대한 기대값은 각 기대값의 곱과 같습니다.

### 2.1 성질
$$E[g(X)h(Y)] = E[g(X)]E[h(Y)]$$

### 2.2 증명 (연속형 기준)
독립이므로 결합 확률 밀도 함수가 마지날(Marginal)의 곱으로 표현됩니다 ($f(x, y) = f_X(x)f_Y(y)$).
$$E[g(X)h(Y)] = \int \int g(x)h(y) f(x, y) dx dy$$
$$= \int \int g(x)h(y) f_X(x)f_Y(y) dx dy$$
$$= \left( \int g(x)f_X(x) dx \right) \left( \int h(y)f_Y(y) dy \right) = E[g(X)]E[h(Y)]$$

## 3. 공분산 (Covariance) ⭐
<img width="1536" height="1129" alt="image" src="https://github.com/user-attachments/assets/79f82c79-cd08-48be-8e16-57d90e13aa35" />

공분산은 두 확률변수 사이의 **선형적 관계**에 대한 정보를 제공하는 지표입니다.

### 3.1 정의
$$Cov(X, Y) = E[(X - E[X])(Y - E[Y])]$$

### 3.2 계산 공식 (중요)
실제 계산 시에는 다음의 전개된 식을 더 많이 사용합니다.
$$Cov(X, Y) = E[XY] - E[X]E[Y]$$

**[증명 과정]**
$Cov(X, Y) = E[XY - X E[Y] - Y E[X] + E[X]E[Y]]$
여기서 $E[X], E[Y]$는 상수(Constant)이므로 기대값 밖으로 나옵니다.
$= E[XY] - E[X]E[Y] - E[Y]E[X] + E[X]E[Y]$
$= E[XY] - E[X]E[Y]$

### 3.3 독립성과 공분산의 관계
<img width="1532" height="1135" alt="image" src="https://github.com/user-attachments/assets/c743e068-6cb3-4fc3-a7d8-43f6fd5345b5" />

1. **독립이면 공분산은 0이다**: $X, Y$가 독립이면 $E[XY] = E[X]E[Y]$이므로 $Cov(X, Y) = 0$.
2. **역은 성립하지 않는다**: 공분산이 0이라고 해서 항상 독립인 것은 아닙니다. (비선형적 관계가 존재할 수 있음)

**[반례 예시]**
- $X$가 $\{-1, 0, 1\}$을 각각 $1/3$의 확률로 가짐.
- $Y$는 $X=0$이면 $1$, 아니면 $0$으로 정의 ($Y$는 $X$에 종속됨).
- 계산 결과 $Cov(X, Y)=0$이 나오지만, $X$와 $Y$는 명백히 독립이 아닙니다.

## 4. 공분산의 주요 특성 (Properties)
<img width="1512" height="927" alt="image" src="https://github.com/user-attachments/assets/33b36f0d-a775-4320-8acb-f97b2d63b5a7" />
<img width="1517" height="792" alt="image" src="https://github.com/user-attachments/assets/b828e2bb-9d86-453d-8859-ace570a3aa94" />
<img width="1501" height="1040" alt="image" src="https://github.com/user-attachments/assets/9f4dada1-ce7d-4197-8d3f-0f017d3f96ac" />

1. **교환 법칙**: $Cov(X, Y) = Cov(Y, X)$
2. **자기 자신과의 공분산**: $Cov(X, X) = Var(X)$
3. **상수 곱**: $Cov(aX, Y) = a Cov(X, Y)$
4. **합의 공분산**: $Cov(\sum_{i=1}^n X_i, \sum_{j=1}^m Y_j) = \sum_{i=1}^n \sum_{j=1}^m Cov(X_i, Y_j)$

## 5. 확률변수 합의 분산 (Variance of a Sum)

여러 확률변수를 더한 값의 분산은 각 분산의 합에 공분산 항을 더한 것과 같습니다.

### 5.1 일반식
<img width="1509" height="1142" alt="image" src="https://github.com/user-attachments/assets/21851fb9-4b5b-4b48-8c9c-da4b1d03bf6e" />

$$Var\left(\sum_{i=1}^n X_i\right) = \sum_{i=1}^n Var(X_i) + 2 \sum_{i<j} Cov(X_i, X_j)$$

### 5.2 두 변수의 경우
<img width="1531" height="929" alt="image" src="https://github.com/user-attachments/assets/0e8cbb00-b776-4b14-84ac-d635595f284b" />

$$Var(X+Y) = Var(X) + Var(Y) + 2Cov(X, Y)$$

### 5.3 독립인 경우 (독립이면 $Cov=0$)
<img width="1509" height="977" alt="image" src="https://github.com/user-attachments/assets/ed73d788-4394-4007-9c36-d546ed535a88" />

변수들이 서로 독립(Pairwise Independent)이라면 공분산 항이 모두 사라집니다.
$$Var\left(\sum_{i=1}^n X_i\right) = \sum_{i=1}^n Var(X_i)$$

## 6. 표본 평균과 표본 분산 (Sample Mean & Variance)
<img width="1523" height="909" alt="image" src="https://github.com/user-attachments/assets/5ede42ff-1aa2-4706-a835-d0563cbd782f" />

동일한 분포(i.i.d)를 따르는 $n$개의 확률변수 $X_1, \dots, X_n$이 있을 때:
* **기대값**: $E[X_i] = \mu$
* **분산**: $Var(X_i) = \sigma^2$

### 6.1 표본 평균 (Sample Mean)
$$\bar{X} = \frac{\sum_{i=1}^n X_i}{n}$$

### 6.2 표본 분산 (Sample Variance)
데이터와 표본 평균의 차이인 **편차(Deviation)**를 이용하여 정의합니다.
$$S^2 = \frac{\sum_{i=1}^n (X_i - \bar{X})^2}{n-1}$$
* 분모가 $n$이 아니라 **$n-1$**인 이유는 표본 분산의 기대값이 모분산($\sigma^2$)과 일치하게 만들기 위함(불편 추정량)입니다.

# 📘 확률통계 강의 노트: 표본 분산, 이항분포의 분산 및 상관계수

## 1. 표본 분산($S^2$)의 기대값 증명 ⭐
<img width="1521" height="1135" alt="image" src="https://github.com/user-attachments/assets/e0273f8c-b016-4b9f-a31a-4593fdecb59b" />

우리는 표본 분산을 정의할 때 분모를 $n$이 아닌 $n-1$로 나눕니다. 그 이유는 표본 분산의 기대값이 모분산($\sigma^2$)과 일치하게 만들기 위함입니다.

### 1.1 증명 과정 (수식 전개)
표본 분산의 정의: $S^2 = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \bar{X})^2$

먼저, 분자 부분인 $\sum_{i=1}^{n} (X_i - \bar{X})^2$을 정리하기 위해 모평균 $\mu$를 빼고 더하는 트릭을 사용합니다.
$$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n [(X_i - \mu) - (\bar{X} - \mu)]^2$$
$$= \sum_{i=1}^n (X_i - \mu)^2 - 2(\bar{X} - \mu) \sum_{i=1}^n (X_i - \mu) + n(\bar{X} - \mu)^2$$

여기서 $\sum_{i=1}^n (X_i - \mu) = n\bar{X} - n\mu = n(\bar{X} - \mu)$ 이므로 중간 항을 정리하면:
$$= \sum_{i=1}^n (X_i - \mu)^2 - 2n(\bar{X} - \mu)^2 + n(\bar{X} - \mu)^2$$
$$= \sum_{i=1}^n (X_i - \mu)^2 - n(\bar{X} - \mu)^2$$

### 1.2 기대값 취하기
이제 양변에 기대값을 취합니다.
$$E[(n-1)S^2] = \sum_{i=1}^n E[(X_i - \mu)^2] - n E[(\bar{X} - \mu)^2]$$
* $E[(X_i - \mu)^2]$ 는 정의상 모분산 **$\sigma^2$** 입니다.
* $E[(\bar{X} - \mu)^2]$ 는 표본 평균의 분산인 **$Var(\bar{X}) = \frac{\sigma^2}{n}$** 입니다.

따라서,
$$E[(n-1)S^2] = n\sigma^2 - n(\frac{\sigma^2}{n}) = n\sigma^2 - \sigma^2 = (n-1)\sigma^2$$
양변을 $(n-1)$로 나누면 최종 결과가 나옵니다.
$$E[S^2] = \sigma^2$$

> **결론**: 표본 분산의 기대값은 정확히 모분산과 일치합니다. 이를 **불편 추정량(Unbiased Estimator)**이라고 부릅니다.

## 2. 이항분포(Binomial)의 분산 유도
<img width="1527" height="1125" alt="image" src="https://github.com/user-attachments/assets/c2c74b32-9f10-44ee-9a57-fb0a23bf3a20" />

이항분포 $X \sim \text{Binomial}(n, p)$의 분산이 왜 $np(1-p)$인지 베르누이 시행의 합으로 증명합니다.

### 2.1 베르누이 확률변수 활용
이항분포는 독립적인 베르누이 확률변수 $X_1, \dots, X_n$의 합입니다. ($X = \sum X_i$)
* 각 $X_i \sim \text{Bernoulli}(p)$ 에 대해:
    * $E[X_i] = p$
    * $Var(X_i) = p(1-p)$

### 2.2 합의 분산 적용
$X_i$들이 서로 독립이므로 공분산 항은 모두 0이 됩니다.
$$Var(X) = Var(X_1 + \dots + X_n) = Var(X_1) + \dots + Var(X_n)$$
$$= np(1-p)$$

## 3. 공분산 응용 예제: 센터링된 변수의 공분산
<img width="1523" height="1115" alt="image" src="https://github.com/user-attachments/assets/2ae03bee-629e-4461-b9e9-dac2b2d3a5d4" />

독립이고 동일한 분포(i.i.d)를 따르는 $X_i$들에 대해, 각 변수에서 표본 평균을 뺀 값($X_i - \bar{X}$)과 표본 평균($\bar{X}$) 사이의 공분산은 0임을 증명합니다.

### ✔️ 증명 요약
$$Cov(X_i - \bar{X}, \bar{X}) = Cov(X_i, \bar{X}) - Cov(\bar{X}, \bar{X})$$
1. $Cov(X_i, \bar{X}) = Cov(X_i, \frac{1}{n} \sum X_j) = \frac{1}{n} Var(X_i) = \frac{\sigma^2}{n}$ (독립이므로 $i=j$인 항만 남음)
2. $Cov(\bar{X}, \bar{X}) = Var(\bar{X}) = \frac{\sigma^2}{n}$
따라서, $\frac{\sigma^2}{n} - \frac{\sigma^2}{n} = 0$ 이 됩니다.

## 4. 상관계수 (Correlation, $\rho$) ⭐
<img width="1533" height="1135" alt="image" src="https://github.com/user-attachments/assets/78651bb6-9185-45f3-992c-9f9e6bb95ac6" />

공분산($Cov$)은 데이터의 스케일에 따라 값이 크게 변하는 단점이 있습니다. 이를 보완하기 위해 표준편차로 나눠준 것이 상관계수입니다.

### 4.1 정의
$$\rho_{X,Y} = \frac{Cov(X, Y)}{\sigma_X \sigma_Y}$$
* **범위**: $-1 \le \rho \le 1$
* **의미**: 두 변수 사이의 **선형 관계**의 강도와 방향을 나타냅니다.

### 4.2 시각적 이해


1. **$\rho \approx 1$ (양의 상관관계)**: $X$가 커질 때 $Y$도 직선적으로 커집니다.
2. **$\rho \approx -1$ (음의 상관관계)**: $X$가 커질 때 $Y$는 직선적으로 작아집니다. 상관관계가 없는 것이 아니라, **반대 방향으로 매우 강한 것**입니다.
3. **$\rho \approx 0$ (상관관계 없음)**: 두 변수 사이에 선형적인 관계가 보이지 않습니다. (원형 클라우드 형태)

> **핵심**: 상관계수는 공분산을 **스케일링(Scaling)**하여 누구나 직관적으로 관계의 크기를 알 수 있게 만든 지표입니다.
