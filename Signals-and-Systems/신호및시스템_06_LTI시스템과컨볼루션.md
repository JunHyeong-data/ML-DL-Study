## 1. 복소수 좌표계 변환 복습 및 예제

### 1-1. 세 가지 좌표계 복습

| 형식 | 표현 | 조건 |
|------|------|------|
| 직교 좌표계 | $a + jb$ | 덧셈·뺄셈에 유리 |
| 지수 형식 | $r e^{j\theta}$ | 곱셈·나눗셈·미적분에 유리 |
| 극형식 | $r\angle\theta$ | 곱셈·나눗셈에 유리 |

> **지수 형식 조건**: 앞의 크기 $r$은 반드시 **실수 (거리)**, 각도 $\theta$는 **x축 양의 방향 기준**

### 1-2. 변환 공식

**직교 → 지수/극형식:**

$$r = |z| = \sqrt{a^2 + b^2}$$

$$\theta = \angle z = \arctan\!\left(\frac{b}{a}\right)$$

**지수/극 → 직교:**

$$a = r\cos\theta, \qquad b = r\sin\theta$$

### 1-3. 예제 풀이

**예제 1**: $x(t) = jae^{j2\pi \cdot 60t}$ — 지수 형식인가?

- $ja$는 복소수 → 크기 $r$이 실수가 아님 → **지수 형식 아님**
- $ja = ae^{j\pi/2}$ (순허수이므로 크기 $a$, 각도 $90°$)
- 변환 결과:

$$x(t) = a \cdot e^{j\pi/2} \cdot e^{j2\pi \cdot 60t} = a \cdot e^{j(2\pi \cdot 60t + \pi/2)}$$

**예제 2**: $y[n] = (4 - j\sqrt{3}^n)$ 형태 — 지수 형식으로 변환

직교 성분 분리 후:

$$r = \sqrt{(\text{실수부})^2 + (\text{허수부})^2}$$

$$\theta = \arctan\!\left(\frac{\text{허수부}}{\text{실수부}}\right)$$

**예제 3**: $g(t) = 1 + e^{jot}$ — 지수 형식으로 변환

오일러 공식 적용:

$$e^{jot} = \cos(ot) + j\sin(ot)$$

$$g(t) = (1 + \cos(ot)) + j\sin(ot)$$

$$r = \sqrt{(1+\cos(ot))^2 + \sin^2(ot)} = \sqrt{2 + 2\cos(ot)}$$

$$\theta = \arctan\!\left(\frac{\sin(ot)}{1+\cos(ot)}\right)$$

최종:

$$g(t) = \sqrt{2 + 2\cos(ot)} \cdot e^{j\theta}$$

> **핵심**: 덧셈이 필요할 땐 직교 좌표계로 변환 후 계산 → 다시 지수 형식으로 변환

## 2. LTI 시스템이란

### 2-1. 정의

$$\text{LTI} = \text{Linear (선형)} + \text{Time-Invariant (시불변)}$$

| 성질 | 의미 |
|------|------|
| **선형성** | 입력이 커지면 출력도 비례해서 커짐. 중첩의 원리 성립 |
| **시불변성** | 입력이 $t_0$만큼 지연되면 출력도 $t_0$만큼 지연 |

### 2-2. LTI 시스템이 중요한 이유

**예측 가능성**: 어느 시점에 측정해도 동일한 특성 → 한 번 분석하면 영구 사용 가능

```
비LTI 시스템: 시시각각 특성 변화 → 매 순간 기록 필요 → 해석 불가
LTI 시스템:  시간에 무관하게 동일 특성 → 예측 가능 → 해석 용이
```

**컨볼루션의 전제**: LTI 시스템이라는 가정하에서만 컨볼루션이 성립

**주파수 영역 변환**: LTI 시스템이기 때문에 푸리에 변환 등이 쉬워짐

> **실제 회로**는 엄밀히 LTI가 아니지만, **짧은 시간 내**에는 LTI로 근사 가능  
> **이산시간(디지털) 시스템**에서는 실제로 LTI가 성립 → 디지털 시스템의 장점!

### 2-3. 선형성 상세

$$ax_1[n] + bx_2[n] \;\xrightarrow{H}\; ay_1[n] + by_2[n]$$

- 기본 신호(임펄스)에 대한 출력을 알면 → 임의 입력에 대한 출력 **예측 가능**

## 3. 임펄스 응답 (Impulse Response)

### 3-1. 정의

$$\delta[n] \;\xrightarrow{H}\; h[n]$$

> **임펄스 응답 $h[n]$**: 시스템의 입력이 단위 임펄스 $\delta[n]$일 때의 출력

- $h[n]$이 시스템을 **수학적으로 완전히 표현**하는 함수
- LTI 시스템이면 $h[n]$만 알면 어떤 입력에 대한 출력도 구할 수 있음

### 3-2. 비유

> "정체불명의 박스를 발로 찬다"  
> → 순간적 충격(임펄스) 입력에 대한 반응을 보고 시스템 특성 파악  
> → 딸랑거리면 방울, 묵직하면 무거운 물체, 쉽게 날아가면 빈 상자

### 3-3. 시불변성과 임펄스 응답

$$\delta[n-k] \;\xrightarrow{H}\; h[n-k]$$

시불변 시스템에서는 입력을 $k$만큼 지연시키면 출력도 $k$만큼 지연됨.

---

## 4. 임펄스를 이용한 신호 표현

### 4-1. 샘플링 성질 복습

$$x[n] \cdot \delta[n-k] = x[k] \cdot \delta[n-k]$$

$$\sum_{n=-\infty}^{\infty} x[n]\,\delta[n-k] = x[k]$$

### 4-2. 임의 신호의 임펄스 분해

임의 이산시간 신호 $x[n]$을 임펄스 합으로 표현:

$$\boxed{x[n] = \sum_{k=-\infty}^{\infty} x[k]\,\delta[n-k]}$$

**직관적 이해:**

$$x[n] = \cdots + x[-1]\,\delta[n+1] + x[0]\,\delta[n] + x[1]\,\delta[n-1] + x[2]\,\delta[n-2] + \cdots$$

- 각 $\delta[n-k]$는 $n=k$에서만 1인 신호
- $x[k]$는 해당 임펄스의 **가중치(weighting factor)**

---

## 5. 컨볼루션 합 (Convolution Sum)

### 5-1. 유도 과정

$x[n]$을 임펄스 분해 후 LTI 시스템에 입력:

**1단계**: $x[n] = \sum_{k} x[k]\,\delta[n-k]$

**2단계**: LTI 시스템 적용 (선형성)

$$y[n] = H\left(\sum_{k} x[k]\,\delta[n-k]\right) = \sum_{k} x[k]\, H(\delta[n-k])$$

**3단계**: 시불변성 적용 → $H(\delta[n-k]) = h[n-k]$

$$\boxed{y[n] = \sum_{k=-\infty}^{\infty} x[k]\, h[n-k]}$$

이것이 **컨볼루션 합 (Convolution Sum)**이다.

### 5-2. 표기법

$$y[n] = x[n] \ast h[n]$$

- $\ast$: 컨볼루션 연산자
- 이산시간: **컨볼루션 합 (Convolution Sum)**
- 연속시간: **컨볼루션 적분 (Convolution Integral)**

$$y(t) = \int_{-\infty}^{\infty} x(\tau)\, h(t-\tau)\, d\tau = x(t) \ast h(t)$$

### 5-3. 교환 법칙 (Commutativity)

$$x[n] \ast h[n] = h[n] \ast x[n]$$

$$\sum_{k} x[k]\, h[n-k] = \sum_{k} h[k]\, x[n-k]$$

> 증명은 뒤에서 다루며, 지금은 **교환 법칙이 성립한다**는 것만 기억

### 5-4. 컨볼루션의 물리적 의미

$$y[n] = \sum_{k} x[k] \cdot h[n-k]$$

- $x[k]$: 고정된 입력 신호
- $h[n-k]$: **반전($k \to -k$) 후 $n$만큼 이동**시킨 임펄스 응답
- 두 신호를 곱하여 **겹치는 구간의 합**을 구하는 연산

```
컨볼루션 절차:
  1. h[k]를 반전 → h[-k]
  2. n만큼 이동 → h[n-k]
  3. x[k]와 곱하기
  4. k에 대해 합산 → y[n]
```

## 6. 컨볼루션 예제

### 예제 1 (교재 2.3): 지수 감쇠 신호

**입력**: $x[n] = u[n]$ (단위 계단)  
**임펄스 응답**: $h[n] = \alpha^n u[n]$, $|\alpha| < 1$

컨볼루션 합:

$$y[n] = \sum_{k=-\infty}^{\infty} x[k]\, h[n-k] = \sum_{k=0}^{n} \alpha^{n-k} \cdot u[n]$$

$u[k]$가 $k \geq 0$에서만 1이므로 구간 정리:

$$y[n] = \sum_{k=0}^{n} \alpha^{n-k}, \quad n \geq 0$$

등비수열 합 공식 적용:

$$y[n] = \alpha^n \sum_{k=0}^{n} \alpha^{-k} = \frac{1 - \alpha^{n+1}}{1 - \alpha} \cdot u[n]$$

### 예제 2 (교재 2.4): 사각 펄스 컨볼루션 (그래픽 해법)

**입력**: $x[n] = 1$ for $0 \leq n \leq 4$, 나머지 0  
**임펄스 응답**: $h[n]$ for $0 \leq n \leq 6$ (증가하는 형태)

**그래픽 해법 구간 분류:**

| 구간 | 겹침 여부 | $y[n]$ |
|------|----------|--------|
| $n < 0$ | 겹침 없음 | $0$ |
| $0 \leq n \leq 4$ | 일부 겹침 | $\sum_{k=0}^{n} h[k]$ |
| $4 < n \leq 6$ | 전체 겹침 | $\sum_{k=0}^{4} h[k]$ |
| $6 < n \leq 10$ | 일부 겹침 | $\sum_{k=n-4}^{6} h[k]$ 등 |
| $n > 10$ | 겹침 없음 | $0$ |

> 컨볼루션 결과의 길이: 두 신호 길이의 합 - 1  
> ($5 + 7 - 1 = 11$점)

### 예제 3 (교재 2.5): 두 지수 신호의 컨볼루션

**입력**: $x[n] = 2^n u[-n]$  
**임펄스 응답**: $h[n] = u[n]$

**$n \geq 0$ 구간:**

$$y[n] = \sum_{k=-\infty}^{0} 2^k = \frac{1}{1 - 2^{-1}} \cdot 2^0 = 2, \quad n \geq 0$$

**$n < 0$ 구간:**

$$y[n] = \sum_{k=-\infty}^{n} 2^k = \frac{2^n}{1-2^{-1}} = 2 \cdot 2^n = 2^{n+1}, \quad n < 0$$

최종 결과:

$$y[n] = \begin{cases} 2 & n \geq 0 \\ 2^{n+1} & n < 0 \end{cases}$$

## 7. 핵심 요약 & 시험 포인트

### ✅ 반드시 외울 공식

**신호의 임펄스 분해:**

$$x[n] = \sum_{k=-\infty}^{\infty} x[k]\,\delta[n-k]$$

**이산시간 컨볼루션 합:**

$$y[n] = x[n] \ast h[n] = \sum_{k=-\infty}^{\infty} x[k]\,h[n-k]$$

**연속시간 컨볼루션 적분:**

$$y(t) = x(t) \ast h(t) = \int_{-\infty}^{\infty} x(\tau)\,h(t-\tau)\,d\tau$$

**교환 법칙:**

$$x[n] \ast h[n] = h[n] \ast x[n]$$

### ✅ 컨볼루션 계산 절차

```
① h[k]를 반전 → h[-k]
② n만큼 이동 → h[n-k]
③ x[k]와 점별 곱셈
④ k에 대해 합산 → y[n]
⑤ n을 변화시켜 반복
```

### ✅ 자주 틀리는 포인트

- 컨볼루션은 **LTI 시스템 가정**에서만 성립
- $h[n-k]$: 반전 후 $n$만큼 이동 (부호 주의)
- $u[n-k]$의 유효 구간: $n-k \geq 0 \Rightarrow k \leq n$
- 결과 신호 길이: 두 신호 길이 $L_1 + L_2 - 1$
- 교환 법칙 성립: $x \ast h = h \ast x$ (계산 편한 쪽 선택)

### ✅ 이번 학기 3대 핵심

1. **LTI 시스템** — 예측 가능한 이상적 시스템
2. **컨볼루션** — LTI 시스템의 입출력 관계 계산법
3. **푸리에 변환** — 신호를 주파수 영역에서 분석 (이후 강의)
