## 1. 이산시간 주파수-주기 관계 심화

### 1-1. 핵심 실험: 9개 신호 분석

$x[n] = \cos(\omega_0 n)$에서 $\omega_0$를 0부터 $2\pi$까지 증가시킬 때:

| 신호 | $\omega_0$ | $\omega_0$ 수치 | $N_0$ |
|------|-----------|----------------|-------|
| a | $0$ | $0$ | $\infty$ (상수) |
| b | $\frac{\pi}{8}$ | $\approx 0.39$ | $16$ |
| c | $\frac{\pi}{4}$ | $\approx 0.79$ | $8$ |
| d | $\frac{\pi}{2}$ | $\approx 1.57$ | $4$ |
| **e** | $\pi$ | $\approx 3.14$ | $2$ |
| f | $\frac{3\pi}{2}$ | $\approx 4.71$ | $4$ |
| g | $\frac{7\pi}{4}$ | $\approx 5.50$ | $8$ |
| h | $\frac{15\pi}{8}$ | $\approx 5.89$ | $16$ |
| i | $2\pi$ | $\approx 6.28$ | $\infty$ (상수, a와 동일) |

### 1-2. 관찰 결과 — ⭐ 핵심

**$0 \leq \omega_0 \leq \pi$ 구간**: $\omega_0$ 증가 → $N_0$ 감소 (연속시간과 같음)

**$\pi < \omega_0 \leq 2\pi$ 구간**: $\omega_0$ 증가 → $N_0$ **증가** (연속시간과 반대!)

$$N_0: \quad \infty \to 16 \to 8 \to 4 \to \mathbf{2} \to 4 \to 8 \to 16 \to \infty$$

→ $\omega_0 = \pi$를 기준으로 **좌우 대칭** 패턴

### 1-3. 이산시간 핵심 성질 3가지

**성질 1**: $\omega_0 = 0$과 $\omega_0 = 2\pi$는 동일한 신호

$$e^{j \cdot 0 \cdot n} = e^{j \cdot 2\pi n} = 1 \quad \text{(항상 같음)}$$

**성질 2**: 물리적으로 가장 높은 주파수는 $\omega_0 = \pi$

$$e^{j\pi n} = (-1)^n \quad \text{(+1, -1 교번 — 가장 빠른 변화)}$$

증명:

$$e^{j\pi} = \cos\pi + j\sin\pi = -1$$

$$e^{j\pi n} = (-1)^n \checkmark$$

**성질 3**: 의미 있는 주파수 범위는 $[0,\, 2\pi]$ 또는 $[-\pi,\, \pi]$

$$e^{j(\omega_0 + 2\pi)n} = e^{j\omega_0 n} \cdot e^{j2\pi n} = e^{j\omega_0 n}$$

→ $2\pi$ 주기로 반복 → $[-\pi, \pi]$ 또는 $[0, 2\pi]$ 구간만 분석하면 충분

### 1-4. 연속시간 vs 이산시간 비교

| 항목 | 연속시간 | 이산시간 |
|------|---------|---------|
| 유효 주파수 범위 | $(-\infty, +\infty)$ 전부 | $[-\pi, \pi]$ 또는 $[0, 2\pi]$ |
| 최고 주파수 | 제한 없음 | $\omega_0 = \pi$ |
| $\omega_0$ 증가 → $N_0$ | 항상 감소 | $\omega_0 \leq \pi$: 감소, $\omega_0 > \pi$: 증가 |
| 서로 다른 신호 | $\omega_0$ 다르면 항상 다름 | $2\pi$ 주기로 같은 신호 반복 |

> **디지털 신호 처리의 장점**: $[-\pi, \pi]$ 범위만 분석하면 되므로 연속시간보다 훨씬 단순!

## 2. 이산시간 고조파

### 2-1. 연속시간 고조파 복습

$$\phi_k(t) = e^{jk\omega_0 t}, \quad k = 0, \pm1, \pm2, \ldots$$

→ $k$가 다르면 항상 다른 신호 (무한히 많은 고조파 존재)

### 2-2. 이산시간 고조파

$$\phi_k[n] = e^{jk\omega_0 n}, \quad \omega_0 = \frac{2\pi}{N}$$

$k$번째 고조파:

$$\phi_k[n] = e^{j\frac{2\pi}{N}kn}$$

**$k$와 $k+N$은 동일한 신호:**

$$\phi_{k+N}[n] = e^{j\frac{2\pi}{N}(k+N)n} = e^{j\frac{2\pi}{N}kn} \cdot \underbrace{e^{j2\pi n}}_{=1} = \phi_k[n]$$

### 2-3. 결론 — ⭐ 핵심

> **이산시간**에서는 서로 다른 고조파가 정확히 **$N$개** 존재한다.  
> ($k = 0, 1, 2, \ldots, N-1$)

> **연속시간**에서는 고조파가 **무한히** 많이 존재한다.  
> ($k = 0, \pm1, \pm2, \ldots$ 모두 다른 신호)

## 3. 단위 임펄스 함수 (Unit Impulse)

### 3-1. 왜 필요한가?

> **비유**: 정체불명의 박스가 있을 때 가장 간단한 확인법 → **발로 차보기**  
> 순간 충격(임펄스)을 가했을 때 시스템의 반응을 보고 특성 파악

복잡한 입력을 쓰면 출력도 복잡 → 분석 어려움  
**가장 간단한 신호**(임펄스, 계단)를 입력으로 쓰면 시스템 분석이 쉬워짐

### 3-2. 이산시간 단위 임펄스 (Kronecker Delta)

$$\delta[n] = \begin{cases} 1 & n = 0 \\ 0 & n \neq 0 \end{cases}$$

시간 이동:

$$\delta[n - k] = \begin{cases} 1 & n = k \\ 0 & n \neq k \end{cases}$$

그래프:

```
δ[n]          δ[n-2]
  │             │
1 ┤             │       1
  │    ...   ───┤── ────┤────
──┼──────────   │       │
  0  1  2       0   1   2   n
```

### 3-3. 연속시간 단위 임펄스 (Dirac Delta)

$$\delta(t) = \begin{cases} \infty & t = 0 \\ 0 & t \neq 0 \end{cases}, \qquad \int_{-\infty}^{\infty} \delta(t)\, dt = 1$$

> 이산시간 $\delta[n]$과 구별하기 위해 **디랙 델타(Dirac Delta)** 라고 부름  
> 화살표로 표시하며, 숫자는 **가중치(Weighting Factor)**

**유도**: 폭 $\Delta$, 높이 $\frac{1}{\Delta}$인 사각 펄스에서 $\Delta \to 0$으로 극한

$$\lim_{\Delta \to 0} \frac{1}{\Delta} \cdot \text{rect}\!\left(\frac{t}{\Delta}\right) = \delta(t)$$

면적은 항상 1로 유지, 높이는 $\infty$로 발산

## 4. 단위 계단 함수 (Unit Step)

### 4-1. 이산시간 단위 계단

$$u[n] = \begin{cases} 1 & n \geq 0 \\ 0 & n < 0 \end{cases}$$

시간 이동:

$$u[n - k] = \begin{cases} 1 & n \geq k \\ 0 & n < k \end{cases}$$

### 4-2. 연속시간 단위 계단

$$u(t) = \begin{cases} 1 & t \geq 0 \\ 0 & t < 0 \end{cases}$$

---

## 5. 임펄스와 계단의 관계

### 5-1. 이산시간 관계식 ⭐

**계단 → 임펄스 (차분):**

$$\delta[n] = u[n] - u[n-1]$$

**임펄스 → 계단 (합산):**

$$u[n] = \sum_{k=0}^{\infty} \delta[n-k] = \sum_{m=-\infty}^{n} \delta[m]$$

직관적 이해:

$$u[n] = \delta[0] + \delta[-1\text{ 위치}] + \delta[-2\text{ 위치}] + \cdots = \sum_{k \geq 0} \delta[n-k]$$

### 5-2. 연속시간 관계식 ⭐

**계단 → 임펄스 (미분):**

$$\delta(t) = \frac{d}{dt}u(t)$$

**임펄스 → 계단 (적분):**

$$u(t) = \int_{-\infty}^{t} \delta(\tau)\, d\tau$$

### 5-3. 이산 ↔ 연속 대응 관계

| 연산 | 이산시간 | 연속시간 |
|------|---------|---------|
| 계단 → 임펄스 | **차분** (뺄셈) | **미분** |
| 임펄스 → 계단 | **합산** ($\sum$) | **적분** ($\int$) |

## 6. 샘플링 성질 (Sifting Property)

### 6-1. 이산시간

$$x[n] \cdot \delta[n] = x[0] \cdot \delta[n]$$

$$x[n] \cdot \delta[n - n_0] = x[n_0] \cdot \delta[n - n_0]$$

$$\sum_{n=-\infty}^{\infty} x[n]\, \delta[n - n_0] = x[n_0]$$

### 6-2. 연속시간

$$x(t) \cdot \delta(t - t_0) = x(t_0) \cdot \delta(t - t_0)$$

$$\int_{-\infty}^{\infty} x(t)\, \delta(t - t_0)\, dt = x(t_0)$$

**의미**: 임펄스를 곱하면 특정 시점의 값만 뽑아낼 수 있다 → **샘플링의 수학적 표현**

> 이것이 앞으로 배울 **샘플링 이론**의 기반이 되는 개념!

---

## 7. 연속시간 임펄스 함수 (디랙 델타)

디랙 델타의 중요 성질 정리:

**면적 = 1:**

$$\int_{-\infty}^{\infty} \delta(t)\, dt = 1$$

**스케일링:**

$$\delta(at) = \frac{1}{|a|}\delta(t)$$

**샘플링:**

$$\int_{-\infty}^{\infty} x(t)\, \delta(t - t_0)\, dt = x(t_0)$$

**짝함수:**

$$\delta(-t) = \delta(t)$$

## 8. 다음 강의 예고: 시스템 성질

1.6절에서 다룰 시스템의 기본 성질들:

| 성질 | 영어 | 핵심 개념 |
|------|------|---------|
| **선형성** | Linearity | 중첩 원리 성립 |
| **시불변성** | Time-Invariance | 시간 이동해도 같은 출력 |
| **메모리** | Memory | 현재 출력이 과거/미래 입력에 의존 |
| **인과성** | Causality | 미래 입력에 의존하지 않음 |
| **안정성** | Stability | 유한 입력 → 유한 출력 (BIBO) |
| **가역성** | Invertibility | 역시스템 존재 여부 |

> 선형성 + 시불변성 = **LTI 시스템** (이 과목의 핵심 대상!)

## 9. 핵심 요약 & 시험 포인트

### ✅ 반드시 외울 것

**이산시간 주파수**:

$$\text{물리적 최고 주파수} = \omega_0 = \pi, \quad e^{j\pi n} = (-1)^n$$

$$\text{유효 범위}: [-\pi,\, \pi] \;\text{또는}\; [0,\, 2\pi]$$

**임펄스 ↔ 계단 관계**:

$$\delta[n] = u[n] - u[n-1] \qquad \text{(이산: 차분)}$$

$$\delta(t) = \frac{d}{dt}u(t) \qquad \text{(연속: 미분)}$$

$$u[n] = \sum_{k=0}^{\infty} \delta[n-k] \qquad \text{(이산: 합산)}$$

$$u(t) = \int_{-\infty}^{t} \delta(\tau)\, d\tau \qquad \text{(연속: 적분)}$$

**샘플링 성질**:

$$\int_{-\infty}^{\infty} x(t)\,\delta(t - t_0)\, dt = x(t_0)$$

$$\sum_{n=-\infty}^{\infty} x[n]\,\delta[n - n_0] = x[n_0]$$

**이산시간 고조파 개수**: 기본 주기 $N$일 때 정확히 **$N$개** ($k = 0, 1, \ldots, N-1$)

### ✅ 자주 틀리는 포인트

- 이산시간에서 $\omega_0 > \pi$이면 주파수가 커져도 $N_0$가 다시 증가함
- $\delta[n]$은 $n=0$에서 **1** (유한), $\delta(t)$는 $t=0$에서 **$\infty$** (무한대)
- 이산 차분 = 연속 미분, 이산 합산 = 연속 적분 대응 관계 혼동 주의
- 고조파 개수: 연속시간 = **무한**, 이산시간 = **$N$개** (유한)
