## 1. 이번 학기 전체 로드맵

```
[1장] 신호·시스템 기초 (시간 영역)
   ↓
[2장] 선형 시불변(LTI) 시스템
   ↓
[3장] 주기 신호 → 푸리에 급수 (Fourier Series)
   ↓
[4·5장] 푸리에 변환 — 연속시간 / 이산시간
   ↓
[6장] 주파수 영역에서의 신호·시스템
   ↓
[7장] 샘플링 & 복원 (Sampling & Reconstruction)
   ↓
[8장] (진도 빠를 경우) Z-변환
```

### 최종 목표: 주파수 응답 / 전달함수

$$H(j\omega) = \frac{Y(j\omega)}{X(j\omega)}$$

- $H(j\omega)$: 시스템의 **주파수 응답** (= 전달함수, 회로에서 봤던 그것)
- 입력 신호 → 시스템 → 출력 신호 관계를 **주파수 영역**에서 표현

### 실제 시스템 처리 흐름

```
아날로그 입력 x(t)
      ↓  [샘플링: × 임펄스 열]
이산시간 신호 x[n]
      ↓  [디지털 시스템 H]
이산시간 출력 y[n]
      ↓  [D/A 변환]
아날로그 출력 y(t)
```

> 요즘 대부분의 장비는 **디지털** → 아날로그 신호를 디지털화해서 처리한 뒤 다시 아날로그로 복원

## 2. 신호(Signal)의 정의와 분류

### 2-1. 정의

> **신호**: 어떤 현상의 성적·특성을 나타내는 **변수들의 함수**  
> 예: 전압, 전류, 음성, 영상

### 2-2. 연속시간 신호 vs 이산시간 신호

| 구분 | 연속시간 (Continuous-Time) | 이산시간 (Discrete-Time) |
|------|--------------------------|------------------------|
| 표기 | $x(t)$ — 소괄호 | $x[n]$ — 대괄호 |
| 독립변수 | 시간 $t$ (실수) | 순서 $n$ (정수) |
| 특징 | 모든 시간에 값 존재 (아날로그) | 샘플링으로 얻은 띄엄띄엄 데이터 |
| 다른 이름 | 아날로그 신호 | 디지털 신호 |

> **핵심**: 괄호 모양으로 구분!  
> - $x(t)$: 둥근 괄호 → 연속시간  
> - $x[n]$: 각진 괄호 → 이산시간

**이산시간 신호는 연속시간 신호를 샘플링해서 얻는다:**

$$x[n] = x(nT_s), \quad n \in \mathbb{Z}$$

여기서 $T_s$는 샘플링 주기.

## 3. 시스템(System)의 정의

> **시스템**: 특정 목적에 맞도록 **입력 신호를 처리하여 출력 신호를 만들어내는 장치**

- 수학적으로는 **일련의 방정식** (함수)으로 표현
- 하드웨어 그 자체가 아니라 **수식으로 표현된 함수**라고 이해

### RC 회로 예시 (전달함수 유도)

입력: $v_s(t) = A\cos(\omega t + \theta)$, 출력: $v_C(t)$

주파수 영역에서 전압 분배 법칙 적용:

$$H(j\omega) = \frac{V_C(j\omega)}{V_s(j\omega)} = \frac{\frac{1}{j\omega C}}{R + \frac{1}{j\omega C}} = \frac{1}{1 + j\omega RC}$$

**이득(Gain)**: 절댓값 취하면

$$|H(j\omega)| = \frac{1}{\sqrt{1 + (\omega RC)^2}}$$

## 4. 독립변수의 변환

신호 $x(t)$ 또는 $x[n]$에 대해 세 가지 변환이 존재.

### 4-1. 시간 이동 (Time Shift)

$$x(t) \rightarrow x(t - t_0)$$

| $t_0 > 0$ | $t_0 < 0$ |
|-----------|-----------|
| **오른쪽** 이동 (지연, Delay) | **왼쪽** 이동 (전진, Advance) |

> **기억법**: 괄호 안이 $t - t_0$이면, $t_0$만큼 **오른쪽** (양수 = 지연)

### 4-2. 시간 반전 (Time Reversal)

$$x(t) \rightarrow x(-t)$$

- $y$ 축(세로축)을 기준으로 신호를 **좌우 대칭 (flip)**
- $t$ 대신 $-t$를 넣어 전체를 뒤집음

### 4-3. 시간 스케일링 (Time Scaling)

$$x(t) \rightarrow x(at), \quad a > 0$$

| 조건 | 효과 |
|------|------|
| $a > 1$ | 시간 축 **압축** (빠르게 재생) |
| $0 < a < 1$ | 시간 축 **팽창** (느리게 재생) |
| $a = -1$ | 시간 반전과 동일 |

> **직관**: 2배속 재생 → $x(2t)$ → 시간 압축  
> 0.5배속 재생 → $x(0.5t)$ → 시간 팽창

### 4-4. 복합 변환 순서 — 중요!

$x(at + b)$ 형태에서 변환 순서:

**방법 (권장)**: 공통 인수 $a$로 묶어서 파악

$$x(at + b) = x\!\left(a\!\left(t + \frac{b}{a}\right)\right)$$

→ ① 시간 스케일링 $a$ 적용 후 ② $\frac{b}{a}$만큼 이동 (또는 반대 순서도 가능하나 혼동 주의)

### 4-5. 예제 정리

기본 신호 $x(t)$가 주어졌을 때:

| 변환 | 해석 |
|------|------|
| $x(t+1)$ | 왼쪽으로 1 이동 |
| $x(-t+1) = x(-(t-1))$ | 반전 후 오른쪽으로 1 이동 |
| $x(3t)$ | 시간 압축 (1/3로 줄어듦) |
| $x\!\left(\frac{3}{2}t + 1\right)$ | $\frac{3}{2}$ 압축 후 왼쪽으로 $\frac{2}{3}$ 이동 |

## 5. 주기 신호 vs 비주기 신호

### 5-1. 정의

**연속시간 주기 신호**: 모든 $t$에 대해

$$x(t) = x(t + T), \quad \exists\, T > 0$$

**이산시간 주기 신호**: 모든 $n$에 대해

$$x[n] = x[n + N], \quad \exists\, N \in \mathbb{Z}^+$$

> **⚠️ 중요 차이**:  
> - 연속시간: $T$는 양수 실수면 OK  
> - 이산시간: $N$은 반드시 **양의 정수**여야 함!

### 5-2. 기본 주기 (Fundamental Period)

- **$T_0$** (연속시간): 주기 중 **가장 작은 양수** 값
- **$N_0$** (이산시간): 주기 중 **가장 작은 양의 정수** 값
- 영어: **Fundamental Period**

$$x(t) = x(t + T_0) = x(t + 2T_0) = x(t + 3T_0) = \cdots$$

### 5-3. 주기 신호 판별 예제

$x(t) = \cos(2t) \cdot u(t)$ 는 주기 신호인가?

- $t < 0$ 구간: $u(t) = 0$ → 신호 없음
- $t \geq 0$ 구간: $\cos(2t)$
- **전체 시간**에 대해 반복되지 않음 → **비주기 신호**

> 주기 신호는 **모든 시간 $t$** (또는 $n$)에 대해 조건이 성립해야 함

### 5-4. 푸리에 변환과의 연결

```
시간 영역               주파수 영역
─────────────────────────────────────
주기 신호  ←→  푸리에 급수 (Fourier Series)
비주기 신호 ←→  푸리에 변환 (Fourier Transform)
```

## 6. 에너지와 파워

신호를 **정량적으로 표현**하기 위해 사용.

### 6-1. 에너지 (Energy)

**연속시간**:

$$E = \int_{-\infty}^{\infty} |x(t)|^2 \, dt$$

**이산시간**:

$$E = \sum_{n=-\infty}^{\infty} |x[n]|^2$$

- 유한할 수도, 무한할 수도 있음

### 6-2. 평균 전력 (Average Power)

에너지가 무한할 때 → 평균 전력으로 대신 사용

**연속시간**:

$$P = \lim_{T \to \infty} \frac{1}{2T} \int_{-T}^{T} |x(t)|^2 \, dt$$

**이산시간**:

$$P = \lim_{N \to \infty} \frac{1}{2N+1} \sum_{n=-N}^{N} |x[n]|^2$$

### 6-3. 에너지 신호 vs 파워 신호

| 구분 | 조건 | 특징 |
|------|------|------|
| **에너지 신호** | $E < \infty$ | $P = 0$ |
| **파워 신호** | $P < \infty$ (유한, $\neq 0$) | $E = \infty$ |
| 의미 없는 경우 | $E = \infty$, $P = \infty$ | 분석 불가 |

> **관계**: $E$가 유한하면 $P = 0$, $P$가 유한·비영이면 $E = \infty$  
> (둘 다 유한·비영인 경우는 없음)

## 7. 시스템의 연결 형태

### 7-1. 종속(직렬) 연결 (Cascade / Series)

```
x(t) → [H₁] → [H₂] → y(t)
```

첫 번째 시스템의 출력이 두 번째 시스템의 입력.

### 7-2. 병렬 연결 (Parallel)

```
        ┌→ [H₁] →┐
x(t) ──→┤         ├──→ y(t)
        └→ [H₂] →┘ (+)
```

두 시스템에 동일한 입력, 출력을 합산.

### 7-3. 피드백 연결 (Feedback)

```
x(t) ──→ (+) ──→ [H₁] ──→ y(t)
          ↑                  │
          └──── [H₂] ────────┘
```

출력의 일부가 다시 입력으로 돌아오는 구조.

## 8. 신호 처리의 종류

| 종류 | 의미 | 예시 |
|------|------|------|
| **해석** | 신호에서 원하는 정보 추출·표현 | 심전도에서 심박수 추출 |
| **합성** | 원하는 출력 신호 생성 | TTS(음성 합성) |
| **변환** | 신호의 물리적 형태 변환 | 마이크: 음파 → 전기 신호 |
| **필터링** | 원치 않는 성분 제거 또는 강조 | 잡음 제거, 저역통과필터 |

## 9. 핵심 요약 & 시험 포인트

### ✅ 반드시 외울 것

1. **괄호 구분**: $x(t)$ = 연속시간, $x[n]$ = 이산시간
2. **이산시간 주기**: $N$은 반드시 **양의 정수**
3. **시간 이동 방향**: $x(t - t_0)$에서 $t_0 > 0$이면 **오른쪽** 이동
4. **스케일링**: $|a| > 1$ → 압축, $0 < |a| < 1$ → 팽창
5. **에너지 신호**: $E < \infty$ → $P = 0$
6. **파워 신호**: $P$가 유한·비영 → $E = \infty$

### ✅ 자주 틀리는 포인트

- $x(t+1)$: **왼쪽** 이동 (플러스 = 앞당김)
- $x(-t+1)$을 볼 때: $x(-(t-1))$로 묶어서 → 반전 후 오른쪽 1 이동
- 이산시간 신호의 주기 $N$: 실수나 소수면 **주기 신호 아님**

### ✅ 다음 시간 예고 (1.3절~)

- 임펄스 함수 $\delta(t)$, 단위 계단 함수 $u(t)$
- 지수 신호, 정현파 신호
- 시스템의 기본 성질 (선형성, 시불변성, 인과성, 안정성)
