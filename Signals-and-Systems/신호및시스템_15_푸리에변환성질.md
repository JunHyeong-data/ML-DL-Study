## 1. 주기 신호의 푸리에 변환

### 주기 신호에 CTFT를 적용할 수 있나?

- **비주기 신호**: CTFT 직접 적용 가능
- **주기 신호**: 에너지가 무한 → 수렴 조건 불만족 → 일반적으로 CTFT 존재 불가

그런데 **임펄스 함수 $\delta(\omega)$를 허용**하면 주기 신호에도 CTFT를 정의할 수 있다.

> **결론**: 주기 신호의 CTFT는 주파수 영역에서 **임펄스 함수**를 포함한다.

### 상수 함수 $x(t) = 1$의 CTFT

주파수 스펙트럼 $X(j\omega) = 2\pi\,\delta(\omega)$가 주어졌다고 하자. 역변환을 적용하면:

$$x(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} 2\pi\,\delta(\omega)\, e^{j\omega t}\, d\omega$$

$\delta(\omega)$는 $\omega = 0$에서만 값을 가지므로:

$$x(t) = e^{j \cdot 0 \cdot t} = 1$$

$$\boxed{1 \xleftrightarrow{\mathcal{F}} 2\pi\,\delta(\omega)}$$

### 복소 지수 $e^{j\omega_0 t}$의 CTFT

같은 방법으로:

$$X(j\omega) = 2\pi\,\delta(\omega - \omega_0)$$

$$\boxed{e^{j\omega_0 t} \xleftrightarrow{\mathcal{F}} 2\pi\,\delta(\omega - \omega_0)}$$

모든 에너지가 $\omega = \omega_0$에 집중된 형태 → 단일 주파수를 가진 신호의 특성.

### 일반 주기 신호의 CTFT

CTFS로 표현된 주기 신호:

$$x(t) = \sum_{k=-\infty}^{\infty} a_k\, e^{jk\omega_0 t}$$

CTFT 적용 (선형성 이용):

$$X(j\omega) = \sum_{k=-\infty}^{\infty} 2\pi\, a_k\, \delta(\omega - k\omega_0)$$

> 주기 신호의 CTFT = CTFS 계수 $a_k$에 비례하는 **임펄스 열**

주파수 스펙트럼은 $\omega_0$의 정수 배마다 값을 가지며, 그 크기는 $a_k$에 비례한다.

## 2. 예제 4.6 — CTFS 계수로부터 CTFT 구하기

### 문제

CTFS 계수 $a_k$가 주어진 주기 신호 $x(t)$의 CTFT를 구하라.

### 풀이

위에서 유도한 공식 적용:

$$X(j\omega) = 2\pi \sum_{k=-\infty}^{\infty} a_k\, \delta(\omega - k\omega_0)$$

- 스펙트럼 모양: CTFS 계수를 포락선(envelope)으로 갖는 **임펄스 열**
- 비주기 신호의 연속 스펙트럼에서 $\omega_0$ 간격으로 샘플링한 형태

### 그래프 해석

| | 비주기 신호 | 주기 신호 |
|--|-----------|---------|
| CTFT | 연속 스펙트럼 $X(j\omega)$ | 임펄스 열 |
| 간격 | 연속 | $\omega_0$ 마다 |
| 비유 | 원래 포락선 | 포락선을 샘플링한 것 |

## 3. 예제 4.7 — 코사인/사인 함수의 CTFT

### 핵심 변환 쌍 (암기 필수)

$$e^{j\omega_0 t} \xleftrightarrow{\mathcal{F}} 2\pi\,\delta(\omega - \omega_0)$$

$$e^{-j\omega_0 t} \xleftrightarrow{\mathcal{F}} 2\pi\,\delta(\omega + \omega_0)$$

### 코사인 함수의 CTFT

오일러 공식으로 분해:

$$\cos(\omega_0 t) = \frac{1}{2} e^{j\omega_0 t} + \frac{1}{2} e^{-j\omega_0 t}$$

각 항에 CTFT 적용:

$$\boxed{\cos(\omega_0 t) \xleftrightarrow{\mathcal{F}} \pi\,\delta(\omega - \omega_0) + \pi\,\delta(\omega + \omega_0)}$$

### 사인 함수의 CTFT

$$\sin(\omega_0 t) = \frac{1}{2j} e^{j\omega_0 t} - \frac{1}{2j} e^{-j\omega_0 t}$$

$$\boxed{\sin(\omega_0 t) \xleftrightarrow{\mathcal{F}} \frac{\pi}{j}\,\delta(\omega - \omega_0) - \frac{\pi}{j}\,\delta(\omega + \omega_0)}$$

### 그래프 해석

코사인의 CTFT: $\omega = \pm\omega_0$ 두 점에서만 크기 $\pi$인 임펄스

| 주파수 $\omega$ | 값 |
|--------------|---|
| $+\omega_0$ | $\pi$ |
| $-\omega_0$ | $\pi$ |
| 그 외 | 0 |

## 4. 성질 1: 선형성 (Linearity)

### 내용

$$x(t) \xleftrightarrow{\mathcal{F}} X(j\omega), \quad y(t) \xleftrightarrow{\mathcal{F}} Y(j\omega)$$

$$\alpha x(t) + \beta y(t) \xleftrightarrow{\mathcal{F}} \alpha X(j\omega) + \beta Y(j\omega)$$

### 성립 이유

CTFT는 적분 연산이고, **적분은 선형(linear) 연산**이기 때문에 자동으로 성립.

$$\int_{-\infty}^{\infty} [\alpha x(t) + \beta y(t)]\, e^{-j\omega t}\, dt = \alpha \int_{-\infty}^{\infty} x(t)\, e^{-j\omega t}\, dt + \beta \int_{-\infty}^{\infty} y(t)\, e^{-j\omega t}\, dt$$

## 5. 성질 2: 시간 이동 (Time Shifting)

### 내용

$$x(t - t_0) \xleftrightarrow{\mathcal{F}} e^{-j\omega t_0} X(j\omega)$$

### 유도

$$\mathcal{F}\{x(t - t_0)\} = \int_{-\infty}^{\infty} x(t - t_0)\, e^{-j\omega t}\, dt$$

$\tau = t - t_0$ 치환:

$$= \int_{-\infty}^{\infty} x(\tau)\, e^{-j\omega(\tau + t_0)}\, d\tau = e^{-j\omega t_0} \int_{-\infty}^{\infty} x(\tau)\, e^{-j\omega\tau}\, d\tau = e^{-j\omega t_0} X(j\omega)$$

### 핵심 결론 ⭐

$$|e^{-j\omega t_0}| = 1 \quad \Rightarrow \quad |X(j\omega)| \text{ 불변}$$

$$\angle \left[e^{-j\omega t_0} X(j\omega)\right] = \angle X(j\omega) - \omega t_0$$

- **크기 스펙트럼**: 변화 없음
- **위상 스펙트럼**: $-\omega t_0$만큼 선형적으로 변화 (주파수에 비례)

> $t_0$는 고정값 → 위상 변화가 $\omega$에 **선형 비례**

## 6. 예제 4.9 — 선형성 + 시간 이동 활용

### 문제

아래와 같이 생긴 신호 $x(t)$의 CTFT를 구하라.

$$x(t) = x_1(t - 2.5) + x_2(t - 2.5)$$

- $x_1(t)$: $-\frac{1}{2} \leq t \leq \frac{1}{2}$에서 1인 스퀘어 웨이브 (폭 $= 1$, $t_1 = \frac{1}{2}$)
- $x_2(t)$: $-\frac{3}{2} \leq t \leq \frac{3}{2}$에서 1인 스퀘어 웨이브 (폭 $= 3$, $t_1 = \frac{3}{2}$)
- 두 신호를 합한 후 오른쪽으로 $\frac{5}{2}$ 이동

### 스퀘어 웨이브의 CTFT (암기 필수)

$$x_{\square}(t) = \begin{cases} 1 & |t| \leq t_1 \\ 0 & |t| > t_1 \end{cases} \quad \xleftrightarrow{\mathcal{F}} \quad \frac{2\sin(\omega t_1)}{\omega}$$

### 풀이

**Step 1**: 각 신호의 CTFT

$$X_1(j\omega) = \frac{2\sin(\omega \cdot \frac{1}{2})}{\omega}$$

$$X_2(j\omega) = \frac{2\sin(\omega \cdot \frac{3}{2})}{\omega}$$

**Step 2**: 합산 (선형성)

$$[X_1 + X_2](j\omega) = \frac{2\sin(\frac{\omega}{2})}{\omega} + \frac{2\sin(\frac{3\omega}{2})}{\omega}$$

**Step 3**: 시간 이동 $t_0 = \frac{5}{2}$ 적용

$$X(j\omega) = e^{-j\omega \cdot \frac{5}{2}} \cdot \frac{2}{\omega}\!\left[\sin\!\left(\frac{\omega}{2}\right) + \sin\!\left(\frac{3\omega}{2}\right)\right]$$

## 7. 성질 3: 켤레 대칭 (Conjugate Symmetry)

### 기본 성질

$$x^{\ast}(t) \xleftrightarrow{\mathcal{F}} X^{\ast}(-j\omega)$$

복소수 $a + jb$의 켤레복소수는 $a - jb$이므로, CTFT에서 $j$를 $-j$로 바꾸면 됨.

### 실수 신호의 켤레 대칭

$x(t)$가 실수이면 $x(t) = x^{\ast}(t)$이므로:

$$\boxed{X(-j\omega) = X^{\ast}(j\omega)} \quad \text{(실수 신호 조건)}$$

$$|X(-j\omega)| = |X(j\omega)|, \quad \angle X(-j\omega) = -\angle X(j\omega)$$

- 크기 스펙트럼: **우함수(even)**
- 위상 스펙트럼: **기함수(odd)**

### 우함수 신호의 성질

$x(t) = x(-t)$ (우함수)이면, $X(j\omega)$는 **실수**:

$$x(t) \text{ 실수 + 우함수} \quad \Rightarrow \quad X(j\omega) \in \mathbb{R}$$

### 기함수 신호의 성질

$x(t) = -x(-t)$ (기함수)이면, $X(j\omega)$는 **순허수**:

$$x(t) \text{ 실수 + 기함수} \quad \Rightarrow \quad X(j\omega) \in j\mathbb{R}$$

### 실수 신호 분해: 우함수 + 기함수 파트

임의의 실수 신호 $x(t)$를 분해:

$$x(t) = \underbrace{x_e(t)}_{\text{우함수 파트}} + \underbrace{x_o(t)}_{\text{기함수 파트}}$$

$$x_e(t) = \frac{x(t) + x(-t)}{2}, \quad x_o(t) = \frac{x(t) - x(-t)}{2}$$

CTFT와의 관계:

$$x_e(t) \xleftrightarrow{\mathcal{F}} \text{Re}\{X(j\omega)\}$$

$$x_o(t) \xleftrightarrow{\mathcal{F}} j\,\text{Im}\{X(j\omega)\}$$

> $x_o(t)$의 CTFT는 **허수부에 $j$가 붙은 형태** — 부호 주의!

### 정리표 (문제풀이에 유용) ⭐

| $x(t)$ 조건 | $X(j\omega)$ 특성 |
|------------|-----------------|
| 실수 | $X(-j\omega) = X^{\ast}(j\omega)$ |
| 실수 + 우함수 | **실수** |
| 실수 + 기함수 | **순허수** |
| 우함수 | $X(-j\omega) = X(j\omega)$ |

## 8. 성질 4: 미분과 적분

### 미분 성질

$$\frac{d}{dt}x(t) \xleftrightarrow{\mathcal{F}} j\omega \cdot X(j\omega)$$

**유도**: 역변환 $x(t) = \frac{1}{2\pi}\int X(j\omega) e^{j\omega t}\, d\omega$를 $t$로 미분하면:

$$\frac{d}{dt}x(t) = \frac{1}{2\pi}\int j\omega\, X(j\omega)\, e^{j\omega t}\, d\omega$$

즉 $j\omega\, X(j\omega)$가 미분된 신호의 CTFT.

### 미분의 효과

| $k$차 미분 | CTFT |
|----------|------|
| $\frac{d^n}{dt^n}x(t)$ | $(j\omega)^n X(j\omega)$ |

고주파($\omega$가 큰) 성분이 강조 → **하이패스 효과**

### 적분 성질

$$\int_{-\infty}^{t} x(\tau)\, d\tau \xleftrightarrow{\mathcal{F}} \frac{1}{j\omega} X(j\omega) + \pi X(0)\,\delta(\omega)$$

두 번째 항 $\pi X(0)\,\delta(\omega)$: DC 성분($\omega = 0$) 처리

- $X(0) = \int_{-\infty}^{\infty} x(t)\, dt$ (신호의 총 면적)
- DC 성분이 있으면 반드시 $\delta(\omega)$ 항 포함

## 9. 예제 4.11 — 단위 계단 함수의 CTFT

### 문제

$$x(t) = u(t) \xleftrightarrow{\mathcal{F}} ?$$

### 풀이 전략

임펄스와 계단의 관계:

$$\frac{d}{dt}u(t) = \delta(t)$$

따라서 $u(t)$는 $\delta(t)$의 적분:

$$u(t) = \int_{-\infty}^{t} \delta(\tau)\, d\tau$$

적분 성질 적용. $\delta(t)$의 CTFT = 1이므로, $X(j\omega) = 1$, $X(0) = 1$:

$$\boxed{U(j\omega) = \frac{1}{j\omega} + \pi\,\delta(\omega)}$$

- $\frac{1}{j\omega}$: 주파수 도메인에서의 적분 효과
- $\pi\,\delta(\omega)$: DC 성분 ($u(t)$의 평균값이 $\frac{1}{2}$이므로)

## 10. 성질 5: 시간 스케일링 (Time Scaling)

### 내용

$$x(at) \xleftrightarrow{\mathcal{F}} \frac{1}{|a|} X\!\left(\frac{j\omega}{a}\right)$$

### 핵심 결론 ⭐

| 시간 영역 | 주파수 영역 |
|---------|-----------|
| 압축 ($|a| > 1$) | **신장** (+ $\frac{1}{|a|}$ 스케일) |
| 신장 ($|a| < 1$) | **압축** (+ $\frac{1}{|a|}$ 스케일) |

> 넓이 보존: 시간 영역에서 압축 → 높이는 줄어들고 주파수 범위는 넓어짐

### 직관적 예시

**빠른 재생 (시간 압축, $a > 1$)**:
- 신호가 짧아짐 → 고주파 성분 증가
- 음성이 높아짐 (톤 상승)

**느린 재생 (시간 신장, $a < 1$)**:
- 신호가 길어짐 → 저주파 성분만 남음
- 음성이 낮아짐 (톤 하강)

## 11. 성질 6: 쌍대성 (Duality)

### 개념

CTFT와 역변환의 수식이 $\pm j$와 $2\pi$ 스케일만 다르고 구조가 유사하다. 따라서 타임-주파수 관계가 **대칭적**으로 성립한다.

### 쌍대성 정리

$$x(t) \xleftrightarrow{\mathcal{F}} X(j\omega) \quad \Rightarrow \quad X(jt) \xleftrightarrow{\mathcal{F}} 2\pi\, x(-\omega)$$

### 주요 쌍대 쌍

| 타임 도메인 | 주파수 도메인 |
|-----------|------------|
| $\delta(t)$ | $1$ |
| $1$ | $2\pi\,\delta(\omega)$ |
| rect (스퀘어 웨이브) | Sinc 함수 |
| Sinc 함수 | rect (스퀘어 웨이브) |

### 실용적 의미

하나의 변환 쌍을 알면 그 반대 방향도 예측 가능.

예: $\delta(t) \to 1$을 알면 → $1 \to 2\pi\,\delta(\omega)$ 유추 가능

> 쌍대성은 직접 많이 쓰기보다는 **다른 성질들을 통해 문제를 풀고**, 결과의 일관성을 확인할 때 유용하다.

## 12. 성질 7: 파스발 정리 (Parseval's Theorem)

### 내용 ⭐

$$\int_{-\infty}^{\infty} |x(t)|^2\, dt = \frac{1}{2\pi} \int_{-\infty}^{\infty} |X(j\omega)|^2\, d\omega$$

### 의미

**에너지 보존**: 시간 영역의 에너지 = 주파수 영역의 에너지

| 영역 | 에너지 표현 |
|------|-----------|
| 시간 | $\int_{-\infty}^{\infty} \|x(t)\|^2\, dt$ |
| 주파수 | $\frac{1}{2\pi}\int_{-\infty}^{\infty} \|X(j\omega)\|^2\, d\omega$ |

### 증명 스케치

$$\int |x(t)|^2\, dt = \int x(t) \cdot x^{\ast}(t)\, dt$$

$x^{\ast}(t)$를 역변환으로 표현 후 적분 순서 교환:

$$= \frac{1}{2\pi} \int |X(j\omega)|^2\, d\omega$$

### 활용

- 시간 영역에서 에너지 계산이 쉬우면 → 시간 영역에서 계산
- 주파수 영역에서 에너지 계산이 쉬우면 → 주파수 영역에서 계산
- 둘의 결과가 같음을 이용해 검증 가능

## 13. 핵심 요약 & 시험 포인트

### 반드시 암기할 변환 쌍

| $x(t)$ | $X(j\omega)$ |
|--------|-------------|
| $\delta(t)$ | $1$ |
| $1$ | $2\pi\,\delta(\omega)$ |
| $e^{j\omega_0 t}$ | $2\pi\,\delta(\omega - \omega_0)$ |
| $\cos(\omega_0 t)$ | $\pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]$ |
| $\sin(\omega_0 t)$ | $\frac{\pi}{j}[\delta(\omega-\omega_0)-\delta(\omega+\omega_0)]$ |
| $u(t)$ | $\frac{1}{j\omega} + \pi\,\delta(\omega)$ |

### CTFT 성질 한눈에 정리

| 성질 | 시간 영역 | 주파수 영역 |
|------|---------|-----------|
| 선형성 | $\alpha x(t) + \beta y(t)$ | $\alpha X + \beta Y$ |
| 시간 이동 | $x(t - t_0)$ | $e^{-j\omega t_0} X(j\omega)$ (크기 불변) |
| 켤레 | $x^{\ast}(t)$ | $X^{\ast}(-j\omega)$ |
| 실수 신호 | $x(t) = x^{\ast}(t)$ | $X(-j\omega) = X^{\ast}(j\omega)$ |
| 미분 | $\frac{d}{dt}x(t)$ | $j\omega\, X(j\omega)$ |
| 적분 | $\int_{-\infty}^{t}$ | $\frac{1}{j\omega}X + \pi X(0)\delta(\omega)$ |
| 스케일링 | $x(at)$ | $\frac{1}{\|a\|}X\!\left(\frac{j\omega}{a}\right)$ |
| 쌍대성 | $X(jt)$ | $2\pi\, x(-\omega)$ |
| 파스발 | $\int\|x\|^2\, dt$ | $= \frac{1}{2\pi}\int\|X\|^2\, d\omega$ |

### 자주 틀리는 포인트

- 시간 이동: **크기 불변, 위상만** $-\omega t_0$만큼 변화
- 주기 신호의 CTFT: 임펄스 함수 포함 → $2\pi a_k\,\delta(\omega - k\omega_0)$
- 적분 성질: DC 성분 $\pi X(0)\,\delta(\omega)$ 항 **빠뜨리지 말 것**
- 켤레 대칭: 실수 + 우함수 → $X(j\omega)$ 실수 / 실수 + 기함수 → $X(j\omega)$ 순허수
- 기함수 파트 변환: $j\,\text{Im}\{X(j\omega)\}$ — **앞에 $j$ 붙는 것** 주의
- 스케일링: 시간 압축 → 주파수 신장 + $\frac{1}{|a|}$ 크기 감소 (넓이 보존)
- 파스발: 주파수 영역 적분에 $\frac{1}{2\pi}$ 붙임
