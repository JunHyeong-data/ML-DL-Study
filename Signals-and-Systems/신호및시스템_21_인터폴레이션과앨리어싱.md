## 1. 지난 강의 복습

### 20강에서 배운 것

| 개념 | 핵심 내용 |
|------|---------|
| 샘플링 모델 | $x_p(t) = x(t) \cdot p(t)$, 임펄스 트레인 곱 |
| 스펙트럼 결과 | $X_p(j\omega) = \frac{1}{T}\sum_{k} X(j(\omega - k\omega_s))$ |
| 나이퀴스트 정리 | $\omega_s > 2\omega_M$ 이어야 복원 가능 |
| 이상적 복원 | 아이디얼 LPF (컷오프 $\omega_c = \omega_s/2$) |
| 실제 구현 | ZOH (Zero-Order Hold) — 샘플값을 $T$동안 유지 |

### 이번 강의에서 다룰 것

샘플링된 신호를 다시 **연속시간 신호로 복원**하는 방법 (인터폴레이션)과, 샘플링이 부족할 때 생기는 **앨리어싱** 현상을 수학적으로 분석한다.

> **컷오프 주파수 약속**: 이번 강의부터 특별한 언급 없으면
> $$\omega_c = \frac{\omega_s}{2}$$
> 로 고정한다.

## 2. 인터폴레이션이란?

### 정의

샘플링된 이산값들을 이용해 **연속시간 신호를 재구성**하는 과정.

```
샘플링된 값:    •       •       •       •
                |       |       |       |
               x(0)   x(T)   x(2T)   x(3T)

인터폴레이션:  연속 곡선으로 복원 → xᵣ(t)
```

### 방법 비교

| 방법 | 사용 점 수 | 특징 |
|------|---------|------|
| ZOH (0차 홀드) | 1개 | 계단 모양, 구현 가장 쉬움 |
| 선형 인터폴레이션 (1차 홀드) | 2개 | 직선 연결, 미분 불가 |
| Ideal LPF (Sinc) | $\infty$개 | 이상적, 현실 구현 불가 |
| Windowed Sinc | 유한 개 | 실용적 근사 |

## 3. 선형 인터폴레이션 (Linear / First-Order Hold)

### 개념

인접한 두 샘플값을 **직선으로 연결**하여 사이 값을 추정.

```
x(t):                  xᵣ(t) (선형 인터폴레이션):
  •           •           •---------•
  |           |          /           \
  |           |         /             \
  •           •        •               •
  0     T    2T   →    0       T      2T
```

### ZOH와의 차이

| | ZOH (0차) | 선형 인터폴레이션 (1차) |
|--|----------|-------------------|
| 필요한 점 수 | 1개 | 2개 |
| 연속성 | 불연속 (계단) | 연속 |
| 미분 가능성 | ❌ | ❌ (기울기 불연속) |
| 정확도 | 낮음 | 중간 |

### 임펄스 응답 (삼각형 펄스)

하나의 임펄스만 있는 경우 ($t=0$에 임펄스, $t=-T$와 $t=T$에서 이웃값 = 0):

$$h_{FOH}(t) = \begin{cases} 1 - \dfrac{|t|}{T} & |t| \leq T \\ 0 & |t| > T \end{cases}$$

```
h_FOH(t):
    1
   /\
  /  \
 /    \
/      \
-T  0   T → t
```

주변 이웃 샘플값이 0이므로 자기 자신 쪽으로 직선을 그었을 때 이 삼각형 모양이 됨.

### 주파수 응답

$$H_{FOH}(j\omega) = T \cdot \left(\frac{\sin(\omega T/2)}{\omega T/2}\right)^2$$

ZOH의 sinc보다 감쇠가 더 강함 → **아이디얼 LPF에 더 가까움** (ZOH보다 정확).

## 4. 이상적 인터폴레이션 — Ideal LPF (Sinc)

### 아이디얼 LPF의 주파수 응답

$$H(j\omega) = \begin{cases} T & |\omega| \leq \omega_c \\ 0 & |\omega| > \omega_c \end{cases}, \quad \omega_c = \frac{\omega_s}{2}$$

### 임펄스 응답: Sinc 함수

$$h(t) = \frac{\sin(\omega_c t)}{\pi t} = \frac{\omega_c}{\pi} \cdot \text{sinc}\!\left(\frac{\omega_c t}{\pi}\right)$$

```
h(t) = sin(ω_c t) / (πt):
         1/T
          |
    .  . /|\ .  .
   . . / | \ . .
---.--/--|--\---.---
  . /   |   \ .
 . /    |    \.
-T      0      T  2T → t
(사이드로브가 양쪽으로 무한히 뻗어있음)
```

### 복원 수식

$$x_r(t) = \sum_{n=-\infty}^{\infty} x(nT) \cdot \frac{\sin(\omega_c(t - nT))}{\pi(t - nT)}$$

각 샘플값 $x(nT)$를 sinc 함수로 확장하여 **모두 더한 것**.

### Sinc 함수의 핵심 성질

**① $t = 0$에서의 값 (L'Hôpital 적용)**:

$$h(0) = \lim_{t \to 0} \frac{\sin(\omega_c t)}{\pi t} = \frac{\omega_c}{\pi} = \frac{\omega_s/2}{\pi} = \frac{1}{T}$$

$T$를 곱하면 1 → 자기 샘플 위치에서 정확히 원래 값 유지 ✓

**② $t = kT$ ($k \neq 0$)에서의 값**:

$$h(kT) = \frac{\sin(\omega_c \cdot kT)}{\pi \cdot kT} = \frac{\sin(k\pi)}{k\pi T} = 0$$

다른 샘플 위치에서 0 → 샘플 간 상호 간섭 없음 ✓

| 위치 | Sinc 값 | 의미 |
|------|---------|------|
| 자기 샘플 위치 $t = nT$ | $\frac{1}{T}$ | 원래 샘플값 그대로 |
| 다른 샘플 위치 $t = kT, k\neq n$ | $0$ | 간섭 없음 |
| 샘플 사이 임의 위치 | 가중합 | 인접 샘플일수록 가중치 큼 |

### 직관적 이해

```
x(0)에 해당하는 sinc:         x(T)에 해당하는 sinc:
       ↑ x(0)/T                         ↑ x(T)/T
    . /|\ .                          . /|\ .
  ./  | \.                         ./  | \.
-/---|--\---T---2T    +    -T------/---|--\---2T
      0                                  T
        ↓ 둘을 더하면 ↓
각 샘플 위치에서는 자기 값만 살아있고, 사이는 자연스럽게 보간됨
```

### 아이디얼 LPF의 한계

| 문제 | 원인 |
|------|------|
| 비인과 (non-causal) | $h(t)$가 $t < 0$에서도 존재 → 미래 정보 필요 |
| 계산량 무한대 | $-\infty$부터 $+\infty$까지 모든 샘플 사용 |
| 하드웨어 구현 불가 | 완벽한 구형파 주파수 응답 실제 불가 |

## 5. Windowed Sinc — 실용적 근사

### 아이디어

Sinc 함수는 멀어질수록 값이 작아짐 → **가까운 샘플만 사용**해도 충분히 정확.

```
h(t) 크기:
메인로브:       ████████
1st 사이드로브:   ██  ██      ← 여기까지만 사용
2nd 사이드로브:  █      █    ← 버림
3rd 사이드로브: █        █   ← 버림
```

### Windowed Sinc 정의

$$h_w(t) = h(t) \cdot w(t)$$

- $w(t)$: 윈도우 함수 (특정 구간 밖은 0)
- 유한 구간의 샘플만 사용 → 계산량 대폭 감소
- 완벽하진 않지만 실용적으로 충분

### 인터폴레이션 방법 최종 비교

```
정확도 ↑
   │  Ideal LPF (Sinc)   ← 이론적 최선, 구현 불가
   │  Windowed Sinc       ← 실용적 선택
   │  FOH (선형)           ← 간단하고 무난
   │  ZOH                 ← 가장 단순
정확도 ↓
```

샘플링 주파수 $\omega_s$를 충분히 높이면 → **어떤 방법이든 에러 감소**.  
단, 샘플링을 촘촘하게 하는 것 자체가 데이터 양 증가 → 샘플링 목적에 반하는 트레이드오프.

## 6. 앨리어싱 (Aliasing)

### 정의

나이퀴스트 조건 $\omega_s > 2\omega_M$을 **위반**했을 때, 복원된 신호가 원래 신호와 달라지는 현상.

### 일상 예시: 헬리콥터 영상

```
헬리콥터 프로펠러 회전:    → 프로펠러 주파수 = f₀
카메라 촬영:               → 샘플링 주파수 = fₛ

만약 fₛ = f₀ 이면:
찍는 순간마다 프로펠러가 같은 위치 → 정지한 것처럼 보임!
```

이것이 앨리어싱. 실제로는 회전하는데 정지한 것으로 **잘못 복원**되는 것.

### 앨리어싱의 타임 도메인 분석

신호: $x(t) = \cos(\omega_0 t)$, 샘플링 주파수: $\omega_s$

| 케이스 | $\omega_0$와 $\omega_s$ 관계 | 한 주기 내 샘플 수 | 나이퀴스트 만족? |
|--------|--------------------------|----------------|--------------|
| (a) | $\omega_0 = \frac{\omega_s}{6}$ | 6번 | ✅ |
| (b) | $\omega_0 = \frac{2\omega_s}{6}$ | 3번 | ✅ |
| (c) | $\omega_0 = \frac{4\omega_s}{6}$ | 1.5번 | ❌ |
| (d) | $\omega_0 = \frac{5\omega_s}{6}$ | 1.2번 | ❌ |
| (e) | $\omega_0 = \omega_s$ | 1번 | ❌ (헬기 예시) |

**케이스 (a), (b)**: 샘플값을 부드럽게 이으면 → 원래 신호 복원 ✓

**케이스 (c), (d)**: 샘플값을 부드럽게 이으면 → **다른 주파수의 신호로 복원** ❌

흥미로운 점: 케이스 (b)와 (c)의 복원 신호가 **동일**하게 나옴.  
→ 완전히 다른 주파수의 두 신호가 같은 샘플값을 가짐 = 앨리어싱

## 7. 앨리어싱의 주파수 영역 분석

### 스펙트럼에서 보이는 앨리어싱

$x(t) = \cos(\omega_0 t)$의 CTFT:

$$X(j\omega) = \pi[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]$$

샘플링 후 스펙트럼: $X_p(j\omega) = \frac{1}{T}\sum_k X(j(\omega - k\omega_s))$

**나이퀴스트 만족 시** (케이스 a):

```
Xₚ(jω):
   ↑         ↑             ↑         ↑
   |         |             |         |
-ωs  -ω₀   ω₀    ωs     → ω

LPF 적용 후:   ↑         ↑
               -ω₀      ω₀   → 원래 신호 복원 ✓
```

**나이퀴스트 위반 시** (케이스 c, $\omega_0 = \frac{4\omega_s}{6}$):

```
Xₚ(jω): ω_s를 기준으로 반복 시 겹침 발생
   ↑             ↑   ↑
   |             |   |     ← 겹침!
-ωs   -ω₀      ω₀  ωs  → ω

           ↑↑↑ 여기서 ωs - ω₀ 위치에 원치 않는 성분 추가
```

복원된 신호의 주파수:

$$\omega_0' = \omega_s - \omega_0 \quad \text{(aliased frequency)}$$

케이스 (c): $\omega_0' = \omega_s - \frac{4\omega_s}{6} = \frac{2\omega_s}{6}$ → 케이스 (b)의 주파수와 동일!

이것이 **두 신호가 같은 샘플값을 갖는 이유**.

### 앨리어싱 정리

$$\boxed{\omega_{\text{aliased}} = \omega_s - \omega_0 \quad \text{(aliased frequency)}}$$

원래 주파수 $\omega_0$인 신호가, 샘플링 후 $\omega_s - \omega_0$의 신호로 **오인**되는 것.

### 이미지에서의 앨리어싱

디지털 사진에서 나타나는 **모아레(Moire) 패턴** 또는 **지그재그 무늬**:

```
실제 패턴 (고주파):   ||||||||||||||||
디지털 샘플링:        ↓↓ ↓↓ ↓↓ ↓↓      (샘플링 부족)
복원된 이미지:        ~~~~~~~~~~~~~~~~~~~~  (저주파 줄무늬)
```

→ **안티앨리어싱 필터**: 샘플링 전 LPF로 $\omega_M < \omega_s/2$ 보장하면 해결.

## 8. CT → DT 변환 (C/D 컨버전)

### 전체 디지털 신호처리 시스템

```
x_c(t) → [C/D 변환] → x[n] → [DT 시스템] → y[n] → [D/C 변환] → y_c(t)
           (A/D 컨버터)                              (D/A 컨버터)
```

실제 예시: 마이크 입력 → 디지털 처리 (이퀄라이저, 에코 등) → 스피커 출력

### C/D 변환 2단계

**1단계**: $x_c(t) \times p(t)$ → $x_p(t)$ (임펄스 트레인 곱, 여전히 **CT 신호**)

```
x_c(t):     /\            x_p(t): 임펄스 트레인 곱
            /  \                    ↑     ↑
           /    \          →        |  ↑  |  ↑
          /      \                  | ↑|  | ↑|
         /        \                 0  T  2T 3T → t
```

**2단계**: $x_p(t)$ → $x[n]$ (**시간 정보 제거, 순서 정보만 유지**)

```
x_p(t): 임펄스(CT 신호)     x[n]: 막대그래프(DT 신호)
          ↑  ↑  ↑  ↑                ↑  ↑  ↑  ↑
          |  |  |  |        →       |  |  |  |
→ t       0  T 2T 3T               → n 0  1  2  3
(시간 정보 있음)                    (순서만 있음)
```

### 핵심 관계

$$\boxed{x[n] = x_c(nT)}$$

- $n$은 **시간이 아닌 순서(index)**
- $T$: 샘플링 주기 (별도 저장 필요 — MP3의 44.1kHz 등이 이 정보)

> **주의**: $x_p(t)$와 $x[n]$은 수치는 같지만 서로 다른 신호.  
> $x_p(t)$: 연속시간에서 정의, 임펄스 트레인 모양  
> $x[n]$: 이산시간에서 정의, 정수 인덱스에서만 값 존재

### 샘플링 주기에 따른 차이

```
T₁ (촘촘한 샘플링):        T₂ (드문 샘플링, T₂ > T₁):
x_p(t): ↑↑↑↑↑↑↑↑↑↑       x_p(t): ↑   ↑   ↑   ↑   ↑

x[n]:   ↑↑↑↑↑↑↑↑↑↑       x[n]:   ↑   ↑   ↑   ↑   ↑
(패턴 유사)               (패턴 압축되어 보임)
```

DT 도메인에서는 항상 간격이 1이지만, 실제로 담고 있는 정보량은 다름.

## 9. DTFT와 CT 주파수의 관계

### 이산시간 주파수 $\Omega$와 연속시간 주파수 $\omega$의 관계

$$\boxed{\Omega = \omega T}$$

이것이 이번 강의에서 **반드시 암기**해야 할 관계식.

### 유도 과정

$x_p(t)$의 CTFT:

$$X_p(j\omega) = \frac{1}{T}\sum_{k=-\infty}^{\infty} X(j(\omega - k\omega_s))$$

$x[n]$의 DTFT:

$$X_d(e^{j\Omega}) = \sum_{n=-\infty}^{\infty} x[n] e^{-j\Omega n}$$

$x[n] = x_c(nT)$를 이용해 정리하면 두 식이 동일해지는 조건:

$$\Omega = \omega T \quad \Leftrightarrow \quad \omega = \frac{\Omega}{T}$$

### 주파수 범위 대응

| DT 주파수 $\Omega$ | CT 주파수 $\omega$ |
|------------------|-----------------|
| $-\pi$ | $-\dfrac{\pi}{T} = -\dfrac{\omega_s}{2}$ |
| $0$ | $0$ |
| $+\pi$ | $+\dfrac{\pi}{T} = +\dfrac{\omega_s}{2}$ |

→ DTFT의 의미있는 범위 $[-\pi, \pi]$는 CT에서 $\left[-\dfrac{\omega_s}{2}, \dfrac{\omega_s}{2}\right]$에 대응.

### DTFT의 주기성

$$X_d(e^{j\Omega}) \text{ 는 } 2\pi \text{ 주기로 반복}$$

$\Omega$가 $2\pi$ 이상이 되면 같은 신호를 의미함 (이산시간의 특성).

### $X_d(e^{j\Omega})$와 $X_p(j\omega)$ 관계

$$X_d(e^{j\Omega}) = X_p\!\left(j\frac{\Omega}{T}\right) \cdot T$$

즉, CT 스펙트럼 $X_p(j\omega)$에서 $\omega \to \Omega/T$로 치환 + $T$ 배 스케일링 = DTFT.

### 샘플링 주기와 스펙트럼 변화

```
CT 스펙트럼 X_p(jω):               DT 스펙트럼 X_d(e^{jΩ}):

T₁ (촘촘):                          항상 2π 주기
   △    △    △    △                    △
 ω_s₁간격              →        -π    0    π   (Ω)

T₂ (드문, T₂ > T₁):                항상 2π 주기
 △  △  △  △  △                        △
ω_s₂간격 (좁음)           →        -π    0    π   (Ω)
(앨리어싱 위험 증가)
```

CT 도메인에서는 샘플링 간격에 따라 스펙트럼 간격이 달라지지만,  
DT 도메인으로 변환하면 항상 $2\pi$ 주기로 정규화됨. 차이는 스케일링뿐.

## 10. 핵심 요약 & 시험 포인트

### 반드시 암기할 공식

**선형 인터폴레이션 임펄스 응답 (삼각형 펄스)**:

$$h_{FOH}(t) = \begin{cases} 1 - \dfrac{|t|}{T} & |t| \leq T \\ 0 & |t| > T \end{cases}$$

**Ideal LPF 임펄스 응답 (Sinc)**:

$$h(t) = \frac{\sin(\omega_c t)}{\pi t}, \quad \omega_c = \frac{\omega_s}{2}$$

**Sinc 인터폴레이션 복원 수식**:

$$x_r(t) = \sum_{n=-\infty}^{\infty} x(nT) \cdot \frac{\sin(\omega_c(t - nT))}{\pi(t - nT)}$$

**앨리어싱 발생 시 복원 주파수**:

$$\omega_0' = \omega_s - \omega_0$$

**CT↔DT 주파수 관계**:

$$\boxed{\Omega = \omega T}$$

### 인터폴레이션 방법 요약

| 방법 | 임펄스 응답 $h(t)$ | 주파수 응답 | 특징 |
|------|--------------------|-----------|------|
| ZOH | 구형파 ($0 \leq t < T$) | Sinc 형태 | 계단 모양, 구현 쉬움 |
| FOH (선형) | 삼각형 펄스 ($|t| \leq T$) | Sinc² 형태 | 직선 연결, 미분 불가 |
| Ideal LPF | $\dfrac{\sin(\omega_c t)}{\pi t}$ | 구형파 | 이상적, 구현 불가 |

### 앨리어싱 판별 및 분석

| 단계 | 확인 사항 |
|------|---------|
| 1 | $\omega_s > 2\omega_0$? → 만족: 복원 가능, 위반: 앨리어싱 |
| 2 | 앨리어싱 시 복원 주파수 = $\omega_s - \omega_0$ |
| 3 | 다른 주파수인데 같은 복원 결과 → 해당 두 신호가 서로 alias 관계 |

### C/D 변환 과정 요약

| 단계 | 신호 | 도메인 | 설명 |
|------|------|--------|------|
| 입력 | $x_c(t)$ | CT | 연속시간 입력 |
| ×임펄스 트레인 | $x_p(t)$ | CT | 여전히 CT이지만 띄엄띄엄 |
| 시간 정보 제거 | $x[n]$ | DT | 순서 index만 존재 |
| 관계식 | $x[n] = x_c(nT)$ | — | 수치는 동일 |

### DTFT 주파수 범위 정리

$$-\pi \leq \Omega \leq \pi \quad \Leftrightarrow \quad -\frac{\omega_s}{2} \leq \omega \leq \frac{\omega_s}{2}$$

### 자주 틀리는 포인트

- $x_p(t)$와 $x[n]$은 수치는 같지만 **다른 신호** (도메인이 다름)
- $n$은 **시간이 아닌 순서(index)** — 시간 정보는 별도 저장
- Sinc 함수: $h(0) = \omega_c / \pi = 1/T$ (0이 아님, L'Hôpital 적용)
- FOH 임펄스 응답의 구간: $|t| \leq T$ (ZOH의 $0 \leq t < T$와 다름)
- 앨리어싱 복원 주파수: $\omega_s - \omega_0$ (절댓값 주의)
