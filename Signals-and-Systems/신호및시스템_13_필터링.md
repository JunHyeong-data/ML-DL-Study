## 1. 지난 강의 연결 — 주파수 응답 복습

### 핵심 관계식

LTI 시스템에서 입력 $x[n] = e^{j\omega_0 n}$에 대한 출력:

$$y[n] = H(e^{j\omega_0}) \cdot x[n]$$

CTFS 계수로 표현하면, 입력 계수 $a_k$에 대해 출력 계수 $b_k$는:

$$b_k = H(e^{jk\omega_0}) \cdot a_k$$

### 이것이 갖는 의미

$x[n]$을 DTFS로 전개한다는 것은 신호를 **주파수 성분별로 분해**하는 것이다.

- $a_k$: $k$번째 주파수 성분의 **가중치(weighting)**
- $H(e^{jk\omega_0})$: 그 주파수 성분에 시스템이 얼마나 **이득(gain)** 을 주는지

$$b_k = \underbrace{H(e^{jk\omega_0})}_{\text{이득}} \cdot \underbrace{a_k}_{\text{입력 가중치}}$$

> **핵심**: 주파수 응답 $H$를 이용해 특정 주파수 성분의 이득을 조절하는 것 = **필터링**

---

## 2. 필터링(Filtering)이란?

### 정의

**원하는 주파수 성분을 강조하거나, 원치 않는 주파수 성분을 감쇠시키는 것**

- 특정 주파수 성분의 이득을 크게 → **강조(Boost)**
- 특정 주파수 성분의 이득을 0에 가깝게 → **감쇠(Attenuation)**

### 실생활 예시

| 예시 | 필터링 역할 |
|------|-----------|
| 음악 이퀄라이저 | 저음/고음 주파수 대역을 독립적으로 조절 |
| 정수기 / 공기청정기 | 불필요한 성분(바이러스 등)을 걸러냄 |
| 카메라 엣지 검출 | 경계선(고주파) 성분만 강조 |

### 주파수 응답 표현 — dB 스케일

주파수 응답의 크기(이득)는 주로 **dB(데시벨)** 단위로 표현:

$$\text{이득 [dB]} = 20 \log_{10} |H(e^{j\omega})|$$

- 가로축: 주파수 범위 (정보가 넓게 퍼짐 → 가로로 펼쳐서 보기 편함)
- 세로축: 이득 [dB]

## 3. 미분기(Differentiator) — 하이패스 필터 (연속시간)

### 시스템 정의

입력 $x(t)$에 대해 출력 $y(t) = \frac{d}{dt}x(t)$인 시스템.

### 주파수 응답 유도

CTFS 미분 성질:

$$x(t) \xrightarrow{FS} a_k \quad \Rightarrow \quad \frac{d}{dt}x(t) \xrightarrow{FS} jk\omega_0 \cdot a_k$$

따라서 출력 계수:

$$b_k = jk\omega_0 \cdot a_k$$

이를 주파수 응답 관점에서 쓰면 ($\omega = k\omega_0$):

$$H(j\omega) = j\omega$$

### 크기 특성 (이득)

$$|H(j\omega)| = |\omega|$$

$\omega$(주파수)가 클수록 이득이 커진다 → **고주파 성분이 강조**됨

### 결론: 하이패스 필터

| 주파수 | 이득 $|H(j\omega)|$ |
|--------|-------------------|
| 낮은 주파수 ($\omega \to 0$) | $\approx 0$ (감쇠) |
| 높은 주파수 ($\omega \to \infty$) | 크게 증가 (강조) |

> 미분 = **변화량**을 구하는 것 → 변화가 큰(고주파) 성분이 강조됨

### 사인파 입력에 대한 검증

$$x(t) = \sin(\omega t) \quad \Rightarrow \quad y(t) = \omega \cos(\omega t) = \omega \sin\!\left(\omega t + \frac{\pi}{2}\right)$$

- 크기: 원래의 $\omega$배로 증가 → 고주파일수록 더 강조
- 위상: $+\frac{\pi}{2}$ 이동 (크기에는 영향 없음)

$$x(t) = \cos(\omega t) \quad \Rightarrow \quad y(t) = -\omega \sin(\omega t) = \omega \cos\!\left(\omega t + \frac{\pi}{2}\right)$$

## 4. 차분기 — 하이패스 필터 (이산시간)

### 이산시간에서 미분의 대체

이산시간에서는 미분이 불가능하다. 대신 **차분(difference)** 이 미분에 대응한다:

$$y[n] = x[n] - x[n-1]$$

### 주파수 응답 유도

임펄스 응답: $x[n] = \delta[n]$을 대입하면

$$h[n] = \delta[n] - \delta[n-1]$$

DTFS 시간 이동 성질을 이용해 푸리에 변환:

$$H(e^{j\omega}) = 1 - e^{-j\omega}$$

### 크기 특성 분석

$$H(e^{j\omega}) = 1 - e^{-j\omega} = e^{-j\omega/2}\left(e^{j\omega/2} - e^{-j\omega/2}\right) = e^{-j\omega/2} \cdot 2j\sin\!\left(\frac{\omega}{2}\right)$$

$$|H(e^{j\omega})| = 2\left|\sin\!\left(\frac{\omega}{2}\right)\right|$$

| 주파수 | $\sin(\omega/2)$ | 이득 |
|--------|-----------------|------|
| $\omega = 0$ (저주파) | $0$ | 0 (감쇠) |
| $\omega = \pi$ (고주파, 이산시간 최대) | $1$ | 2 (강조) |

> **이산시간에서 가장 높은 주파수는 $\omega = \pi$**

$$\therefore \text{ 차분기 = 하이패스 필터}$$

### 빠른 직관

입력을 $\sin(\omega n)$으로 놓으면:

$$y[n] = \sin(\omega n) - \sin(\omega(n-1))$$

삼각함수 공식으로 전개하면 앞에 $2\sin(\omega/2)$가 이득으로 곱해짐 — 주파수 응답에서 구한 결과와 일치.

## 5. 하이패스 필터 응용 — 엣지 검출

### 영상 처리에서의 활용

하이패스 필터(미분/차분)를 영상에 적용하면 **경계선(Edge)을 검출**할 수 있다.

### 원리

| 영역 | 픽셀 변화 | 미분값 |
|------|---------|--------|
| 배경 (균일한 색) | 변화 없음 | $\approx 0$ |
| 경계선 | 픽셀값이 급격히 변화 | 크게 증가 |
| 물체 내부 (균일) | 변화 없음 | $\approx 0$ |

### 동작 과정

1. 배경(어두운 색): 픽셀값 일정 → 차이 거의 없음 → 미분값 ≈ 0
2. **경계선**: 어두운 색 → 밝은 색으로 급격 전환 → 미분값 **크게 증가**
3. 물체 내부(밝은 색): 픽셀값 일정 → 미분값 ≈ 0
4. 또 다른 경계선에서 다시 미분값 크게 증가

> 경계선은 주변과의 차이가 크다 = 고주파 성분 = 하이패스 필터가 강조

### 연속시간 vs 이산시간

| | 연속시간 | 이산시간 |
|--|---------|---------|
| 연산 | 1차 미분 | 차분 (인접 픽셀 빼기) |
| 결과 | 변화량 큰 곳 강조 | 인접 픽셀 차이 큰 곳 강조 |
| 효과 | 하이패스 → 엣지 검출 | 하이패스 → 엣지 검출 |

## 6. 이동 평균기(Moving Average) — 로우패스 필터 (이산시간)

### 시스템 정의

현재 시점 주변 샘플들의 평균을 구하는 시스템:

$$y[n] = \frac{1}{3}\left(x[n+1] + x[n] + x[n-1]\right)$$

> 더하기(평균) = 로우패스 필터 (차분의 반대)

### 인과성(Causality) 확인

$$y[n] = \frac{1}{3}\left(x[n+1] + x[n] + x[n-1]\right)$$

$x[n+1]$은 **미래 입력** → **비인과(Non-causal) 시스템**

$$y[n] = \frac{1}{3}\left(x[n] + x[n-1] + x[n-2]\right)$$

$x[n], x[n-1], x[n-2]$만 사용 → **인과(Causal) 시스템**

> 두 시스템은 같은 **이득(Gain)** 을 가지며, **위상(Phase)만 다름**

### 주파수 응답 유도

임펄스 응답으로부터 (인과 버전):

$$h[n] = \frac{1}{3}\left(\delta[n] + \delta[n-1] + \delta[n-2]\right)$$

$$H(e^{j\omega}) = \frac{1}{3}\left(1 + e^{-j\omega} + e^{-j2\omega}\right)$$

$$= \frac{1}{3} e^{-j\omega} \left(e^{j\omega} + 1 + e^{-j\omega}\right) = \frac{1}{3} e^{-j\omega} \left(1 + 2\cos\omega\right)$$

$$|H(e^{j\omega})| = \frac{1}{3}\left|1 + 2\cos\omega\right|$$

또는 비인과 버전의 경우:

$$H(e^{j\omega}) = \frac{1}{3}\left(e^{j\omega} + 1 + e^{-j\omega}\right) = \frac{1}{3}\left(1 + 2\cos\omega\right)$$

$$|H(e^{j\omega})| = \frac{1}{3}\left|1 + 2\cos\omega\right|$$

### 크기 특성 분석

더 일반적인 표현으로 $\cos(\omega/2)$로 나타낼 수 있다:

| 주파수 | $\cos(\omega/2)$ | 이득 |
|--------|-----------------|------|
| $\omega = 0$ (저주파) | $1$ | 최대 (강조) |
| $\omega = \pi$ (고주파) | $0$ | 0 (감쇠) |

$$\therefore \text{ 이동 평균기 = 로우패스 필터}$$

### 로우패스 vs 하이패스 대응

| 연산 | 필터 종류 | 직관 |
|------|---------|------|
| 미분 / 차분 (빼기) | 하이패스 | 변화량 강조 |
| 적분 / 합산 / 평균 (더하기) | 로우패스 | 평균화 → 부드럽게 |

## 7. 필터의 종류 4가지

### 이산시간 필터 분류 원칙

이산시간에서 주파수 응답 $H(e^{j\omega})$는 **주기 $2\pi$로 반복**된다.

따라서 $-\pi \leq \omega \leq \pi$ 구간만 분석하면 된다.

- **물리적으로 가장 높은 주파수**: $\omega = \pm\pi$
- **물리적으로 가장 낮은 주파수**: $\omega = 0$

### 필터 종류

**① 로우패스 필터 (Low-Pass Filter, LPF)**

$$|H(e^{j\omega})| = \begin{cases} 1 & |\omega| \leq \omega_c \\ 0 & \omega_c < |\omega| \leq \pi \end{cases}$$

- $\omega_c$: **차단 주파수(Cutoff Frequency)** — 이 이상 주파수를 차단
- $\omega \approx 0$ 근처 성분만 통과
- 고주파 제거 → 신호를 부드럽게

**② 하이패스 필터 (High-Pass Filter, HPF)**

$$|H(e^{j\omega})| = \begin{cases} 0 & |\omega| \leq \omega_c \\ 1 & \omega_c < |\omega| \leq \pi \end{cases}$$

- $\omega \approx \pm\pi$ 근처 성분만 통과
- 저주파 제거 → 변화량 강조

**③ 밴드패스 필터 (Band-Pass Filter, BPF)**

$$|H(e^{j\omega})| = \begin{cases} 1 & \omega_{c1} \leq |\omega| \leq \omega_{c2} \\ 0 & \text{그 외} \end{cases}$$

- 특정 주파수 대역만 통과
- LPF와 HPF 사이의 중간 대역만 선택

**④ 밴드스탑 필터 (Band-Stop Filter / Band-Reject Filter)**

$$|H(e^{j\omega})| = \begin{cases} 0 & \omega_{c1} \leq |\omega| \leq \omega_{c2} \\ 1 & \text{그 외} \end{cases}$$

- 특정 주파수 대역만 제거
- BPF의 반대 (대역 저지 필터, Notch Filter)

### 필터 종류 판별법 요약

| 필터 | $\omega = 0$일 때 이득 | $\omega = \pi$일 때 이득 |
|------|---------------------|----------------------|
| LPF | 크다 (1) | 작다 (0) |
| HPF | 작다 (0) | 크다 (1) |
| BPF | 작다 | 작다 (중간만 큼) |
| BSF | 크다 | 크다 (중간만 작음) |

> **판별 팁**: $\omega = 0$과 $\omega = \pi$에서의 값을 계산해보면 어떤 필터인지 바로 알 수 있다.

## 8. 주파수 응답을 빠르게 구하는 방법

### 기존 방법 (느리지만 확실)

1. 임펄스 입력 $\delta[n]$ 대입 → 임펄스 응답 $h[n]$ 계산
2. $h[n]$을 푸리에 변환 → $H(e^{j\omega})$

### 빠른 방법 (권장)

가장 간단한 입력 $x[n] = e^{j\omega n}$을 직접 대입:

$$y[n] = H(e^{j\omega}) \cdot e^{j\omega n}$$

이를 이용해 차분 방정식에 $x[n] = e^{j\omega n}$, $y[n] = H(e^{j\omega}) \cdot e^{j\omega n}$ 대입 후 $H(e^{j\omega})$에 대해 풀면 된다.

### 예시: 차분 방정식 $y[n] = x[n] + ay[n-1]$

$x[n] = e^{j\omega n}$, $y[n] = H(e^{j\omega}) e^{j\omega n}$ 대입:

$$H(e^{j\omega}) e^{j\omega n} = e^{j\omega n} + a \cdot H(e^{j\omega}) e^{j\omega(n-1)}$$

$$H(e^{j\omega}) e^{j\omega n} = e^{j\omega n} + a \cdot H(e^{j\omega}) e^{j\omega n} \cdot e^{-j\omega}$$

공통인수 $e^{j\omega n}$으로 나누고, $H$에 대해 정리:

$$H(e^{j\omega})(1 - ae^{-j\omega}) = 1$$

$$\boxed{H(e^{j\omega}) = \frac{1}{1 - ae^{-j\omega}}}$$

> 이 방법이 실제로 더 많이 쓰인다.

## 9. 피드백이 있는 시스템 (Recursive)

### 시스템 정의

$$y[n] = ay[n-1] + x[n]$$

과거의 **출력**이 다시 현재 출력 계산에 사용됨 → **피드백(Feedback)**

### 임펄스 응답

$x[n] = \delta[n]$을 대입하면:

$$h[n] = a^n u[n]$$

$|a| < 1$이면 수렴, $|a| > 1$이면 발산.

### 주파수 응답

$$H(e^{j\omega}) = \frac{1}{1 - ae^{-j\omega}}$$

### 필터 특성 분류

**$a > 0$인 경우 (로우패스 필터)**

| 주파수 | $|H(e^{j\omega})|$ |
|--------|------------------|
| $\omega = 0$ | $\frac{1}{1-a}$ (크다) |
| $\omega = \pi$ | $\frac{1}{1+a}$ (작다) |

→ 저주파 강조 = **LPF**

**$a < 0$인 경우 (하이패스 필터)**

| 주파수 | $|H(e^{j\omega})|$ |
|--------|------------------|
| $\omega = 0$ | $\frac{1}{1-a}$ (작다, $a<0$이므로 분모 큼) |
| $\omega = \pi$ | $\frac{1}{1+a}$ (크다) |

→ 고주파 강조 = **HPF**

### 특징

- 임펄스 응답이 **무한히 지속** (피드백 때문)
- IIR (Infinite Impulse Response) 시스템

---

## 10. 피드백이 없는 시스템 (Non-recursive)

### 시스템 정의

과거의 출력 없이 **입력만**으로 출력을 만드는 시스템:

$$y[n] = \frac{1}{3}\left(x[n+1] + x[n] + x[n-1]\right) \quad \text{(비인과)}$$

$$y[n] = \frac{1}{3}\left(x[n] + x[n-1] + x[n-2]\right) \quad \text{(인과)}$$

### 비인과 vs 인과 — 이득은 같다

**비인과 버전** ($x[n+1]$ 포함):

$$H_1(e^{j\omega}) = \frac{1}{3}\left(e^{j\omega} + 1 + e^{-j\omega}\right)$$

**인과 버전** ($x[n-2]$까지만):

$$H_2(e^{j\omega}) = \frac{1}{3}\left(1 + e^{-j\omega} + e^{-j2\omega}\right) = e^{-j\omega} \cdot H_1(e^{j\omega})$$

$$|H_1(e^{j\omega})| = |H_2(e^{j\omega})|$$

> **크기(이득)는 동일, 위상만 다름** (타임 시프트는 크기에 영향 없음)

### 특징

- 임펄스 응답이 **유한**
- FIR (Finite Impulse Response) 시스템

## 11. 일반형 이동 평균 (Moving Average)

### 일반 시스템 정의

$$y[n] = \frac{1}{N+M+1} \sum_{k=-M}^{N} x[n-k]$$

- $N + M + 1$개 샘플의 평균
- 연속적으로 업데이트되는 평균 → **무빙 에버리지(Moving Average)**

### 빠른 방법으로 주파수 응답 구하기

$x[n] = e^{j\omega n}$을 대입:

$$y[n] = e^{j\omega n} \cdot \frac{1}{N+M+1} \sum_{k=-M}^{N} e^{-j\omega k} = H(e^{j\omega}) \cdot e^{j\omega n}$$

$$H(e^{j\omega}) = \frac{1}{N+M+1} \sum_{k=-M}^{N} e^{-j\omega k}$$

정리하면:

$$H(e^{j\omega}) = e^{-j\omega \cdot \frac{N-M}{2}} \cdot \frac{\sin\!\left[\omega\dfrac{N+M+1}{2}\right]}{(N+M+1)\sin\!\left(\dfrac{\omega}{2}\right)}$$

- 앞의 $e^{-j\omega(\cdot)}$: 위상에만 영향 (크기 불변)
- 뒤의 Sinc 형태: **크기(이득)를 결정**

### 크기 특성 → 로우패스 필터 확인

$$|H(e^{j0})| = 1, \qquad |H(e^{j\pi})| = \frac{|\sin[\pi(N+M+1)/2]|}{(N+M+1)|\sin(\pi/2)|} \approx 0$$

$\omega = 0$에서 크고 $\omega = \pi$에서 작다 → **LPF 확인**

### 샘플 수와 필터 성능

| 샘플 수 ($N+M+1$) | Sinc 영점 간격 | 필터 선택성 |
|-----------------|--------------|----------|
| 작다 | 넓다 | 둔함 (브로드) |
| **크다** | **좁다** | **날카로움** (sharp) |

> 샘플 수가 많을수록 더 날카로운(sharp) 로우패스 필터 → 하지만 계산량 증가

## 12. 필터 설계 기초 — 좋은 필터란?

### 필터 선택성(Selectivity)

좋은 필터 = 통과 대역(Pass-band)과 저지 대역(Stop-band) 사이의 **전환이 급격한** 필터

```
이상적인 LPF:
|H|
 1 |_____
   |     |
   |     |_______
   +-----+-------→ ω
   0    ωc     π

실제 LPF:
|H|
 1 |_____
   |      \
   |       \___
   +-----+-------→ ω
   0    ωc     π
```

전환이 급격할수록 → 통과/차단 구분이 명확 → **좋은 필터**

### 이동 평균 필터: 샘플 수 비교

**샘플 수 적은 경우** (예: 3개):
- 이득이 점진적으로 감소
- 선택성이 낮음 (브로드)
- 계산량 적음

**샘플 수 많은 경우** (예: 9개):
- 이득이 더 급격히 감소
- 선택성이 높음 (샤프)
- 계산량 많음

### 현실적 트레이드오프

$$\text{좋은 선택성} \longleftrightarrow \text{많은 계산량}$$

실제 필터 설계는 이 둘 사이의 **최적 균형점**을 찾는 것이다.

> 이것이 필터 설계(Filter Design)의 핵심 — 이후 과목(디지털 신호처리)에서 깊이 다룸

### 차분기(하이패스 필터) 정리

$$y[n] = x[n] - x[n-1]$$

임펄스 응답: $h[n] = \delta[n] - \delta[n-1]$

주파수 응답:

$$H(e^{j\omega}) = 1 - e^{-j\omega} = 2j\sin\!\left(\frac{\omega}{2}\right) \cdot e^{-j\omega/2}$$

$$|H(e^{j\omega})| = 2\left|\sin\!\left(\frac{\omega}{2}\right)\right|$$

| $\omega$ | $\|H(e^{j\omega})\|$ | 의미 |
|----------|----------------------|------|
| $0$ | $0$ | 저주파 완전 차단 |
| $\pi$ | $2$ | 고주파 강조 |

→ HPF 확인

## 13. 핵심 요약 & 시험 포인트

### 반드시 암기할 개념

**필터 판별 공식:**
- $|H(e^{j0})|$ 크고 $|H(e^{j\pi})|$ 작으면 → **LPF**
- $|H(e^{j0})|$ 작고 $|H(e^{j\pi})|$ 크면 → **HPF**

**주파수 응답 빠른 계산법:**

$$x[n] = e^{j\omega n} \text{ 대입} \quad\Rightarrow\quad y[n] = H(e^{j\omega}) \cdot e^{j\omega n}$$

**이득(Gain)만 신경쓰면 되는 이유:**

$$|y[n]| = |H(e^{j\omega})| \cdot |x[n]|$$

위상은 출력의 모양을 시프트시킬 뿐, 크기에는 영향 없음

### 연산-필터 대응표

| 연산 | 필터 종류 | 예 |
|------|---------|---|
| 미분 $\frac{d}{dt}$ | HPF | 연속시간 미분기 |
| 차분 $x[n]-x[n-1]$ | HPF | 이산시간 차분기 |
| 적분 $\int$ | LPF | 연속시간 적분기 |
| 평균 / 합산 | LPF | 이동 평균기 |

### 필터 4종류 요약

| 필터 | 통과 대역 | 대표 응용 |
|------|---------|---------|
| LPF | $\|\omega\| \leq \omega_c$ | 노이즈 제거, 신호 평활화 |
| HPF | $\|\omega\| \geq \omega_c$ | 엣지 검출, 고주파 강조 |
| BPF | $\omega_{c1} \leq \|\omega\| \leq \omega_{c2}$ | 특정 대역 선택 |
| BSF | $\|\omega\| \leq \omega_{c1}$ or $\geq \omega_{c2}$ | 특정 주파수 제거 |

### 자주 틀리는 포인트

- 이산시간 최고 주파수: $\omega = \pi$ (연속시간처럼 $\infty$가 아님)
- 비인과 vs 인과 이동 평균: 이득(크기) 동일, 위상만 다름
- 피드백이 있으면 IIR → 임펄스 응답이 무한히 지속
- 피드백이 없으면 FIR → 임펄스 응답이 유한
- $a > 0$이면 LPF, $a < 0$이면 HPF (피드백 시스템 $y[n] = ay[n-1] + x[n]$)

### 다음 강의 예고

- **4장: 연속시간 푸리에 변환(CTFT)**
- 3장(주기 신호의 CTFS)에서 비주기 신호로 확장
