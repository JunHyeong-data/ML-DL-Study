## 1. 왜 푸리에 변환을 배우는가?

### 주파수 해석(Frequency Analysis)이 목적

신호 처리의 핵심 목표 중 하나는 **주파수 해석**이다.

> 신호에 포함된 여러 주파수 성분을 분리하고 파악하는 것

코사인 신호 $A\cos(\omega_0 t + \phi)$는 다음 세 가지 정보를 담고 있다:

| 정보 | 의미 | 기호 |
|------|------|------|
| 진폭(Amplitude) | 신호의 세기 | $A$ |
| 주파수(Frequency) | 진동 속도 | $\omega_0$ |
| 위상(Phase) | 시작 위치 | $\phi$ |

### 3장과 4장의 차이

| | 3장 (푸리에 급수) | 4장 (푸리에 변환) |
|--|-----------------|-----------------|
| 대상 신호 | **주기** 신호 | **비주기** 신호 (일반적) |
| 주파수 성분 | 이산 스펙트럼 (띄엄띄엄) | **연속 스펙트럼** |
| 표현 방법 | 시그마 $\sum$ | 적분 $\int$ |
| 용도 | 특수한 경우 | **일반적인 경우** |

> 푸리에 급수는 푸리에 변환을 이해하기 위한 **도입 개념**이다.

## 2. 푸리에 급수 → 푸리에 변환: 핵심 아이디어

### 비주기 신호를 주기 신호로 보기

비주기 신호 = **주기가 무한대인 주기 신호**로 취급

$$T \to \infty$$

### 주기가 커지면 스펙트럼이 어떻게 변하나?

$$\omega_0 = \frac{2\pi}{T}$$

$T$가 커질수록 $\omega_0$가 작아진다. 따라서:

- 하모닉 성분 간격: $\omega_0 \to 0$
- 스펙트럼이 **점점 촘촘해짐** → 결국 연속 스펙트럼

| 주기 $T$ | $\omega_0 = 2\pi/T$ | 스펙트럼 형태 |
|---------|---------------------|-------------|
| 작다 | 크다 | 성기다 (이산) |
| 크다 | 작다 | 촘촘하다 |
| $\infty$ | $0$ | 연속 (푸리에 변환) |

### 시그마 → 적분으로의 전환

$$\sum_{k=-\infty}^{\infty} (\cdots) \xrightarrow{T \to \infty} \int_{-\infty}^{\infty} (\cdots)\, d\omega$$

## 3. 푸리에 변환 유도 과정

### 출발점: 주기 신호의 CTFS

주기 신호 $\tilde{x}(t)$의 푸리에 급수와 계수:

$$\tilde{x}(t) = \sum_{k=-\infty}^{\infty} a_k\, e^{jk\omega_0 t}$$

$$a_k = \frac{1}{T} \int_{-T/2}^{T/2} \tilde{x}(t)\, e^{-jk\omega_0 t}\, dt$$

### Step 1: 적분 구간 확장

$T \to \infty$로 보내면 적분 구간이 확장됨:

$$a_k = \frac{1}{T} \int_{-\infty}^{\infty} x(t)\, e^{-jk\omega_0 t}\, dt$$

(이때 $\tilde{x}(t) \to x(t)$: 주기 신호 → 비주기 신호)

### Step 2: $T \cdot a_k$ 정의

$$T \cdot a_k = \int_{-\infty}^{\infty} x(t)\, e^{-jk\omega_0 t}\, dt$$

이 값을 $X(j\omega)$라 정의 ($\omega = k\omega_0$):

$$X(j\omega) = \int_{-\infty}^{\infty} x(t)\, e^{-j\omega t}\, dt \quad \leftarrow \textbf{푸리에 변환}$$

따라서:

$$a_k = \frac{1}{T} X(jk\omega_0)$$

### Step 3: 합성식에 대입

$$\tilde{x}(t) = \sum_{k=-\infty}^{\infty} \frac{1}{T} X(jk\omega_0)\, e^{jk\omega_0 t} = \frac{1}{2\pi} \sum_{k=-\infty}^{\infty} X(jk\omega_0)\, e^{jk\omega_0 t} \cdot \omega_0$$

$T \to \infty$이면 $\omega_0 \to d\omega$, 시그마 → 적분:

$$x(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} X(j\omega)\, e^{j\omega t}\, d\omega \quad \leftarrow \textbf{역변환}$$

## 4. 푸리에 변환과 역변환 공식

### 반드시 암기 ⭐

**푸리에 변환 (분석, Forward Transform):**

$$\boxed{X(j\omega) = \int_{-\infty}^{\infty} x(t)\, e^{-j\omega t}\, dt}$$

**푸리에 역변환 (합성, Inverse Transform):**

$$\boxed{x(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} X(j\omega)\, e^{j\omega t}\, d\omega}$$

### 표기법

$$x(t) \xleftrightarrow{\mathcal{F}} X(j\omega)$$

또는 $X(j\omega)$를 $X(\omega)$로도 쓴다.

### 각 식의 의미

| 식 | 이름 | 방향 | 의미 |
|----|------|------|------|
| $X(j\omega) = \int x(t) e^{-j\omega t} dt$ | 푸리에 변환 | $t \to \omega$ | 신호를 주파수 성분별로 **분석** |
| $x(t) = \frac{1}{2\pi}\int X(j\omega) e^{j\omega t} d\omega$ | 역변환 | $\omega \to t$ | 주파수 성분으로 신호를 **합성** |

### 수렴 조건 (푸리에 변환)

푸리에 급수의 디리클레 조건에서 **주기성만 제거**:

$$\int_{-\infty}^{\infty} |x(t)|\, dt < \infty \quad \text{(절대 적분 가능)}$$

+ 유한 개의 극값 + 유한 개의 불연속점

## 5. 예제 4.4 — 임펄스 함수의 푸리에 변환

### 문제

$$x(t) = \delta(t)$$

### 풀이

$$X(j\omega) = \int_{-\infty}^{\infty} \delta(t)\, e^{-j\omega t}\, dt$$

임펄스의 샘플링 성질: $t = 0$에서만 $\delta(t) \neq 0$이므로 $e^{-j\omega \cdot 0} = 1$

$$\boxed{X(j\omega) = 1}$$

### 결과 해석

$$\delta(t) \xleftrightarrow{\mathcal{F}} 1$$

```
시간 영역:              주파수 영역:
  ↑                      |X(jω)|
  |δ(t)                   ___________
  |                       1
  +---→ t                 +----------→ ω
  0                       0
```

> **임펄스 함수는 모든 주파수 성분을 동일하게 포함** (주파수 스펙트럼이 평탄)

### 역방향도 기억

$$1 \xleftrightarrow{\mathcal{F}} 2\pi\,\delta(\omega)$$

상수 함수(DC)의 푸리에 변환은 $\omega = 0$에서의 임펄스

## 6. 예제 4.1 — 단방향 지수 감쇠 신호

### 문제

$$x(t) = e^{-at} u(t), \quad a > 0$$

### 풀이

$$X(j\omega) = \int_{-\infty}^{\infty} e^{-at} u(t)\, e^{-j\omega t}\, dt = \int_0^{\infty} e^{-at} e^{-j\omega t}\, dt$$

$$= \int_0^{\infty} e^{-(a+j\omega)t}\, dt = \left[\frac{e^{-(a+j\omega)t}}{-(a+j\omega)}\right]_0^{\infty}$$

$a > 0$이면 $t \to \infty$에서 $e^{-(a+j\omega)t} \to 0$이므로:

$$\boxed{X(j\omega) = \frac{1}{a + j\omega}}$$

### 크기(Magnitude) 스펙트럼

$$|X(j\omega)| = \frac{1}{\sqrt{a^2 + \omega^2}}$$

### 위상(Phase) 스펙트럼

분자: $1$ → 위상 = $0$

분모: $a + j\omega$ → 위상 = $\arctan\!\left(\dfrac{\omega}{a}\right)$

$$\angle X(j\omega) = 0 - \arctan\!\left(\frac{\omega}{a}\right) = -\arctan\!\left(\frac{\omega}{a}\right)$$

> **위상 계산법**: $\angle X = \angle(\text{분자}) - \angle(\text{분모})$

## 7. 예제 4.2 — 양방향 지수 감쇠 신호

### 문제

$$x(t) = e^{-a|t|}, \quad a > 0$$

### 풀이 (구간 분할)

$$X(j\omega) = \int_{-\infty}^{0} e^{at} e^{-j\omega t}\, dt + \int_0^{\infty} e^{-at} e^{-j\omega t}\, dt$$

**첫 번째 구간** ($t < 0$): 예제 4.1을 $t \to -t$ 치환하면

$$\int_{-\infty}^{0} e^{at} e^{-j\omega t}\, dt = \frac{1}{a - j\omega}$$

**두 번째 구간** ($t > 0$): 예제 4.1과 동일

$$\int_0^{\infty} e^{-at} e^{-j\omega t}\, dt = \frac{1}{a + j\omega}$$

**합산**:

$$X(j\omega) = \frac{1}{a - j\omega} + \frac{1}{a + j\omega} = \frac{(a+j\omega) + (a-j\omega)}{a^2 + \omega^2} = \frac{2a}{a^2 + \omega^2}$$

$$\boxed{X(j\omega) = \frac{2a}{a^2 + \omega^2}}$$

### 결과 해석

- $X(j\omega)$가 **실수** → 위상 = 0 → 크기와 위상을 따로 그리지 않고 $X(j\omega)$ 자체를 표시
- $x(t)$가 우함수이면 $X(j\omega)$도 실수(우함수)

## 8. 예제 4.4 — 스퀘어 웨이브(비주기)의 푸리에 변환

### 문제

$$x(t) = \begin{cases} 1 & |t| \leq t_1 \\ 0 & |t| > t_1 \end{cases}$$

### 풀이

$$X(j\omega) = \int_{-t_1}^{t_1} 1 \cdot e^{-j\omega t}\, dt = \left[\frac{e^{-j\omega t}}{-j\omega}\right]_{-t_1}^{t_1}$$

$$= \frac{e^{-j\omega t_1} - e^{j\omega t_1}}{-j\omega} = \frac{2\sin(\omega t_1)}{\omega}$$

$$\boxed{X(j\omega) = \frac{2\sin(\omega t_1)}{\omega} = 2t_1 \cdot \text{sinc}\!\left(\frac{\omega t_1}{\pi}\right)}$$

### 결과: Sinc 형태

$$X(j\omega) = \frac{2\sin(\omega t_1)}{\omega}$$

- $X(j\omega)$가 실수 → 크기와 위상 따로 분리 없이 그대로 그림
- 영점(zero): $\omega t_1 = n\pi$ → $\omega = \frac{n\pi}{t_1}$

### 반드시 외울 변환 쌍 ⭐

$$\text{rect}(t/2t_1) \xleftrightarrow{\mathcal{F}} \frac{2\sin(\omega t_1)}{\omega}$$

또는 3장 결과와 비교:

$$T \cdot a_k = \frac{2\sin(k\omega_0 t_1)}{k\omega_0} = X(jk\omega_0)$$

> 푸리에 급수 계수에 주기 $T$를 곱하면 푸리에 변환과 같다.

## 9. 쌍대성(Duality)

### 개념

타임 도메인과 주파수 도메인은 **서로 대칭적인(쌍대적인) 관계**를 가진다.

| 타임 도메인 | 주파수 도메인 |
|-----------|-------------|
| $\delta(t)$ (임펄스) | $1$ (상수) |
| $1$ (상수) | $2\pi\,\delta(\omega)$ (임펄스) |
| rect (스퀘어 웨이브) | Sinc 함수 |
| Sinc 함수 | rect (스퀘어 웨이브) |

### 쌍대성 정리

$$x(t) \xleftrightarrow{\mathcal{F}} X(j\omega)$$

이면:

$$X(jt) \xleftrightarrow{\mathcal{F}} 2\pi\, x(-\omega)$$

### 활용

타임 도메인의 성질을 알면 → 주파수 도메인의 성질을 바로 유도 가능

**예시**:
- 타임 도메인에서 $\delta(t) \to 1$ (임펄스 → 상수)
- 쌍대성으로: 상수 $1 \to 2\pi\,\delta(\omega)$ (상수 → 임펄스)

## 10. Sinc 함수

### 정의

$$\text{sinc}(\theta) = \frac{\sin(\pi\theta)}{\pi\theta}$$

또는 unnormalized 형태로:

$$\text{sinc}_u(\theta) = \frac{\sin(\theta)}{\theta}$$

### 파이 분의 사인 형태로 자주 쓰이는 표현

$$\frac{\sin(\omega t_1)}{\omega} = t_1 \cdot \text{sinc}\!\left(\frac{\omega t_1}{\pi}\right)$$

### 스퀘어 웨이브 ↔ Sinc 변환 쌍

$$\underbrace{\text{rect 함수}}_{\text{시간 영역 스퀘어 웨이브}} \xleftrightarrow{\mathcal{F}} \underbrace{\text{Sinc 함수}}_{\text{주파수 영역}}$$

$$\underbrace{\text{Sinc 함수}}_{\text{시간 영역}} \xleftrightarrow{\mathcal{F}} \underbrace{\text{rect 함수}}_{\text{주파수 영역 스퀘어 웨이브}}$$

### Sinc 함수의 특성

- $\theta = 0$: $\lim_{\theta \to 0} \frac{\sin\theta}{\theta} = 1$ (L'Hôpital)
- 영점(zero): $\sin(\omega t_1) = 0$ → $\omega t_1 = n\pi$ → $\omega = \frac{n\pi}{t_1}$

### $w$ 값과 Sinc 파형의 관계

주파수 영역 스퀘어 웨이브의 폭을 $\omega_c$라 할 때:

| $\omega_c$ 크다 | $\omega_c$ 작다 |
|---------------|---------------|
| 고주파 성분 많이 포함 | 저주파 성분만 포함 |
| Sinc 영점 간격 좁음 | Sinc 영점 간격 넓음 |
| 시간 영역 신호: 출렁임 많음 | 시간 영역 신호: 부드러움 |

> **타임-주파수 역비례 관계**: 주파수 영역에서 좁으면 시간 영역에서 넓고, 반대도 성립

## 11. 이산시간에서의 Sinc — 주의사항

### 연속시간 Sinc

$$\frac{\sin(\pi n)}{\pi n} \quad (n \in \mathbb{R})$$

연속 변수에서는 $n = 0$일 때 1, 나머지는 부드럽게 변함.

### 이산시간 Sinc — 특수 결과

이산시간에서 $n$은 **정수**만 가능.

$$\frac{\sin(\pi n)}{\pi n} = \begin{cases} 1 & n = 0 \\ 0 & n \neq 0 \end{cases} = \delta[n]$$

이유: $n$이 0이 아닌 정수이면 $\sin(\pi n) = 0$ (정수배 $\pi$)

$$\therefore \quad \frac{\sin(\pi n)}{\pi n}\bigg|_{n \in \mathbb{Z}} = \delta[n]$$

### 시험 함정 주의 ⭐

복잡해 보이는 이산시간 Sinc 표현은 사실 임펄스:

$$\frac{\sin(\pi n / M)}{\pi n} \quad \text{같이 복잡하게 주어져도} \to \delta[n] \text{로 단순화 가능한 경우 있음}$$

> 문제를 어렵게 보이게 만들려고 $\delta[n]$ 대신 Sinc 형태로 쓰기도 한다.

## 12. 핵심 요약 & 시험 포인트

### 반드시 암기할 공식

**푸리에 변환:**

$$\boxed{X(j\omega) = \int_{-\infty}^{\infty} x(t)\, e^{-j\omega t}\, dt}$$

**푸리에 역변환:**

$$\boxed{x(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} X(j\omega)\, e^{j\omega t}\, d\omega}$$

### 반드시 암기할 변환 쌍

| $x(t)$ | $X(j\omega)$ | 비고 |
|--------|-------------|------|
| $\delta(t)$ | $1$ | 임펄스 → 상수 |
| $1$ | $2\pi\,\delta(\omega)$ | 상수 → 임펄스 |
| $e^{-at}u(t)$, $a>0$ | $\dfrac{1}{a+j\omega}$ | 단방향 지수 감쇠 |
| $e^{-a\|t\|}$, $a>0$ | $\dfrac{2a}{a^2+\omega^2}$ | 양방향 지수 감쇠 (실수) |
| rect$(t/2t_1)$ | $\dfrac{2\sin(\omega t_1)}{\omega}$ | 스퀘어 웨이브 → Sinc |

### 위상 계산법

$$\angle X(j\omega) = \angle(\text{분자}) - \angle(\text{분모})$$

$$\angle(a + j\omega) = \arctan\!\left(\frac{\omega}{a}\right)$$

실수 신호($X(j\omega)$가 실수): 위상 = 0 → 크기와 위상 따로 그리지 않음

### 자주 틀리는 포인트

- 역변환 앞에 $\dfrac{1}{2\pi}$ 곱하는 것 **절대 빠뜨리지 말 것**
- 단방향 지수의 적분 구간: $0$부터 $\infty$ ($u(t)$ 때문)
- 위상: 분자 위상 $-$ 분모 위상 (빼야 함)
- 이산시간에서 $\sin(\pi n)/(\pi n)$: 정수 $n$에서는 $\delta[n]$
- 스퀘어 웨이브의 CTFT = Sinc, Sinc의 CTFT = 스퀘어 웨이브 (쌍대성)

### 푸리에 급수 vs 푸리에 변환 비교

| | 푸리에 급수 (CTFS) | 푸리에 변환 (CTFT) |
|--|------------------|------------------|
| 대상 | 주기 신호 | **비주기** 신호 |
| 스펙트럼 | 이산 (이산 주파수) | **연속** (모든 $\omega$) |
| 계수 | $a_k$ (무차원) | $X(j\omega)$ (연속 함수) |
| 관계 | $T \cdot a_k = X(jk\omega_0)$ | $\leftarrow$ |
| 합산 | $\sum$ | $\int$ |

- 5장: 이산시간 푸리에 변환(DTFT)
