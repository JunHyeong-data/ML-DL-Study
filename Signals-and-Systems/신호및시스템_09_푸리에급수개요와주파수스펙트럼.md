## 1. 왜 주파수 영역으로 변환하는가

### 1-1. 시간 영역의 한계

**문제**: 임의의 주기 신호를 시간 영역에서 분리·분석하기 어렵다

```
시간 영역: x(t) = 하나의 복잡한 파형 → 성분 분리 불가
주파수 영역: X(ω) = 각 주파수 성분의 크기와 위상 → 성분 분리 가능
```

### 1-2. 고조파 분해

임의의 주기 신호는 **기본 주파수 $\omega_0$의 정수 배** 주파수를 가진 정현파들의 합으로 표현 가능:

$$x(t) = x_0 + A_1\cos(\omega_0 t) + A_2\cos(2\omega_0 t) + A_3\cos(3\omega_0 t) + \cdots$$

- $x_0$: 직류(DC) 성분 ($\omega = 0$)
- $A_1\cos(\omega_0 t)$: 기본파 (1차)
- $A_2\cos(2\omega_0 t)$: 2차 고조파
- $A_k\cos(k\omega_0 t)$: $k$차 고조파

### 1-3. 변환의 의미

> **변환(Transform)**: 신호 자체는 바뀌지 않고, **표현만** 바뀐다

$$x(t) \xleftrightarrow{\text{푸리에}} X(\omega)$$

- 시간 영역 $x(t)$와 주파수 영역 $X(\omega)$는 **같은 신호의 다른 표현**
- 에너지 손실 없음 (Lossless transform)

## 2. 신호의 정현파 표현과 스펙트럼

### 2-1. 정현파 표현의 장점

정현파 $A\cos(\omega_0 t + \phi)$는 세 가지 독립적인 정보를 포함:

| 파라미터 | 의미 |
|---------|------|
| $A$ | 진폭 (Amplitude) |
| $\omega_0 = 2\pi f_0$ | 주파수 (Frequency) |
| $\phi$ | 위상 (Phase) |

### 2-2. 오일러 공식으로 지수 표현으로 변환

$$A\cos(\omega_0 t + \phi) = \frac{A}{2}e^{j\phi}e^{j\omega_0 t} + \frac{A}{2}e^{-j\phi}e^{-j\omega_0 t}$$

→ $+\omega_0$와 $-\omega_0$ **두 주파수 성분**이 나타남

### 2-3. 스펙트럼 (Spectrum)

> **스펙트럼**: 주파수 축 위에 각 주파수 성분의 크기와 위상을 표시한 그래프

**진폭 스펙트럼**: 각 $\omega$에서의 크기 $|X(\omega)|$  
**위상 스펙트럼**: 각 $\omega$에서의 위상 $\angle X(\omega)$

**예**: $x(t) = A\cos(\omega_0 t + \phi)$의 스펙트럼

| $\omega$ | 진폭 | 위상 |
|---------|------|------|
| $+\omega_0$ | $A/2$ | $+\phi$ |
| $-\omega_0$ | $A/2$ | $-\phi$ |

### 2-4. 스펙트럼 예제

$$x(t) = \cos(3t - \tfrac{\pi}{4}) + \cos(4t - \tfrac{\pi}{3})$$

오일러 공식 적용 후 각 성분:

| $\omega$ | 진폭 | 위상 |
|---------|------|------|
| $+3$ | $1/2$ | $-\pi/4$ |
| $-3$ | $1/2$ | $+\pi/4$ |
| $+4$ | $1/2$ | $-\pi/3$ |
| $-4$ | $1/2$ | $+\pi/3$ |

> **핵심**: 실수 신호의 스펙트럼은 항상 $\pm\omega$ 쌍으로 나타나며,  
> 진폭은 대칭(우함수), 위상은 반대칭(기함수)

## 3. 기저 신호의 조건

### 3-1. 기저 신호(Basis Signal)란

신호를 표현하는 **기본 빌딩 블록** — 모든 신호를 기저 신호들의 **선형 결합**으로 표현

$$x(t) = \sum_k c_k \phi_k(t)$$

### 3-2. 기저 신호의 4가지 조건

| 조건 | 내용 |
|------|------|
| **간단한 형태** | 기본 신호이므로 단순해야 함 |
| **폭넓은 표현** | 다양한 신호를 표현할 수 있어야 함 |
| **시스템 응답이 편리** | 기저 신호 입력 → 출력 계산이 쉬워야 함 |
| **주파수 유일성** | 하나의 주파수 = 하나의 기저 신호 |

### 3-3. 정현파(사인파)가 기저 신호인 이유

정현파 입력 → LTI 시스템 출력 = **같은 주파수**의 정현파 (크기·위상만 변화)

$$A\cos(\omega_0 t + \phi) \xrightarrow{\text{LTI}} B\cos(\omega_0 t + \psi)$$

→ 주파수 $\omega_0$는 **불변**, $B$와 $\psi$만 달라짐  
→ 기저 신호로서 조건 ③, ④ 만족

## 4. 푸리에 급수 개요

### 4-1. 3~5장 로드맵

```
3장: 푸리에 급수 (Fourier Series)
  → 주기 신호에 적용
  → 이산 스펙트럼

4장: 연속시간 푸리에 변환 (CTFT)
  → 비주기 신호까지 확장

5장: 이산시간 푸리에 변환 (DTFT)
  → 이산시간 신호에 적용
```

### 4-2. 푸리에 급수 정의

주기 $T$ (기본 주기)인 신호 $x(t)$:

$$\boxed{x(t) = \sum_{k=-\infty}^{\infty} a_k\, e^{jk\omega_0 t}, \quad \omega_0 = \frac{2\pi}{T}}$$

- $k=0$: 직류 성분
- $k=\pm 1$: 기본파
- $k=\pm n$: $n$차 고조파
- $a_k$: **푸리에 계수** (구해야 할 가중치)

### 4-3. 핵심 과제

> **3장의 핵심**: 주어진 주기 신호 $x(t)$에서 푸리에 계수 $a_k$를 구하는 것

$$a_k = \frac{1}{T}\int_T x(t)\, e^{-jk\omega_0 t}\, dt$$

- 기저 신호 $e^{jk\omega_0 t}$: 오메가 값이 정해지면 **모두 알고 있음**
- $a_k$: **미지수** — 이것을 구하는 것이 목표

## 5. LTI 시스템의 고유함수: 복소 지수 신호

### 5-1. 고유함수의 개념

> LTI 시스템에 복소 지수 신호를 입력하면 **같은 복소 지수 신호**가 출력

$$e^{st} \xrightarrow{\text{LTI}} H(s)\, e^{st}$$

- 입력과 출력이 **같은 형태** (지수 형태 유지)
- 변하는 것은 **스칼라 $H(s)$** 뿐

### 5-2. 수식 유도

입력 $x(t) = e^{st}$, 임펄스 응답 $h(t)$인 LTI 시스템의 출력:

$$y(t) = \int_{-\infty}^{\infty} h(\tau)\, e^{s(t-\tau)}\, d\tau = e^{st} \int_{-\infty}^{\infty} h(\tau)\, e^{-s\tau}\, d\tau$$

$$\boxed{y(t) = H(s)\, e^{st}}$$

여기서:

$$H(s) = \int_{-\infty}^{\infty} h(\tau)\, e^{-s\tau}\, d\tau \quad \text{(라플라스 변환)}$$

### 5-3. 푸리에 변환과의 관계

$s = j\omega$로 치환하면:

$$H(j\omega) = \int_{-\infty}^{\infty} h(\tau)\, e^{-j\omega\tau}\, d\tau \quad \text{(푸리에 변환)}$$

$$y(t) = H(j\omega)\, e^{j\omega t}$$

| 변환 | 변수 | 의미 |
|------|------|------|
| 라플라스 | $s$ (복소수) | 더 일반적 |
| 푸리에 | $j\omega$ (순허수) | 라플라스의 특수한 경우 |

> **$s \to j\omega$**: 대부분의 경우 $s$ 자리에 $j\omega$를 넣으면 성립

---

## 6. 전달함수와 주파수 응답

### 6-1. 정의

$$H(j\omega) = \frac{Y(j\omega)}{X(j\omega)} = \int_{-\infty}^{\infty} h(t)\, e^{-j\omega t}\, dt$$

- **전달함수**: 주파수 영역에서 입력 대비 출력의 비
- 입력의 주파수는 바뀌지 않고, **크기와 위상만** 변화

### 6-2. 선형 결합 입력에 대한 출력

입력이 복소 지수들의 선형 결합이면:

$$x(t) = \sum_k a_k\, e^{j\omega_k t}$$

출력:

$$y(t) = \sum_k a_k\, H(j\omega_k)\, e^{j\omega_k t}$$

> 각 주파수 성분이 독립적으로 처리됨 → LTI 시스템 분석의 강력한 도구

## 7. 예제: 지연 시스템의 주파수 응답

**시스템**: $y(t) = x(t-3)$ (3초 지연)

### 방법 1: 직접 대입

입력 $x(t) = e^{j\omega t}$:

$$y(t) = e^{j\omega(t-3)} = e^{-3j\omega} \cdot e^{j\omega t}$$

$$\therefore H(j\omega) = e^{-3j\omega}$$

### 방법 2: 임펄스 응답 이용

$h(t) = \delta(t-3)$이므로:

$$H(j\omega) = \int_{-\infty}^{\infty} \delta(\tau-3)\, e^{-j\omega\tau}\, d\tau = e^{-3j\omega}$$

두 방법 모두 동일한 결과: $H(j\omega) = e^{-3j\omega}$

**주파수 응답 분석:**

$$|H(j\omega)| = |e^{-3j\omega}| = 1 \quad \text{(모든 주파수에서 크기 = 1)}$$

$$\angle H(j\omega) = -3\omega \quad \text{(선형 위상 지연)}$$

## 8. 핵심 요약 & 시험 포인트

### ✅ 반드시 외울 공식

**푸리에 급수:**

$$x(t) = \sum_{k=-\infty}^{\infty} a_k\, e^{jk\omega_0 t}, \qquad \omega_0 = \frac{2\pi}{T}$$

**푸리에 계수:**

$$a_k = \frac{1}{T}\int_T x(t)\, e^{-jk\omega_0 t}\, dt$$

**LTI 고유함수 성질:**

$$e^{j\omega t} \xrightarrow{\text{LTI}} H(j\omega)\, e^{j\omega t}$$

**지연 시스템 주파수 응답:**

$$y(t) = x(t-t_0) \;\Rightarrow\; H(j\omega) = e^{-j\omega t_0}$$

### ✅ 스펙트럼 읽는 법

- 실수 신호: 진폭 스펙트럼 **우함수** ($|X(-\omega)| = |X(\omega)|$)
- 실수 신호: 위상 스펙트럼 **기함수** ($$\angle X(-\omega) = -\angle X(\omega)$$)
- 주기 신호: **이산 스펙트럼** (정수 배 주파수에만 성분 존재)

### ✅ 자주 틀리는 포인트

- 기본 주파수 $f_0 = 1/T$, 각 주파수 $\omega_0 = 2\pi f_0 = 2\pi/T$
- 오일러 변환 후 $\pm\omega$ 양쪽에 성분이 생김 → 진폭이 반씩 나뉨
- $s = j\omega$: 라플라스 → 푸리에 치환
- 지연 $t_0$: 크기 변화 없이 위상만 $-\omega t_0$만큼 지연

### ✅ 다음 강의 예고

- 3장 본격 시작: 연속시간 푸리에 급수 계수 $a_k$ 계산
- 디리클레 조건 (수렴 조건)
- 구체적 신호에 대한 $a_k$ 유도 예제
