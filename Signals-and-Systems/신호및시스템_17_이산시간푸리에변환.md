## 1. 왜 이산시간 푸리에 변환을 배우는가

### 챕터 흐름

| 챕터 | 내용 |
|------|------|
| 1장 | 신호와 시스템 기초 |
| 2장 | LTI 시스템 |
| 3장 | 푸리에 급수 (주기 신호, 특수한 경우) |
| 4장 | CTFT — 연속시간 비주기 신호 (일반적) |
| **5장** | **DTFT — 이산시간 비주기 신호** |
| 7장 | 샘플링 |

### 이산시간이 더 중요한 이유

실제로 사용하는 신호의 대부분이 **컴퓨터를 통한 디지털 신호** → 이산시간 처리가 필수.

대부분의 DTFT 성질은 CTFT와 동일하고, **차이나는 부분**에만 집중하면 된다.

## 2. DTFT 공식 유도

### 출발점: 이산시간 푸리에 급수(DTFS)

주기 $N$인 주기 신호 $\tilde{x}[n]$의 DTFS:

$$\tilde{x}[n] = \sum_{k=\langle N \rangle} a_k\, e^{jk(2\pi/N)n}, \quad a_k = \frac{1}{N}\sum_{n=\langle N \rangle} \tilde{x}[n]\, e^{-jk(2\pi/N)n}$$

### 유도 과정

**Step 1**: $a_k$를 $X(e^{j\omega})$로 정의

$$X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x[n]\, e^{-j\omega n}$$

이를 이용하면 $a_k = \frac{1}{N} X(e^{j\omega})\big|_{\omega = k(2\pi/N)}$

**Step 2**: 주기 $N \to \infty$ (비주기 신호로 확장)

$$\frac{2\pi}{N} \to d\omega, \quad \sum_k \to \frac{1}{2\pi}\int_{-\pi}^{\pi}$$

### 최종 공식: 반드시 암기 ⭐

**DTFT (분석):**

$$\boxed{X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x[n]\, e^{-j\omega n}}$$

**역 DTFT (합성):**

$$\boxed{x[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega})\, e^{j\omega n}\, d\omega}$$

### 표기법

$$x[n] \xleftrightarrow{\mathcal{F}} X(e^{j\omega})$$

## 3. DTFT와 CTFT 핵심 차이

### 가장 큰 차이: 스펙트럼의 주기성

| 항목 | CTFT | DTFT |
|------|------|------|
| 대상 신호 | 연속시간 비주기 | **이산시간** 비주기 |
| 스펙트럼 | **비주기** (연속, $-\infty < \omega < \infty$) | **$2\pi$ 주기** ($-\pi \sim \pi$ 반복) |
| 역변환 적분 범위 | $-\infty \sim \infty$ | $-\pi \sim \pi$ (한 주기) |
| 최고 주파수 | 무한대 | $\omega = \pi$ |
| 최저 주파수 | 0 | $\omega = 0$ |

> **DTFT 핵심**: $X(e^{j\omega})$는 $2\pi$ 주기 함수이므로 **$-\pi \sim \pi$ 구간만** 보면 된다.

$$X(e^{j(\omega + 2\pi)}) = X(e^{j\omega})$$

## 4. 이산시간 신호의 고주파 판별법

### 물리적 의미

| 주파수 | 이산시간 신호 특성 |
|--------|-----------------|
| $\omega = 0$ (저주파) | 천천히 변하는 신호 |
| $\omega = \pi$ (최고주파) | 매 샘플마다 부호가 바뀌는 신호 ($+1, -1, +1, -1, \ldots$) |

### 판별법: $-\pi \sim \pi$ 구간만 보기

두 신호 $x_1[n]$, $x_2[n]$의 스펙트럼을 비교할 때:

- **$\omega \approx 0$ 근처에 에너지 집중** → 저주파 신호
- **$\omega \approx \pm\pi$ 근처에 에너지 집중** → 고주파 신호

예: 같은 삼각형(Sinc) 모양이더라도 $\pi$만큼 이동하면 저주파↔고주파가 바뀜.

## 5. 예제 5.1 — 단방향 지수 감쇠 신호

### 문제

$$x[n] = a^n u[n], \quad |a| < 1$$

### 풀이

$$X(e^{j\omega}) = \sum_{n=0}^{\infty} a^n e^{-j\omega n} = \sum_{n=0}^{\infty} (ae^{-j\omega})^n$$

등비급수 ($|ae^{-j\omega}| = |a| < 1$이면 수렴):

$$\boxed{X(e^{j\omega}) = \frac{1}{1 - ae^{-j\omega}}}$$

### 암기 필수 변환 쌍 ⭐

$$a^n u[n] \xleftrightarrow{\mathcal{F}} \frac{1}{1 - ae^{-j\omega}}, \quad |a| < 1$$

### 경우 분류 (a의 부호에 따른 스펙트럼 특성)

**$a > 0$인 경우**: $\omega = 0$ 근처에 에너지 집중 → **로우패스 특성**

**$a < 0$인 경우**: $\omega = \pm\pi$ 근처에 에너지 집중 → **하이패스 특성**

---

## 6. 예제 5.2 — 양방향 지수 감쇠 신호

### 문제

$$x[n] = a^{|n|}, \quad |a| < 1$$

### 풀이 (구간 분할)

$$X(e^{j\omega}) = \sum_{n=-\infty}^{-1} a^{-n} e^{-j\omega n} + \sum_{n=0}^{\infty} a^n e^{-j\omega n}$$

**두 번째 구간** ($n \geq 0$): 예제 5.1과 동일

$$\sum_{n=0}^{\infty} a^n e^{-j\omega n} = \frac{1}{1 - ae^{-j\omega}}$$

**첫 번째 구간** ($n < 0$): $m = -n$ 치환

$$\sum_{n=-\infty}^{-1} a^{-n} e^{-j\omega n} = \sum_{m=1}^{\infty} (ae^{j\omega})^m = \frac{ae^{j\omega}}{1 - ae^{j\omega}}$$

**합산**:

$$X(e^{j\omega}) = \frac{1}{1 - ae^{-j\omega}} + \frac{ae^{j\omega}}{1 - ae^{j\omega}}$$

정리하면:

$$\boxed{X(e^{j\omega}) = \frac{1 - a^2}{1 - 2a\cos\omega + a^2}}$$

### 특성

- $X(e^{j\omega})$가 **실수** → 우함수 신호의 특성
- $\omega = 0$ 근처에 피크 → 저주파 특성

### 레조넌스(Resonance) 개념

특정 주파수에서 날카로운 피크를 갖는 스펙트럼 형태. 분모 $1 - 2a\cos\omega + a^2$가 최솟값을 가질 때 피크 발생. $|a|$가 1에 가까울수록 피크가 좁고 날카로워짐 (레조넌스 심화).

## 7. 예제 5.3 — 이산시간 스퀘어 웨이브

### 문제

$$x[n] = \begin{cases} 1 & |n| \leq N_1 \\ 0 & N_1 < |n| \leq N/2 \end{cases}, \quad \text{비주기 버전}$$

### 풀이

$$X(e^{j\omega}) = \sum_{n=-N_1}^{N_1} e^{-j\omega n}$$

3장 예제 3.12와 동일한 계산 (단, DTFS 아닌 DTFT):

$$\boxed{X(e^{j\omega}) = \frac{\sin[\omega(N_1 + 1/2)]}{\sin(\omega/2)}}$$

### 그래프 특성

- 이산시간 Sinc 형태
- $-\pi \sim \pi$ 구간에서 정의되며, $2\pi$ 주기로 반복
- $\omega = 0$에서 최댓값 $2N_1 + 1$

## 8. DTFT 수렴 조건

### 두 가지 조건 (하나만 만족하면 됨)

**조건 1**: 절대 합 유한

$$\sum_{n=-\infty}^{\infty} |x[n]| < \infty$$

**조건 2**: 에너지 유한 (L2 신호)

$$\sum_{n=-\infty}^{\infty} |x[n]|^2 < \infty$$

### 주기 신호의 경우

주기 신호는 에너지가 무한대 → 수렴 조건 불만족 → **임펄스 함수 $\delta(\omega)$를 포함**시켜 DTFT 정의 가능 (CTFT와 동일한 접근).

---

## 9. 주기 신호의 DTFT

### 결론

CTFT에서와 마찬가지로, 주기 신호의 DTFT는 **임펄스 열**로 나타난다.

복소 지수 $e^{j\omega_0 n}$의 DTFT:

$$e^{j\omega_0 n} \xleftrightarrow{\mathcal{F}} 2\pi \sum_{k=-\infty}^{\infty} \delta(\omega - \omega_0 - 2\pi k)$$

$2\pi$ 주기이므로 임펄스가 $2\pi$ 간격으로 반복된다.

일반 주기 신호 $x[n] = \sum_k a_k e^{jk\omega_0 n}$의 DTFT:

$$X(e^{j\omega}) = 2\pi \sum_{k=-\infty}^{\infty} a_k\, \delta(\omega - k\omega_0)$$

## 10. 예제 5.5 — 코사인 신호의 DTFT

### 문제

$$x[n] = \cos(\omega_0 n), \quad \omega_0 = \frac{\pi}{5}$$

### 풀이

오일러 공식으로 분해:

$$\cos(\omega_0 n) = \frac{1}{2} e^{j\omega_0 n} + \frac{1}{2} e^{-j\omega_0 n}$$

각 항의 DTFT:

$$\frac{1}{2} e^{j\omega_0 n} \xleftrightarrow{\mathcal{F}} \pi \sum_k \delta(\omega - \omega_0 - 2\pi k)$$

$$\frac{1}{2} e^{-j\omega_0 n} \xleftrightarrow{\mathcal{F}} \pi \sum_k \delta(\omega + \omega_0 - 2\pi k)$$

최종 결과 ($-\pi \sim \pi$ 구간):

$$\boxed{X(e^{j\omega}) = \pi\,\delta(\omega - \omega_0) + \pi\,\delta(\omega + \omega_0)}$$

$\omega = \pm\omega_0$에서 크기 $\pi$인 임펄스 두 개. $2\pi$ 주기로 반복.

## 11. 예제 5.6 — 임펄스 열의 DTFT

### 문제

$$x[n] = \sum_{k=-\infty}^{\infty} \delta[n - kN]$$

$N$의 정수 배마다 임펄스가 발생하는 주기 신호.

### CTFS 계수 계산

한 주기 안에 임펄스가 하나뿐이므로:

$$a_k = \frac{1}{N} \sum_{n=\langle N \rangle} x[n]\, e^{-jk(2\pi/N)n} = \frac{1}{N}$$

### DTFT 계산

$$X(e^{j\omega}) = 2\pi \sum_{k=-\infty}^{\infty} a_k\, \delta(\omega - k\cdot\frac{2\pi}{N}) = \frac{2\pi}{N} \sum_{k=-\infty}^{\infty} \delta\!\left(\omega - \frac{2\pi k}{N}\right)$$

### 결과 해석

- $\omega = \frac{2\pi k}{N}$ 마다 임펄스 발생 → 간격: $\frac{2\pi}{N}$
- $N$이 클수록 임펄스 간격이 좁아짐
- $N \to \infty$ (비주기 신호): 임펄스 간격 $\to 0$ → 상수 스펙트럼

$$\delta[n] \xleftrightarrow{\mathcal{F}} 1 \quad \text{(이산시간 임펄스의 DTFT는 상수 1)}$$

## 12. DTFT의 성질

### CTFT와 동일한 성질

대부분의 성질은 CTFT와 같다. **차이나는 부분**만 정리:

### 성질 1: 주기성 (DTFT 고유 성질) ⭐

$$X(e^{j(\omega + 2\pi)}) = X(e^{j\omega})$$

CTFT에는 없는 성질. 이산시간 스펙트럼은 항상 $2\pi$ 주기.

### 성질 2: 시간 이동

$$x[n - n_0] \xleftrightarrow{\mathcal{F}} e^{-j\omega n_0} X(e^{j\omega})$$

CTFT와 동일한 형태. 크기 불변, 위상만 $-\omega n_0$만큼 변화.

### 성질 3: 주파수 이동 (변조)

$$e^{j\omega_0 n} x[n] \xleftrightarrow{\mathcal{F}} X(e^{j(\omega - \omega_0)})$$

타임 도메인에서 $e^{j\omega_0 n}$을 곱하면 주파수 스펙트럼이 $\omega_0$만큼 이동.

### 성질 4: 컨볼루션

$$x[n] \ast h[n] \xleftrightarrow{\mathcal{F}} X(e^{j\omega}) \cdot H(e^{j\omega})$$

타임 도메인 컨볼루션 = 주파수 도메인 곱 (CTFT와 동일).

### 성질 5: 켤레 대칭 (실수 신호)

$x[n]$이 실수이면:

$$X(e^{-j\omega}) = X^{\ast}(e^{j\omega})$$

- 크기 스펙트럼: $|X(e^{j\omega})| = |X(e^{-j\omega})|$ → 우함수
- 위상 스펙트럼: $\angle X(e^{j\omega}) = -\angle X(e^{-j\omega})$ → 기함수

### CTFT vs DTFT 성질 비교표

| 성질 | CTFT | DTFT |
|------|------|------|
| 선형성 | $\alpha X + \beta Y$ | 동일 |
| 시간 이동 | $e^{-j\omega t_0} X(j\omega)$ | $e^{-j\omega n_0} X(e^{j\omega})$ |
| 주파수 이동 | $X(j(\omega-\omega_0))$ | $X(e^{j(\omega-\omega_0)})$ |
| 컨볼루션 | $X \cdot H$ | 동일 |
| **주기성** | **없음** | **$2\pi$ 주기** ← 핵심 차이 |
| 역변환 범위 | $(-\infty, \infty)$ | $(-\pi, \pi)$ |

## 13. 예제 5.7 — 로우패스 ↔ 하이패스 변환

### 로우패스 필터의 임펄스 응답

아이디얼 LPF ($|\omega| \leq \omega_c$에서 통과):

$$h_{LP}[n] = \frac{\omega_c}{\pi} \text{sinc}\!\left(\frac{\omega_c n}{\pi}\right)$$

주파수 응답: $H_{LP}(e^{j\omega})$는 $|\omega| \leq \omega_c$에서 1, 그 외 0.

### 로우패스 → 하이패스 변환

주파수 도메인에서 $\pi$만큼 이동하면 LPF가 HPF로 변환:

$$H_{HP}(e^{j\omega}) = H_{LP}(e^{j(\omega - \pi)})$$

주파수 이동 성질의 역방향 적용:

$$h_{HP}[n] = e^{j\pi n} \cdot h_{LP}[n] = (-1)^n \cdot h_{LP}[n]$$

$e^{j\pi n} = (\cos\pi n + j\sin\pi n) = (-1)^n$ ($n$이 정수이므로)

### 결론

$$\boxed{h_{HP}[n] = (-1)^n \cdot h_{LP}[n]}$$

**로우패스 임펄스 응답에 $(-1)^n$을 곱하면 하이패스 필터가 된다.**

### 직관적 이해

$(-1)^n$을 곱하는 것 = 매 샘플마다 부호를 바꾸는 것 = $\omega = \pi$로 변조
→ 스펙트럼이 $\pi$만큼 이동 → LPF → HPF

## 14. 핵심 요약 & 시험 포인트

### 반드시 암기할 공식

**DTFT:**

$$\boxed{X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x[n]\, e^{-j\omega n}}$$

**역 DTFT:**

$$\boxed{x[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega})\, e^{j\omega n}\, d\omega}$$

### 반드시 암기할 변환 쌍

| $x[n]$ | $X(e^{j\omega})$ | 조건 |
|--------|-----------------|------|
| $\delta[n]$ | $1$ | — |
| $1$ | $2\pi\sum_k \delta(\omega - 2\pi k)$ | 주기 신호 |
| $a^n u[n]$ | $\dfrac{1}{1-ae^{-j\omega}}$ | $\|a\| < 1$ |
| $a^{\|n\|}$ | $\dfrac{1-a^2}{1-2a\cos\omega+a^2}$ | $\|a\| < 1$ |
| $\cos(\omega_0 n)$ | $\pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]$ | $-\pi<\omega<\pi$ |

### CTFT와 DTFT 한눈에 비교

| | CTFT | DTFT |
|--|------|------|
| 변환 | $\int_{-\infty}^{\infty} x(t)e^{-j\omega t}dt$ | $\sum_{n=-\infty}^{\infty} x[n]e^{-j\omega n}$ |
| 역변환 | $\frac{1}{2\pi}\int_{-\infty}^{\infty} X e^{j\omega t}d\omega$ | $\frac{1}{2\pi}\int_{-\pi}^{\pi} X e^{j\omega n}d\omega$ |
| 스펙트럼 | 비주기 | **$2\pi$ 주기** |
| 최고 주파수 | $\infty$ | $\pi$ |
| 임펄스 변환 | $\delta(t) \to 1$ | $\delta[n] \to 1$ |

### 자주 틀리는 포인트

- 역 DTFT 적분 범위: $-\pi \sim \pi$ (CTFT처럼 $-\infty \sim \infty$가 아님)
- 이산시간 최고 주파수: $\omega = \pi$ (무한대가 아님)
- DTFT 스펙트럼은 **항상 $2\pi$ 주기** — 따라서 $-\pi \sim \pi$만 보면 됨
- $a > 0$이면 LPF 특성, $a < 0$이면 HPF 특성 ($a^n u[n]$)
- 로우패스 → 하이패스: 임펄스 응답에 $(-1)^n$ 곱하기
- 주기 신호의 DTFT: 임펄스 열 (크기 $2\pi a_k$)
