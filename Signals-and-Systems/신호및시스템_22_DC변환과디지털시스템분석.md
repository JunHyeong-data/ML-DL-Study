## 2. D/C 변환 (D/A 컨버터)

### 개념: C/D의 역과정

C/D 변환이 CT 신호를 DT 수열로 바꾸는 것이라면,  
D/C 변환은 DT 수열을 다시 CT 신호로 복원하는 과정.

```
y[n]: 수열 (순서 정보만 있음)
        ↓ D/C 변환
y_c(t): 연속시간 신호 (시간 정보 복원)
```

### D/C 변환 2단계

**1단계**: 수열 $y[n]$ → 임펄스 트레인 $y_p(t)$

- 샘플링 주기 $T$의 배수가 되는 점마다 임펄스 생성
- 각 임펄스의 크기 = 해당 샘플값

$$y_p(t) = \sum_{n=-\infty}^{\infty} y[n]\, \delta(t - nT)$$

```
y[n]:  수열                y_p(t): 임펄스 트레인 (CT 신호)
   ↑  ↑  ↑  ↑                 ↑     ↑     ↑     ↑
   |  |  |  |       →          |     |     |     |
→ n 0  1  2  3              → t 0    T    2T    3T
(순서만)                      (시간 정보 복원됨)
```

**2단계**: $y_p(t)$ → Ideal LPF → $y_c(t)$

- 컷오프 주파수 $\omega_c = \omega_s/2$, 이득 $T$
- LPF가 임펄스 트레인의 고주파 성분 제거 → 부드러운 CT 신호

$$y_c(t) = y_p(t) \ast h_r(t)$$

### 전체 D/C 변환 흐름

$$y[n] \xrightarrow{\text{impulse train}} y_p(t) \xrightarrow{\text{Ideal LPF}} y_c(t)$$

## 3. 전체 디지털 처리 시스템 분석

### 완전한 시스템 블록도

```
x_c(t)                                               y_c(t)
   |                                                     ↑
   ↓                                                     |
[× p(t)]→ x_p(t) →[C/D 변환]→ x[n] →[H_d(e^{jΩ})]→ y[n] →[D/C 변환]→ [Ideal LPF]
```

각 단계별 신호:

| 신호 | 도메인 | 의미 |
|------|--------|------|
| $x_c(t)$ | CT | 연속시간 입력 |
| $x_p(t)$ | CT | 임펄스 트레인 곱, $x_p(t) = x_c(t) \cdot p(t)$ |
| $x[n]$ | DT | 이산시간 신호, $x[n] = x_c(nT)$ |
| $y[n]$ | DT | DT 시스템 출력 |
| $y_p(t)$ | CT | 임펄스 트레인 형태로 복원 |
| $y_c(t)$ | CT | 최종 연속시간 출력 |

### 주파수 영역에서의 전체 흐름

입력 $X_c(j\omega)$: 삼각형 펄스 형태 (밴드리미티드, $|\omega| \leq \omega_M$)

**① C/D 변환 후** $X_p(j\omega)$:

$$X_p(j\omega) = \frac{1}{T} \sum_{k=-\infty}^{\infty} X_c(j(\omega - k\omega_s))$$

→ $\omega_s$ 간격으로 반복, $\frac{1}{T}$ 배 스케일

**② DT 도메인** $X_d(e^{j\Omega})$:

$$X_d(e^{j\Omega}) = X_p\!\left(j\frac{\Omega}{T}\right) \cdot T$$

→ 주파수 축 스케일만 변환 ($\omega \to \Omega = \omega T$), 모양은 동일

**③ DT 시스템 처리** $Y_d(e^{j\Omega})$:

$$Y_d(e^{j\Omega}) = H_d(e^{j\Omega}) \cdot X_d(e^{j\Omega})$$

**④ D/C 변환 후** $Y_p(j\omega)$:

$Y_d(e^{j\Omega})$에서 역스케일링 ($\Omega \to \omega T$):

$$Y_p(j\omega) = Y_d(e^{j\omega T}) \cdot \frac{1}{T}$$

**⑤ Ideal LPF 적용** (이득 $T$, 컷오프 $\omega_s/2$):

$$Y_c(j\omega) = T \cdot Y_p(j\omega) \quad (|\omega| \leq \omega_s/2)$$

→ $\frac{1}{T}$와 $T$가 상쇄 → 원래 스케일로 복원

## 4. $H_c(j\omega)$와 $H_d(e^{j\Omega})$의 관계

### 핵심 목표

전체 시스템을 하나의 CT 시스템으로 등가 표현:

$$Y_c(j\omega) = H_c(j\omega) \cdot X_c(j\omega)$$

이 $H_c(j\omega)$를 $H_d(e^{j\Omega})$로 표현하는 것이 목표.

### 관계식 유도

위 흐름을 정리하면:

$$Y_c(j\omega) = H_d(e^{j\omega T}) \cdot X_c(j\omega) \quad (|\omega| \leq \omega_s/2)$$

따라서:

$$\boxed{H_c(j\omega) = H_d(e^{j\Omega})\Big|_{\Omega = \omega T}}$$

즉, CT 주파수 응답 $H_c(j\omega)$는 DT 주파수 응답 $H_d(e^{j\Omega})$에서  
$\Omega$ 대신 $\omega T$를 대입한 것.

### 반대 방향 (DT → CT)

$$H_d(e^{j\Omega}) = H_c\!\left(j\frac{\Omega}{T}\right) \quad (|\Omega| \leq \pi)$$

$H_c$에서 $\omega$ 대신 $\Omega/T$를 대입.

### 직관적 이해

```
H_c(jω):              H_d(e^{jΩ}):
   │                      │
   │  같은 모양            │  같은 모양
   │                      │
-ω_c  0   ω_c → ω     -π   0   π → Ω

차이: 주파수 축 스케일만 다름
      ω_c = π/T = ω_s/2 에 대응
```

## 5. 조건: 밴드리미티드 제한

### 위 관계식이 성립하는 조건

$$\boxed{H_c(j\omega) = 0 \quad \text{for } |\omega| > \frac{\omega_s}{2}}$$

즉, CT 주파수 응답이 **샘플링 주파수의 절반 이하로 밴드리미티드** 되어 있어야 함.

### 조건의 의미

DT 시스템의 주파수 범위가 $|\Omega| \leq \pi$로 제한되어 있기 때문에,  
이에 대응하는 CT 주파수 범위도 $|\omega| \leq \pi/T = \omega_s/2$로 제한되어야 함.

```
H_c(jω) 조건:
   ↑ 1
   |████████|         |████████|
   |        |         |        |
   |        |_________|        |
-ω_s/2      0      ω_s/2  → ω
         (이 구간만 허용)
```

이 조건을 만족하면:

$$H_c(j\omega) = H_d(e^{j\omega T}) \quad (|\omega| \leq \omega_s/2)$$

## 6. 예제 1 — 미분기 (Differentiator)

### 문제 설정

CT 미분 시스템을 DT 시스템으로 구현하고자 함.

**CT 미분기의 주파수 응답**:

$$H_c(j\omega) = j\omega$$

**입력 신호**: 밴드리미티드 Sinc 펄스

$$x_c(t) = \frac{\sin(\omega_c t)}{\pi t}, \quad \omega_c = \frac{\omega_s}{2}$$

CTFT:

$$X_c(j\omega) = \begin{cases} 1 & |\omega| \leq \omega_c \\ 0 & |\omega| > \omega_c \end{cases}$$

→ 밴드리미티드 ✓ → 앞서 유도한 관계 사용 가능

### Step 1: DT 주파수 응답 구하기

$\Omega = \omega T$ 관계를 이용해 $H_c(j\omega)$에서 $H_d(e^{j\Omega})$ 유도:

$$H_d(e^{j\Omega}) = H_c\!\left(j\frac{\Omega}{T}\right) = j\frac{\Omega}{T}$$

범위: $|\Omega| \leq \pi$

$$\boxed{H_d(e^{j\Omega}) = \frac{j\Omega}{T}, \quad |\Omega| \leq \pi}$$

### Step 2: DT 임펄스 응답 구하기 (Sinc 입력 활용)

**직접 IDTFT 계산 대신** Sinc 입력을 이용하는 방법:

1. $x_c(t) = \dfrac{\sin(\omega_c t)}{\pi t}$ 를 샘플링:

$$x[n] = x_c(nT) = \frac{\sin(\omega_c nT)}{\pi nT} = \frac{\sin(\pi n)}{\pi nT}$$

$\omega_c = \omega_s/2 = \pi/T$ 이므로:

$$x[n] = \frac{\sin(\pi n)}{\pi nT} = \begin{cases} \dfrac{1}{T} & n = 0 \\ 0 & n \neq 0 \end{cases} = \frac{1}{T}\delta[n]$$

→ 입력이 $\frac{1}{T}\delta[n]$이 됨 (임펄스 입력!)

2. CT 출력 계산:

$$y_c(t) = \frac{d}{dt} x_c(t) = \frac{d}{dt}\left(\frac{\sin(\omega_c t)}{\pi t}\right)$$

미분 결과:

$$y_c(t) = \frac{\omega_c \cos(\omega_c t) \cdot \pi t - \sin(\omega_c t) \cdot \pi}{\pi^2 t^2} = \frac{\omega_c \cos(\omega_c t)}{\pi t} - \frac{\sin(\omega_c t)}{\pi t^2}$$

3. DT 출력 = CT 출력의 샘플링:

$$y[n] = y_c(nT)$$

$n \neq 0$일 때:

$$y[n] = \frac{\omega_c \cos(\omega_c nT)}{\pi nT} - \frac{\sin(\omega_c nT)}{\pi (nT)^2}$$

$\omega_c = \pi/T$를 대입하면 $\sin(\pi n) = 0$이므로:

$$y[n] = \frac{(\pi/T)\cos(\pi n)}{\pi nT} = \frac{\cos(\pi n)}{nT^2} = \frac{(-1)^n}{nT^2}$$

$n = 0$일 때: L'Hôpital 적용 → $y[0] = 0$

4. 임펄스 응답: 입력이 $\frac{1}{T}\delta[n]$이었으므로

$$h_d[n] = T \cdot y[n]$$

$$\boxed{h_d[n] = \begin{cases} 0 & n = 0 \\ \dfrac{(-1)^n}{nT} & n \neq 0 \end{cases}}$$

## 7. 예제 2 — 하프 샘플 딜레이 (Half-Sample Delay)

### 문제 설정

CT에서 $\tau = T/2$만큼 딜레이를 주는 시스템을 DT로 구현:

$$y_c(t) = x_c\!\left(t - \frac{T}{2}\right)$$

### CT 주파수 응답

시간 이동 성질에 의해:

$$H_c(j\omega) = e^{-j\omega \tau} = e^{-j\omega T/2}$$

### 밴드리미티드 조건 적용

컷오프를 $\omega_s/2$로 제한:

$$H_c(j\omega) = \begin{cases} e^{-j\omega T/2} & |\omega| \leq \dfrac{\omega_s}{2} \\ 0 & |\omega| > \dfrac{\omega_s}{2} \end{cases}$$

### Step 1: DT 주파수 응답 구하기

$\omega = \Omega/T$ 대입:

$$H_d(e^{j\Omega}) = H_c\!\left(j\frac{\Omega}{T}\right) = e^{-j\Omega/2}, \quad |\Omega| \leq \pi$$

$$\boxed{H_d(e^{j\Omega}) = e^{-j\Omega/2}, \quad |\Omega| \leq \pi}$$

### DT 딜레이로의 해석

일반적으로 DT에서 $N$ 샘플 딜레이의 주파수 응답: $e^{-j\Omega N}$

여기서 $e^{-j\Omega/2}$는 $N = 1/2$ 샘플에 해당 → **정수 샘플이 아님**

→ DT에서는 직접 구현 불가능 → CT에서 먼저 $T/2$ 딜레이 후 샘플링

### Step 2: DT 임펄스 응답 구하기 (Sinc 입력 활용)

입력: $x_c(t) = \dfrac{\sin(\omega_c t)}{\pi t}$, 동일하게 $x[n] = \dfrac{1}{T}\delta[n]$

CT 출력:

$$y_c(t) = x_c\!\left(t - \frac{T}{2}\right) = \frac{\sin\!\left(\omega_c\!\left(t - \dfrac{T}{2}\right)\right)}{\pi\!\left(t - \dfrac{T}{2}\right)}$$

DT 출력 (샘플링):

$$y[n] = y_c(nT) = \frac{\sin\!\left(\omega_c\!\left(nT - \dfrac{T}{2}\right)\right)}{\pi\!\left(nT - \dfrac{T}{2}\right)}$$

$\omega_c = \pi/T$ 대입:

$$y[n] = \frac{\sin\!\left(\pi n - \dfrac{\pi}{2}\right)}{\pi T\!\left(n - \dfrac{1}{2}\right)}$$

삼각함수 정리 $\sin(\pi n - \pi/2) = -\cos(\pi n) = -(-1)^n$:

$$y[n] = \frac{-(-1)^n}{\pi T\!\left(n - \dfrac{1}{2}\right)} = \frac{(-1)^{n+1}}{\pi T\!\left(n - \dfrac{1}{2}\right)}$$

임펄스 응답 ($T$ 곱하기):

$$\boxed{h_d[n] = T \cdot y[n] = \frac{(-1)^{n+1}}{\pi\!\left(n - \dfrac{1}{2}\right)}}$$

### 물리적 해석

```
x_c(t):   ~~~~~~~~         (원래 Sinc 파형)
y_c(t):      ~~~~~~~~      (T/2만큼 오른쪽으로 이동)

샘플링:
x[n]:  ↑(n=0만 1/T)
y[n]:  샘플 사이 중간 지점의 값들로 구성
       → 정수 샘플 위치에서 "T/2 딜레이된 값"
```

CT에서 $T/2$ 딜레이 → DT에서 "비정수 샘플 위치"의 값을 계산하는 것.  
→ 이것이 직접 DT 딜레이로 구현이 어려운 이유이며, CT 처리 후 샘플링으로 해결.

## 8. 핵심 요약 & 시험 포인트

### 반드시 암기할 관계식

**D/C 변환 관계**:

$$y_p(t) = \sum_{n=-\infty}^{\infty} y[n]\, \delta(t - nT)$$

**CT↔DT 주파수 응답 변환** (가장 중요):

$$\boxed{H_c(j\omega) = H_d(e^{j\Omega})\Big|_{\Omega = \omega T}}$$

$$\boxed{H_d(e^{j\Omega}) = H_c\!\left(j\frac{\Omega}{T}\right)}$$

**사용 조건**:

$$H_c(j\omega) = 0 \quad \text{for } |\omega| > \frac{\omega_s}{2}$$

### Sinc 입력을 이용한 임펄스 응답 계산법

임펄스 응답을 IDTFT 없이 구하는 방법:

| 단계 | 내용 |
|------|------|
| 1 | 입력을 Sinc 펄스로 설정: $x_c(t) = \sin(\omega_c t)/(\pi t)$ |
| 2 | 샘플링하면 자동으로 $\delta[n]/T$ 가 됨 |
| 3 | CT 시스템에서 출력 $y_c(t)$ 계산 |
| 4 | $y_c(t)$ 를 샘플링하면 $y[n]$ |
| 5 | $h_d[n] = T \cdot y[n]$ |

### 예제 결과 정리

**예제 1: 미분기** ($H_c(j\omega) = j\omega$)

$$H_d(e^{j\Omega}) = \frac{j\Omega}{T}$$

$$h_d[n] = \begin{cases} 0 & n = 0 \\ \dfrac{(-1)^n}{nT} & n \neq 0 \end{cases}$$

**예제 2: 하프 샘플 딜레이** ($H_c(j\omega) = e^{-j\omega T/2}$)

$$H_d(e^{j\Omega}) = e^{-j\Omega/2}$$

$$h_d[n] = \frac{(-1)^{n+1}}{\pi\!\left(n - \dfrac{1}{2}\right)}$$

### 전체 시스템 흐름 요약

| 단계 | 변환 | 주파수 영역 관계 |
|------|------|----------------|
| C/D | $x[n] = x_c(nT)$ | $X_d(e^{j\Omega}) = X_p(j\Omega/T) \cdot T$ |
| DT 처리 | $Y_d = H_d \cdot X_d$ | 주파수 영역 곱셈 |
| D/C | $y_p(t) = \sum y[n]\delta(t-nT)$ | $Y_p(j\omega) = Y_d(e^{j\omega T})/T$ |
| LPF | 이득 $T$, 컷오프 $\omega_s/2$ | $Y_c(j\omega) = T \cdot Y_p(j\omega)$ ($|\omega| \leq \omega_s/2$ 구간) |

### 자주 틀리는 포인트

- $H_d$ → $H_c$ 변환: $\Omega$ 대신 $\omega T$ 대입 (나누는 게 아님)
- $H_c$ → $H_d$ 변환: $\omega$ 대신 $\Omega/T$ 대입
- Sinc 입력 샘플링 결과가 $\delta[n]/T$가 되는 이유: $\sin(\pi n) = 0$ ($n \neq 0$), $\lim_{t\to 0} \sin(\omega_c t)/(\pi t) = \omega_c/\pi = 1/T$
- 하프 샘플 딜레이는 DT에서 **직접 구현 불가** → CT에서 처리 후 샘플링

### 시험 범위 안내 (강의에서 언급)

- **시험 범위**: 4장, 5장, 7장
- **제외**: 6장 (기말고사 범위 아님)
