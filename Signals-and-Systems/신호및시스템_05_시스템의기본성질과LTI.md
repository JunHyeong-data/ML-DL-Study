## 2. 시스템 성질 개요

시스템의 기본 성질 6가지:

| 성질 | 영어 | 중요도 |
|------|------|--------|
| **선형성** | Linearity | ⭐⭐⭐ |
| **시불변성** | Time-Invariance | ⭐⭐⭐ |
| **인과성** | Causality | ⭐⭐ |
| **메모리** | Memory | ⭐⭐ |
| **가역성** | Invertibility | ⭐ |
| **안정성** | Stability | ⭐ |

> 선형성 + 시불변성 = **LTI 시스템** → 이 과목 전체의 핵심 대상

**판별 방법 (공통)**: 반드시 **정의에 입각**하여 증명

## 3. 선형성 (Linearity)

### 3-1. 정의 — 중첩의 원리

입력 $x_1 \to$ 출력 $y_1$, 입력 $x_2 \to$ 출력 $y_2$일 때:

$$ax_1 + bx_2 \;\to\; ay_1 + by_2$$

두 조건을 동시에 만족해야 함:

**① 가산성 (Additivity):**
$$x_1 + x_2 \to y_1 + y_2$$

**② 동차성 (Homogeneity / Scaling):**
$$ax_1 \to ay_1$$

> 연속시간과 이산시간 모두 **동일한 정의** 적용

### 3-2. 비선형 시스템 판별 quick tip

> 입력이 0일 때 출력이 0이 아니면 → **비선형 시스템** (바로 판별 가능)

### 3-3. 예제 풀이

**예제 1**: $y(t) = t \cdot x(t)$ — 선형?

$x_3 = ax_1 + bx_2$로 정의하면:

$$y_3(t) = t \cdot x_3(t) = t(ax_1 + bx_2) = a \cdot tx_1 + b \cdot tx_2 = ay_1(t) + by_2(t)$$

→ 정의 만족 → **선형 시스템** ✓

**예제 2**: $y(t) = x^2(t)$ — 선형?

$$y_3(t) = x_3^2(t) = (ax_1 + bx_2)^2 = a^2x_1^2 + 2abx_1x_2 + b^2x_2^2$$

기대값: $ay_1 + by_2 = ax_1^2 + bx_2^2$

→ 교차항 $2abx_1 x_2$ 때문에 불일치 → **비선형 시스템** ✓

**예제 3**: $y[n] = 2x[n] + 3$ — 선형?

입력이 0일 때 출력 = 3 (0이 아님) → **비선형 시스템** (quick tip으로 즉시 판별)

## 4. 시불변성 (Time-Invariance)

### 4-1. 정의

입력 $x(t) \to$ 출력 $y(t)$일 때, 시간 이동된 입력에 대해:

$$x(t - t_0) \to y(t - t_0)$$

즉, **입력을 $t_0$만큼 지연시키면 출력도 $t_0$만큼 지연**되어야 함

> 어느 시점에 시스템을 측정해도 같은 특성을 보이는 시스템

### 4-2. 판별 방법

두 가지를 계산해서 비교:

| 경로 A | 경로 B |
|--------|--------|
| 시스템에 $x(t-t_0)$ 입력 | $y(t)$를 $t_0$만큼 시프트 |
| $H(x(t-t_0))$ 계산 | $y(t-t_0)$ 계산 |

A = B이면 **시불변**, A ≠ B이면 **시변**

### 4-3. 예제 풀이

**예제 1**: $y(t) = x^2(t)$ — 시불변?

- 경로 A: $H(x(t-t_0)) = [x(t-t_0)]^2$
- 경로 B: $y(t-t_0) = [x(t-t_0)]^2$

A = B → **시불변 시스템** ✓

**예제 2**: $y[n] = n \cdot x[n]$ — 시불변?

- 경로 A: $H(x[n-n_0]) = n \cdot x[n-n_0]$
- 경로 B: $y[n-n_0] = (n-n_0) \cdot x[n-n_0]$

$n \neq n - n_0$ → A ≠ B → **시변 시스템** ✓

**예제 3**: $y(t) = x(t)\cos(\pi \cdot 10^6 t)$ — 시불변?

- 경로 A: $x(t-t_0)\cos(\pi \cdot 10^6 t)$
- 경로 B: $x(t-t_0)\cos(\pi \cdot 10^6(t-t_0))$

$\cos(\pi \cdot 10^6 t) \neq \cos(\pi \cdot 10^6(t-t_0))$ → **시변 시스템** ✓

## 5. LTI 시스템

> **LTI (Linear Time-Invariant)**: 선형성 + 시불변성을 **동시에** 만족하는 시스템

$$\text{선형성} + \text{시불변성} = \textbf{LTI 시스템}$$

**LTI 시스템이 이상적인 이유:**
- **예측 가능**: 어느 시점에 측정해도 같은 특성 → 오늘 측정 결과로 내일 동작 예측 가능
- **수학적으로 다루기 용이**: 중첩 원리 적용 가능

## 6. 메모리 (Memory)

### 6-1. 메모리리스 시스템 (Memoryless)

> 현재 시점의 출력이 **현재 시점의 입력에만** 의존

$$y[n] = f(x[n]) \quad \text{(현재 입력만 사용)}$$

특징:
- 과거나 미래 시점의 입력 참조 없음
- 반응 속도 매우 빠름
- 수식에 $n-k$, $t-\tau$, 적분, 합산 없음

**메모리리스 예시:**

$$y(t) = Rx(t), \quad y[n] = 3x[n], \quad y(t) = x^2(t)$$

### 6-2. 메모리 있는 시스템 (With Memory)

> 출력이 과거(또는 미래) 시점의 입력에도 의존

**메모리 시스템 예시:**

$$y[n] = \sum_{k=-\infty}^{n} x[k] \quad \text{(과거 전체 합산)}$$

$$y[n] = x[n-1] \quad \text{(1샘플 지연 = Delay)}$$

$$y(t) = \int_{-\infty}^{t} x(\tau)\, d\tau$$

> **커패시터, 인덕터** = 메모리 소자 (저장 기능 = 과거 기억)

**아이덴티티 시스템**: $y(t) = x(t)$ — 메모리리스

## 7. 가역성 (Invertibility)

### 7-1. 정의

서로 다른 입력은 항상 서로 다른 출력을 만들어야 함 (단사 함수, One-to-One)

역시스템이 존재: 출력 → 원래 입력 복원 가능

$$x[n] \xrightarrow{H} y[n] \xrightarrow{H^{-1}} x[n]$$

### 7-2. 예제

**가역 시스템**: $y[n] = \sum_{k=-\infty}^{n} x[k]$

역시스템: $x[n] = y[n] - y[n-1]$ (차분으로 복원 가능)

**비가역 예시 1**: $y[n] = 0$ (항상 0 → 어떤 입력인지 알 수 없음)

**비가역 예시 2**: $y(t) = x^2(t)$

$$x(t) = \pm\sqrt{y(t)} \quad \text{(부호 결정 불가 → 역 불가)}$$

---

## 8. 인과성 (Causality)

### 8-1. 정의

> 특정 시간의 출력이 **그 시간을 포함한 과거의 입력에만** 의존

$$y[n] = f(x[n], x[n-1], x[n-2], \ldots) \quad \text{(현재+과거만 사용)}$$

> **원인이 있어야 결과가 있다** — 미래 입력에 의존하지 않음

### 8-2. 메모리리스 vs 인과성

| 구분 | 메모리리스 | 인과성 |
|------|-----------|--------|
| 조건 | 현재 입력에만 의존 | 현재 + **과거** 입력에만 의존 |
| 관계 | 메모리리스 → 항상 인과적 | 인과적 ≠ 메모리리스 |

### 8-3. 예제

**비인과 시스템 1**: $y[n] = x[n+1]$

→ 미래($n+1$) 입력 사용 → **비인과** ✓

**비인과 시스템 2**: $y(t) = x(-t)$

$t < 0$이면 $-t > 0$ → 미래 값 사용 → **비인과** ✓

**인과 시스템**: $y[n] = x[n] + x[n-1]$

→ 현재 + 과거만 사용 → **인과적** ✓

## 9. 안정성 (Stability)

### 9-1. 정의 — BIBO (Bounded Input, Bounded Output)

> 유한한 입력(Bounded Input)을 가하면 출력도 항상 유한(Bounded Output)해야 함

$$|x(t)| \leq M < \infty \;\Rightarrow\; |y(t)| \leq N < \infty$$

### 9-2. 판별법

**안정 시스템 증명**: 임의의 유한 입력 $|x(t)| \leq M$을 가정하고 $|y(t)|$가 유한함을 보임

**불안정 시스템 판별**: 특정 유한 입력에서 출력이 무한대가 되는 반례 제시

### 9-3. 예제

**예제 1**: $y(t) = e^{x(t)}$ — 안정?

$|x(t)| \leq M$이면:

$$|y(t)| = |e^{x(t)}| \leq e^{|x(t)|} \leq e^M < \infty$$

→ **안정 시스템** ✓

**예제 2**: $y(t) = t \cdot x(t)$ — 안정?

반례: $x(t) = 1$ (유한)이면 $y(t) = t \to \infty$

→ **불안정 시스템** ✓

### 9-4. 직관적 이해

```
안정 시스템: 진자 (약간 밀어도 진동 후 수렴)
불안정 시스템: 역진자 (약간만 밀어도 쓰러짐)
```

## 10. 복소수 좌표계 복습

### 10-1. 세 가지 표현 방식

| 형식 | 표현 | 장점 |
|------|------|------|
| 직교 좌표계 | $a + jb$ | 덧셈·뺄셈 |
| 지수 형식 | $re^{j\theta}$ | 곱셈·나눗셈·미적분 |
| 극형식 | $r\angle\theta$ | 곱셈·나눗셈 |

### 10-2. 변환 공식

**직교 → 극 (Rectangular → Polar):**

$$r = \sqrt{a^2 + b^2}, \qquad \theta = \arctan\!\left(\frac{b}{a}\right)$$

**극 → 직교 (Polar → Rectangular):**

$$a = r\cos\theta, \qquad b = r\sin\theta$$

### 10-3. 오일러 공식

$$e^{j\theta} = \cos\theta + j\sin\theta$$

$$|e^{j\theta}| = 1 \quad \text{(반지름 항상 1)}$$

## 11. 핵심 요약 & 시험 포인트

### ✅ 선형성 판별 절차

```
1. x3 = ax1 + bx2 로 정의
2. y3 = H{x3} 계산 (시스템에 x3 입력)
3. ay1 + by2 계산 (각각 입력 후 가중합)
4. y3 == ay1 + by2 이면 선형, 아니면 비선형
```

Quick check: **입력 0 → 출력 0** 아니면 즉시 비선형

### ✅ 시불변성 판별 절차

```
1. 경로 A: 시스템에 x(t-t0) 입력 → H{x(t-t0)}
2. 경로 B: y(t)를 t0 시프트 → y(t-t0)
3. A == B 이면 시불변, 아니면 시변
```

### ✅ 각 성질 빠른 판별

| 성질 | 비해당 조건 |
|------|-----------|
| 선형 | 비선형 항 존재 ($x^2$, $\|x\|$, 상수 등) |
| 시불변 | 독립변수 $t$ 또는 $n$이 계수에 직접 등장 |
| 메모리리스 | $n-k$, $n+k$, $\int$, $\sum$ 존재 |
| 인과 | $n+k$ ($k>0$) 또는 $t > $ 현재 시점 존재 |
| 가역 | 출력에서 입력 유일 복원 불가 ($x^2$, 상수 출력 등) |
| 안정 | 유한 입력에서 무한 출력 가능 (계수에 $t$ 등) |

### ✅ 자주 틀리는 포인트

- $y(t) = x(-t)$: 시불변 판별 시 $-t$ 대입 주의 → **시변**
- $y(t) = x(-t)$: 인과성 판별 시 $t < 0$이면 미래값 사용 → **비인과**
- 메모리리스이면 항상 인과적 (역은 성립 안 함)
- $|x(t)| \leq M$ 가정 후 출력 상한 추정이 안정성 증명의 핵심
