## 1. 샘플링이란?

### 연속시간 → 이산시간의 연결고리

지금까지 배운 것:
- 연속시간 시스템/신호 (CTFT)
- 이산시간 시스템/신호 (DTFT)

둘을 별개로 배웠지만 사실 깊은 관계가 있다.

**이산시간 신호의 탄생 과정**:

$$\text{연속시간 신호} \xrightarrow{\text{일정 간격 측정}} \text{수열 (이산시간 신호)}$$

이렇게 **일정 시간 간격마다 값을 측정하는 것**이 **샘플링(Sampling)** 이다.

### 샘플링이 필요한 이유

- 연속시간 신호를 컴퓨터로 처리하려면 유한한 데이터로 표현해야 함
- 데이터 수를 줄여 저장/전송 후 → 원래 신호로 복원

### 핵심 문제

아래 세 신호 $x_1(t)$, $x_2(t)$, $x_3(t)$를 같은 주기 $T$로 샘플링하면 **샘플 값이 동일**하다.

```
x₁(t): 천천히 변하는 신호    x₂(t): 빠르게 변하는 신호
        ↓ 샘플링(주기 T)              ↓ 샘플링(주기 T)
     이산 신호 xₛ[n]              이산 신호 xₛ[n]
     (두 신호가 같은 샘플 값!)
```

→ 샘플 값만 보면 원래 신호가 $x_1$인지 $x_2$인지 $x_3$인지 **구별 불가**

→ **복원 불가능** (유니크하지 않음)

**해결책**: 특정 조건을 만족하는 신호만 샘플링 → 유니크하게 복원 가능

## 2. 밴드리미티드 신호와 복원 조건

### 밴드리미티드 신호 (Band-Limited Signal)

특정 최대 주파수 $\omega_M$ 이하의 주파수 성분만 가진 신호:

$$X(j\omega) = 0 \quad \text{for } |\omega| > \omega_M$$

**물리적 의미**: 천천히 변하는 신호 (고주파 성분 없음)

### 왜 밴드리미티드 조건이 복원을 가능하게 하나?

두 샘플 사이를 이어줄 때 항상 **직선(가장 단순한 보간)** 으로 연결하는 이유:

> 신호가 천천히 변한다고 가정하기 때문

이 가정 = 밴드리미티드 조건

밴드리미티드 신호라면:
- 두 샘플 사이에 가능한 신호가 **유일**하게 결정됨
- 유니크한 복원 가능

## 3. 임펄스 트레인을 이용한 샘플링 모델

### 임펄스 트레인 (Impulse Train) $p(t)$

$$p(t) = \sum_{k=-\infty}^{\infty} \delta(t - kT)$$

샘플링 주기 $T$마다 임펄스가 발생하는 주기 신호.

```
p(t):
  ↑   ↑   ↑   ↑   ↑   ↑
  |   |   |   |   |   |
-3T -2T  -T  0   T  2T  3T → t
```

### 샘플링 = 원신호 × 임펄스 트레인

$$x_p(t) = x(t) \cdot p(t) = x(t) \cdot \sum_{k=-\infty}^{\infty} \delta(t - kT)$$

$$= \sum_{k=-\infty}^{\infty} x(kT)\, \delta(t - kT)$$

**결과**: $t = kT$ 시점에서의 $x(kT)$ 값을 크기로 갖는 임펄스들의 합

```
x(t):              p(t):              xₚ(t):
 /\                ↑ ↑ ↑ ↑ ↑           ↑x(T) ↑x(2T)
/  \     ×        |||||||||    =    ↑x(0)  |      |
    \  /          |||||||          |       |    ↑x(3T)
     \/           → t              → t
```

각 임펄스의 크기 = 그 시점에서의 $x(t)$ 값 = **샘플 값**

## 4. 샘플링의 주파수 영역 분석

### 분석 전략

타임 도메인에서 $x_p(t) = x(t) \cdot p(t)$이므로:

$$X_p(j\omega) = \frac{1}{2\pi} X(j\omega) \ast P(j\omega) \quad \text{(변조 성질)}$$

### $P(j\omega)$ 계산

$p(t)$는 주기 신호이므로 CTFS 전개 후 CTFT:

CTFS 계수: $a_k = \frac{1}{T}$

$$P(j\omega) = \frac{2\pi}{T} \sum_{k=-\infty}^{\infty} \delta(\omega - k\omega_s)$$

여기서 $\omega_s = \frac{2\pi}{T}$는 **샘플링 각주파수**.

### $X_p(j\omega)$ 계산

$$X_p(j\omega) = \frac{1}{2\pi} X(j\omega) \ast \frac{2\pi}{T} \sum_{k=-\infty}^{\infty} \delta(\omega - k\omega_s)$$

델타 함수와의 컨볼루션 = 이동(Shift):

$$\boxed{X_p(j\omega) = \frac{1}{T} \sum_{k=-\infty}^{\infty} X(j(\omega - k\omega_s))}$$

### 결과 해석

| 항목 | 의미 |
|------|------|
| $\frac{1}{T}$ 배 | 크기가 $\frac{1}{T}$로 감소 |
| $k\omega_s$마다 반복 | 원래 스펙트럼이 $\omega_s$ 간격으로 복사됨 |

```
X(jω):             Xₚ(jω):
  △                   △     △     △     △
 / \              ... | △  / \  △ | △  / \ ...
/   \                 |/   \/ △ \/|/   \/
-ωM   ωM             -ωs  -ωM   ωM  ωs   2ωs → ω
                                    (1/T 배로 감소)
```

## 5. 나이퀴스트 샘플링 정리

### 핵심 조건

스펙트럼이 겹치지 않으려면:

$$\omega_M < \omega_s - \omega_M \quad \Rightarrow \quad \omega_s > 2\omega_M$$

$$\boxed{\omega_s > 2\omega_M}$$

또는:

$$f_s > 2f_M \quad \text{(Hz 단위)}$$

**나이퀴스트 샘플링 정리 (Nyquist Sampling Theorem)**:

> 밴드리미티드 신호 ($|\omega| \leq \omega_M$에서 존재)를 원래대로 복원하려면,  
> 샘플링 주파수 $\omega_s$가 최대 주파수의 **2배 이상**이어야 한다.

### 나이퀴스트 주파수와 나이퀴스트 율

| 용어 | 정의 |
|------|------|
| 나이퀴스트 주파수 | $\omega_M$ (신호의 최대 주파수) |
| 나이퀴스트 율 (Nyquist Rate) | $2\omega_M$ (최소 샘플링 주파수) |

### 실용적 예시

| 신호 | 최대 주파수 | 최소 샘플링 주파수 |
|------|-----------|----------------|
| 음성 전화 | ~4 kHz | 8 kHz (8000 샘플/초) |
| CD 음악 | ~20 kHz | 44.1 kHz |
| 디지털 영상 | 수 MHz | 그 이상 |

## 6. 에일리어싱 (Aliasing)

### 정의

$\omega_s < 2\omega_M$ (나이퀴스트 조건 위반) 시 스펙트럼이 겹치는 현상.

```
에일리어싱 발생:         복원 불가능:
   △    △              ┌─────────┐
  / \/\ / \      →     │ 겹침 발생│
 /  /\ /   \           │ (왜곡)   │
-ωs  0  ωs → ω         └─────────┘
```

### 에일리어싱의 영향

- 복원된 신호에 존재하지 않던 저주파 성분이 나타남
- 원신호와 다른 신호로 복원됨 → 왜곡

### 에일리어싱 방지법

샘플링 전에 **안티 에일리어싱 필터(Anti-Aliasing Filter)** 적용:

$$\text{LPF 적용 (}|\omega| > \omega_s/2 \text{ 제거)} \xrightarrow{\text{샘플링}} \text{에일리어싱 없음}$$

## 7. 이상적인 복원 — 아이디얼 LPF

### 복원 과정

$$x_p(t) \xrightarrow{\text{아이디얼 LPF}} x_r(t) \approx x(t)$$

### 아이디얼 LPF 스펙트럼

$$H_r(j\omega) = \begin{cases} T & |\omega| \leq \omega_c \\ 0 & |\omega| > \omega_c \end{cases}$$

- 이득(Gain) = $T$ → $\frac{1}{T}$로 감소한 크기를 $T$ 배로 복원
- 컷오프 주파수: $\omega_M \leq \omega_c \leq \omega_s - \omega_M$
- 일반적으로 $\omega_c = \frac{\omega_s}{2}$로 설정

### 복원의 주파수 영역

$$X_r(j\omega) = H_r(j\omega) \cdot X_p(j\omega) = X(j\omega) \quad \text{(원래 스펙트럼 복원)}$$

### 복원의 타임 도메인

LPF의 임펄스 응답: $h_r(t) = \frac{\omega_c}{\pi} \text{sinc}\!\left(\frac{\omega_c t}{\pi}\right)$

$$x_r(t) = x_p(t) \ast h_r(t) = \sum_{k=-\infty}^{\infty} x(kT) \cdot h_r(t - kT)$$

이것이 **sinc 보간(Sinc Interpolation)**: 각 샘플 값을 Sinc 함수로 확장하여 더함.

### 아이디얼 LPF의 한계

① **비인과 시스템**: $h_r(t)$가 $t < 0$에서도 존재

② **임펄스 트레인 구현 어려움**: 실제 하드웨어에서 순수 임펄스 생성 불가

③ **아이디얼 필터 구현 불가**: 현실적 LPF는 전이 대역이 있음

## 8. 실제 구현 — 제로오더홀드 (Zero-Order Hold)

### 배경

임펄스 트레인 대신 **실제로 구현 가능한** 샘플링 방법 필요.

### 제로오더홀드(ZOH) 개념

샘플링된 값을 **다음 샘플링 시점까지 유지(hold)** 하는 방식:

```
x(t):              xZOH(t):
 /\                 _
/  \     ZOH →    | |_
    \  /           |   |_
     \/            |      |_
t:  0  T 2T 3T    t: 0  T  2T  3T
```

- 각 샘플 시점에서 값을 측정
- 다음 샘플 시점까지 그 값을 일정하게 유지
- 계단 모양(staircase) 신호 생성

### 계단 폭과 근사 품질

샘플링 주기 $T$가 작을수록 (샘플링 주파수가 높을수록):
- 계단이 촘촘해짐
- 원래 신호에 더 가까운 근사

---

## 9. ZOH의 주파수 응답

### ZOH 임펄스 응답

$$h_0(t) = \begin{cases} 1 & 0 \leq t < T \\ 0 & \text{그 외} \end{cases}$$

0부터 $T$까지 1을 유지하는 구형파.

### ZOH 주파수 응답

구형파의 CTFT (시간 이동 포함):

$$H_0(j\omega) = e^{-j\omega T/2} \cdot \frac{2\sin(\omega T/2)}{\omega} = T\, e^{-j\omega T/2} \cdot \text{sinc}\!\left(\frac{\omega T}{2\pi}\right)$$

$$\boxed{H_0(j\omega) = T\, e^{-j\omega T/2} \cdot \frac{\sin(\omega T/2)}{\omega T/2}}$$

### ZOH 보상 필터

ZOH 후 복원 시스템의 전체 주파수 응답:

$$H_r(j\omega) = \frac{H_{LPF}(j\omega)}{H_0(j\omega)}$$

**ZOH가 아이디얼 LPF와 다른 점**:

| | 아이디얼 복원 | ZOH 후 복원 |
|--|------------|-----------|
| 크기 | 패스밴드 내 완전히 평탄 | 중간 부분 약간 차이 |
| 위상 | 0 또는 선형 | $-\omega T/2$ 추가 위상 지연 |
| 구현 | 불가 (비인과) | **실제 구현 가능** |

### ZOH 기반 복원 시스템 다이어그램

$$x(t) \xrightarrow{\times p(t)} x_p(t) \xrightarrow{H_0(j\omega)} x_{ZOH}(t) \xrightarrow{H_r(j\omega)} x_r(t)$$

보상 필터 $H_r(j\omega) = H_{LPF}(j\omega) \cdot H_0^{-1}(j\omega)$를 적용하면 완전 복원 가능.

## 10. 핵심 요약 & 시험 포인트

### 반드시 암기할 공식

**샘플링된 신호의 스펙트럼:**

$$\boxed{X_p(j\omega) = \frac{1}{T} \sum_{k=-\infty}^{\infty} X(j(\omega - k\omega_s))}$$

**나이퀴스트 조건:**

$$\boxed{\omega_s > 2\omega_M}$$

**샘플링 주파수:**

$$\omega_s = \frac{2\pi}{T}$$

**커트오프 주파수 (일반적 설정):**

$$\omega_c = \frac{\omega_s}{2}$$

### 샘플링 과정 요약

| 단계 | 시간 영역 | 주파수 영역 |
|------|---------|-----------|
| 원신호 | $x(t)$ | $X(j\omega)$: $[-\omega_M, \omega_M]$에 존재 |
| 임펄스 트레인 | $p(t) = \sum_k \delta(t-kT)$ | $P(j\omega) = \frac{2\pi}{T}\sum_k \delta(\omega-k\omega_s)$ |
| 샘플링 | $x_p(t) = x(t) \cdot p(t)$ | $X_p(j\omega) = \frac{1}{T}\sum_k X(j(\omega-k\omega_s))$ |
| 복원 | $x_r(t) = x_p(t) \ast h_r(t)$ | $X_r(j\omega) = H_r(j\omega) \cdot X_p(j\omega) = X(j\omega)$ |

### 나이퀴스트 정리 핵심

$$\omega_s > 2\omega_M \quad \Leftrightarrow \quad T < \frac{\pi}{\omega_M} = \frac{1}{2f_M}$$

- 나이퀴스트 율 이상으로 샘플링 → 복원 가능
- 나이퀴스트 율 미만으로 샘플링 → 에일리어싱 → 복원 불가

### ZOH vs 아이디얼 샘플링

| | 아이디얼 (임펄스 트레인) | ZOH |
|--|----------------------|-----|
| 구현 | 이론적 | **실제 구현 가능** |
| 복원 | 아이디얼 LPF | LPF + 보상 필터 |
| 임펄스 응답 | $\delta(t)$ | 구형파 (0~T) |
| 주파수 응답 | 1 (모든 $\omega$) | Sinc 형태 |

### 자주 틀리는 포인트

- $X_p(j\omega)$의 크기: $\frac{1}{T}$배로 감소 (T 곱하기 아님)
- 커트오프 주파수: $\omega_M \leq \omega_c \leq \omega_s - \omega_M$ (범위 있음)
- 나이퀴스트 조건: **$\omega_s > 2\omega_M$** (등호 불포함 — 등호 성립 시 경계)
- ZOH 임펄스 응답: $0 \leq t < T$ 구간의 구형파
