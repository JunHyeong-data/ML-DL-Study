## 1. 우함수와 기함수

### 1-1. 우함수 (Even Function)

> **정의**: $x(-t) = x(t)$ — $y$축 대칭

$$x_e(t) = x_e(-t)$$

- 그래프가 **$y$축 기준 좌우 대칭**
- 예: $\cos(t)$, $t^2$, $|t|$

### 1-2. 기함수 (Odd Function)

> **정의**: $x(-t) = -x(t)$ — 원점 대칭

$$x_o(t) = -x_o(-t)$$

- 그래프가 **원점 기준 점대칭**
- 예: $\sin(t)$, $t$, $t^3$

> **⚠️ 중요**: 기함수는 반드시 $t=0$ (또는 $n=0$)에서 **0**이어야 함
>
> 원점 대칭 조건: $x_o(0) = -x_o(0)$ → $x_o(0) = 0$

### 1-3. 증명 방법론

> **증명 절차**: 정의 → 대입 → 원래 식과 같은지 확인

```
Step 1. 정의 확인 (우함수: x(-t) = x(t), 기함수: x(-t) = -x(t))
Step 2. 신호에 t 대신 -t 대입
Step 3. 정리 후 원래 신호와 비교
```

## 2. 임의의 신호 = 우함수 + 기함수

### 2-1. 핵심 성질 ⭐

> **모든** 신호 $x(t)$는 항상 우함수 성분과 기함수 성분의 합으로 분해 가능하다.

$$\boxed{x(t) = x_e(t) + x_o(t)}$$

$$x_e(t) = \frac{x(t) + x(-t)}{2}, \qquad x_o(t) = \frac{x(t) - x(-t)}{2}$$

이산시간 신호도 동일:

$$x[n] = x_e[n] + x_o[n]$$
$$x_e[n] = \frac{x[n] + x[-n]}{2}, \qquad x_o[n] = \frac{x[n] - x[-n]}{2}$$

### 2-2. 증명

**$x_e(t)$가 우함수임을 증명:**

$y(t) = x_e(t) = \dfrac{x(t)+x(-t)}{2}$ 로 정의하면

$$y(-t) = \frac{x(-t)+x(t)}{2} = y(t) \quad \checkmark$$

**$x_o(t)$가 기함수임을 증명:**

$y(t) = x_o(t) = \dfrac{x(t)-x(-t)}{2}$ 로 정의하면

$$y(-t) = \frac{x(-t)-x(t)}{2} = -\frac{x(t)-x(-t)}{2} = -y(t) \quad \checkmark$$

**복원 확인:**

$$x_e(t) + x_o(t) = \frac{x(t)+x(-t)}{2} + \frac{x(t)-x(-t)}{2} = x(t) \quad \checkmark$$

### 2-3. 예시: 단위 계단 신호 $u[n]$ 분해

$u[n]$은 $n < 0$이면 0, $n \geq 0$이면 1인 신호.

$$u_e[n] = \frac{u[n] + u[-n]}{2}, \qquad u_o[n] = \frac{u[n] - u[-n]}{2}$$

| $n$ | $u[n]$ | $u[-n]$ | $u_e[n]$ | $u_o[n]$ |
|-----|--------|---------|----------|----------|
| $n < 0$ | 0 | 1 | $1/2$ | $-1/2$ |
| $n = 0$ | 1 | 1 | $1$ | $0$ |
| $n > 0$ | 1 | 0 | $1/2$ | $1/2$ |

> 기함수 성분은 $n=0$에서 반드시 0 → 확인 ✓

### 2-4. 정보량 비교

- 우함수: $t=0$에서 임의의 값 가능 → **정보 더 많음**
- 기함수: $t=0$에서 반드시 0 → $t=0$ 값이 고정되어 있어 정보 1개 적음

## 3. 복소수 표현 — 왜 필요한가

### 3-1. 직교 좌표계의 한계

| 연산 | 직교 좌표계 | 극형식/지수형식 |
|------|------------|--------------|
| **덧셈·뺄셈** | ✅ 쉬움 | ❌ 불편 |
| **곱셈·나눗셈** | ❌ 복잡 | ✅ 쉬움 |

> 앞으로 **주파수 도메인** 분석에서는 신호의 곱셈·나눗셈이 많이 등장  
> → 극형식/지수형식이 필수

### 3-2. 복소 평면 (Complex Plane)

```
Im (허수축)
│
│    • P = a + bi
│   /|
│  / |  b (Im part)
│ /  |
│/ θ |
─────────── Re (실수축)
   a (Re part)
```

- 복소수를 2D 평면의 점으로 시각화
- **반지름** $r = |x|$ = 원점에서 점까지의 거리
- **각도** $\theta = \angle x$ = 실수축에서 반시계 방향 각도

---

## 4. 직교 좌표계 형식 (Rectangular Form)

$$x = a + jb$$

- $a = \text{Re}\{x\}$: 실수 부분
- $b = \text{Im}\{x\}$: 허수 부분
- $j = \sqrt{-1}$ (공학에서는 $i$ 대신 $j$ 사용 — 전류 기호 $i$와 혼동 방지)

### 실수·허수 부분 추출 공식

켤레 복소수(Complex Conjugate): $x^{\ast} = a - jb$

$$\text{Re}(x) = \frac{x + x^{\ast}}{2} = a$$

$$\text{Im}(x) = \frac{x - x^{\ast}}{2j} = b$$

## 5. 지수 형식 & 극형식

### 5-1. 지수 형식 (Exponential Form)

오일러 공식(Euler's Formula):

$$e^{j\theta} = \cos\theta + j\sin\theta$$

따라서 복소수를 다음과 같이 표현:

$$x = |x| \cdot e^{j\angle x} = r e^{j\theta}$$

### 5-2. 극형식 (Polar Form)

$$x = r \angle \theta$$

지수형식과 동일한 정보, 표기만 다름.

### 5-3. 좌표 변환

**직교 → 극 (Rectangular → Polar):**

$$r = |x| = \sqrt{a^2 + b^2}$$
$$\theta = \angle x = \arctan\!\left(\frac{b}{a}\right)$$

**극 → 직교 (Polar → Rectangular):**

$$a = r\cos\theta$$
$$b = r\sin\theta$$

### 5-4. 오일러 공식 응용 — 삼각함수 표현

$$\cos\theta = \frac{e^{j\theta} + e^{-j\theta}}{2}$$
$$\sin\theta = \frac{e^{j\theta} - e^{-j\theta}}{2j}$$

> 이 공식들은 앞으로 **푸리에 급수/변환**에서 핵심적으로 사용됨

## 6. 좌표계 변환 공식 총정리

| 형식 | 표현 | 장점 |
|------|------|------|
| 직교 좌표계 | $x = a + jb$ | 덧셈·뺄셈 |
| 지수 형식 | $x = re^{j\theta}$ | 곱셈·나눗셈, 미적분 |
| 극형식 | $x = r\angle\theta$ | 곱셈·나눗셈 |

**곱셈 비교:**

직교 좌표계:
$$(a+jb)(c+jd) = (ac-bd) + j(ad+bc)$$

극형식:
$$r_1 e^{j\theta_1} \cdot r_2 e^{j\theta_2} = r_1 r_2 \, e^{j(\theta_1+\theta_2)}$$

→ 크기는 곱하고, 각도는 더하면 끝 ✅

## 7. 지수 신호의 분류

일반적인 지수 신호:

$$x(t) = C e^{at}$$

$C$와 $a$의 종류에 따라 세 가지로 분류:

### Case 1. $C$, $a$ 모두 실수 — 실수 지수 신호

$$x(t) = C e^{at}, \quad C, a \in \mathbb{R}$$

| 조건 | 거동 |
|------|------|
| $a > 0$ | 지수적 **증가** |
| $a = 0$ | 상수 신호 |
| $a < 0$ | 지수적 **감쇠** |

### Case 2. $C$ 실수, $a$ 순허수 — 복소 정현파

$$a = j\omega_0 \Rightarrow x(t) = Ce^{j\omega_0 t} = C(\cos\omega_0 t + j\sin\omega_0 t)$$

- 크기 일정, 위상 회전 → **정현파 신호**

### Case 3. $C$, $a$ 모두 복소수 — 일반 복소 지수 신호

$$a = \sigma + j\omega_0 \Rightarrow x(t) = |C|e^{\sigma t} \cos(\omega_0 t + \theta)$$

- $\sigma < 0$: 진폭이 감쇠하는 정현파
- $\sigma > 0$: 진폭이 증가하는 정현파

> 다음 강의에서 세 가지 경우를 각각 상세히 다룰 예정

## 8. 핵심 요약 & 시험 포인트

### ✅ 반드시 외울 공식

$$x(t) = \underbrace{\frac{x(t)+x(-t)}{2}}_{x_e(t)\text{ (우함수)}} + \underbrace{\frac{x(t)-x(-t)}{2}}_{x_o(t)\text{ (기함수)}}$$

$$e^{j\theta} = \cos\theta + j\sin\theta \quad \text{(오일러 공식)}$$

$$r = \sqrt{a^2+b^2}, \qquad \theta = \arctan\!\left(\frac{b}{a}\right)$$

### ✅ 자주 틀리는 포인트

- 기함수는 $t=0$에서 반드시 **0** → 아닌 신호는 기함수 아님
- $x(t)$가 이미 우함수이면 $x_o(t) = 0$, 이미 기함수이면 $x_e(t) = 0$
- 극형식 $r\angle\theta$와 지수형식 $re^{j\theta}$는 **같은 것**, 표기만 다름
- 덧셈 → 직교 좌표계, 곱셈 → 지수/극형식으로 변환 후 계산

- 이산시간에서의 지수 신호
