## 1. 왜 위상이 중요한가

### 정량적 분석 vs 정성적 분석

| 구분 | 내용 |
|------|------|
| 3~5장 (정량적) | 수학적 계산, 변환 공식 |
| **6장 (정성적)** | 그래프 해석, 직관적 특성 파악 |

### 크기(Magnitude)만 같아도 다른 신호

신호 $x(t)$에 4개의 주파수 성분이 포함된 경우:

$$x(t) = A + A_1 \cos(\omega_1 t + \phi_1) + A_2 \cos(\omega_2 t + \phi_2) + A_3 \cos(\omega_3 t + \phi_3)$$

- **신호 A → 신호 B**: 모든 성분이 **같은 위상**만큼 이동 → 파형 모양 유지, 시간만 이동
- **신호 A → 신호 C, D**: 각 성분마다 **다른 위상**으로 이동 → 파형 형태 완전히 바뀜

### 통신에서의 중요성

$$\text{송신} \xrightarrow{\text{채널}} \text{수신}$$

- 모든 주파수 성분이 같은 딜레이로 수신 → 원본 신호 복원 가능
- 주파수마다 딜레이가 다르면 → 신호 왜곡, 복원 불가

> **결론**: 크기 못지않게 위상도 굉장히 중요하다

## 2. 크기와 위상의 관계

### 주파수 응답의 분리 표현

$$H(j\omega) = |H(j\omega)| \cdot e^{j\angle H(j\omega)}$$

**출력 = 입력에 크기와 위상을 각각 적용**

$$|Y(j\omega)| = |H(j\omega)| \cdot |X(j\omega)|$$

$$\angle Y(j\omega) = \angle H(j\omega) + \angle X(j\omega)$$

직렬 연결 시스템에서의 합산:

$$\angle Y = \angle H_1 + \angle H_2 + \angle H_3 + \angle X$$

---

## 3. 선형 위상 (Linear Phase)

### 정의

주파수 응답의 위상이 $\omega$의 **선형 함수**로 표현되는 경우:

$$\angle H(j\omega) = -\alpha\omega$$

이를 **선형 위상(Linear Phase)** 이라 한다.

반대로 선형이 아닌 경우를 **비선형 위상(Non-linear Phase)** 이라 한다.

### 왜 선형 위상이 좋은가?

코사인 신호 $\cos(\omega_1 t - \phi_1)$에서 위상 $\phi_1 = \alpha\omega_1$이면:

$$\cos(\omega_1 t - \alpha\omega_1) = \cos(\omega_1(t - \alpha))$$

즉 위상이 주파수에 선형 비례하면 → 모든 주파수 성분이 **$\alpha$초만큼 동일하게 지연**

$$\boxed{\text{선형 위상} \Rightarrow \text{타임 도메인에서 모든 성분 동일 딜레이} \Rightarrow \text{파형 보존}}$$

### 위상 딜레이 (Phase Delay)

$$\tau_p(\omega) = -\frac{\angle H(j\omega)}{\omega}$$

위상 딜레이: 각 주파수 성분이 시스템을 통과할 때 걸리는 시간.

선형 위상이면 $\tau_p$는 모든 $\omega$에서 **상수** $\alpha$.

---

## 4. 그룹 딜레이 (Group Delay)

### 정의

$$\boxed{\tau_g(\omega) = -\frac{d}{d\omega}\angle H(j\omega)}$$

위상을 주파수로 미분한 후 음수를 취한 값.

### 중요성

- **선형 위상**: $\tau_g = \alpha$ (상수) → 모든 주파수 성분이 동일하게 지연
- **비선형 위상**: $\tau_g(\omega)$ 가 주파수마다 다름 → 신호 왜곡

### 내로우밴드 시스템 (Narrow-Band System)에서의 의미

신호가 중심 주파수 $\omega_0$ 근처에만 존재할 때, 그 좁은 대역 안에서:

$$\angle H(j\omega) \approx -\alpha\omega \quad (\omega_0 \text{ 근방})$$

이 경우 그룹 딜레이 $\alpha$만큼 모든 성분이 동일하게 지연 → 파형 보존.

### 계산 방법

1. 주파수 응답 $H(j\omega)$의 위상 $\angle H(j\omega)$ 계산
2. 위상을 **언래핑(Unwrapping)** 처리 (불연속 제거)
3. $\omega$로 미분
4. $-1$을 곱함

## 5. 예제 6.1 — 직렬 시스템의 위상 분석

### 문제

3개의 시스템이 직렬 연결:

$$H(j\omega) = H_1(j\omega) \cdot H_2(j\omega) \cdot H_3(j\omega)$$

각 시스템의 주파수 응답이 켤레 복소수 쌍으로 주어진 경우.

### 핵심 분석

각 $H_k(j\omega)$가 켤레 관계 → 크기(Magnitude) 성분만 보면:

$$|H_k(j\omega)| = 1 \quad \text{(위상만 변화)}$$

전체 시스템의 크기: $|H| = |H_1||H_2||H_3| = 1 \times 1 \times 1 = 1$

따라서:
- **크기 스펙트럼**: 변화 없음
- **위상**: 각 시스템의 위상 합

### 그룹 딜레이 계산

$$\tau_g = -\frac{d}{d\omega}[\angle H_1 + \angle H_2 + \angle H_3]$$

분모가 0이 되는 지점: $\omega = \omega_0$ (레조넌스 주파수)에서 위상이 급격히 변화.

그룹 딜레이가 타임 도메인에서의 딜레이를 나타내며, 이것이 곧 임펄스 응답의 중심 위치.

## 6. 위상 래핑과 언래핑 (Wrapping & Unwrapping)

### 위상 래핑 (Phase Wrapping)

위상 값을 $-\pi \sim \pi$ (또는 $0 \sim 2\pi$) 범위로 제한하여 표현하는 것.

$$\phi_{\text{wrapped}} = \phi \mod 2\pi \in [-\pi, \pi]$$

예: $15\pi$는 래핑 후 $\pi$와 동일.

### 위상 언래핑 (Phase Unwrapping)

래핑된 위상의 불연속점을 제거하여 연속적인 위상으로 복원하는 것.

```
래핑된 위상:         언래핑된 위상:
   π|‾\_              /
    |   \           /
 -π|    ‾\_   →   /
    |       \   /
             ‾          
```

불연속점에서 $\pm\pi$만큼 점프한 것을 연결하여 부드럽게 만든다.

### 왜 필요한가?

그룹 딜레이 계산 시 미분이 필요한데, 불연속점이 있으면 미분 불가 → 언래핑 후 미분.

## 7. 보데 플롯 (Bode Plot)

### 정의

주파수 응답을 **로그 스케일**로 나타낸 그래프.

- **X축**: 주파수 (로그 스케일)
- **Y축**: 크기 → **데시벨(dB)** = $20\log_{10}|H(j\omega)|$

### 데시벨(dB)을 사용하는 이유

**① 직렬 연결 시스템의 계산 단순화**

$$|Y| = |H_1| \cdot |H_2| \cdot |H_3| \cdot |X|$$

$$20\log|Y| = 20\log|H_1| + 20\log|H_2| + 20\log|H_3| + 20\log|X|$$

곱 → 합으로 변환 (계산 단순화)

**② 넓은 동적 범위(Dynamic Range) 표현**

| 실제 이득 | 선형 스케일 | dB 스케일 |
|---------|----------|---------|
| 0.001 | 0.001 | $-60$ dB |
| 1 | 1 | $0$ dB |
| 1000 | 1000 | $+60$ dB |

선형 스케일로는 0.001~1000을 하나의 그래프에 표시 어려움 → dB로 가능.

### 보데 플롯 그리기 (점근선 근사)

각 극점/영점에서 기울기가 변하는 꺾인 직선으로 근사:

- $\omega < \omega_n$: 수평선
- $\omega > \omega_n$: 기울기 $-20$ dB/decade (1차), $-40$ dB/decade (2차)

이 꺾인 직선을 부드럽게 연결한 것이 실제 보데 플롯.

### 이산시간 보데 플롯

연속시간과 동일하지만:
- X축: $-\pi \sim \pi$ 범위만 유효 (나머지 $2\pi$ 주기로 반복)

## 8. 아이디얼 필터와 실제 필터

### 아이디얼 로우패스 필터 (Ideal LPF)

$$H_{ideal}(j\omega) = \begin{cases} 1 & |\omega| \leq \omega_c \\ 0 & |\omega| > \omega_c \end{cases}$$

임펄스 응답:

$$h_{ideal}(t) = \frac{\omega_c}{\pi} \text{sinc}\!\left(\frac{\omega_c t}{\pi}\right) = \frac{\sin(\omega_c t)}{\pi t}$$

### 아이디얼 필터의 문제점

① **계산량이 무한대**: $h(t)$가 $-\infty \sim \infty$에 걸쳐 존재

② **비인과 시스템**: $t < 0$에서도 값을 가짐 → 현재 출력이 미래 입력에 의존

③ **구현 불가**: 임펄스 입력 자체가 시스템을 손상시킬 수 있음

### 윈도우 함수 (Window Function)

아이디얼 필터의 임펄스 응답을 유한 구간으로 잘라서 근사:

$$h_{approx}[n] = h_{ideal}[n] \cdot w[n]$$

- $w[n]$: 윈도우 함수 (특정 구간에서만 1, 나머지 0)
- 현재 시점 근처의 값이 컨볼루션에 더 큰 영향을 미치므로 먼 값은 무시 가능

### 실제 필터 (Non-ideal Filter)

```
아이디얼 LPF:          실제 LPF:
|H|                    |H|
 1|‾‾‾‾|               1|‾‾‾‾\
  |    |                |     \___
  |    |___        →    |
  +----+---→ ω          +----+----→ ω
       ωc                    ωc
```

실제 필터의 특성:
- **패스밴드(Passband)**: 신호 통과 대역 (이득 ≈ 1)
- **스탑밴드(Stopband)**: 신호 차단 대역 (이득 ≈ 0)
- **전이 대역(Transition Band)**: 패스밴드와 스탑밴드 사이의 완만한 구간
- **리플(Ripple)**: 패스밴드/스탑밴드 내에서의 진동

## 9. 필터 설계 지표 — 스텝 응답

### 왜 임펄스 응답 대신 스텝 응답?

임펄스 입력 $\delta(t)$는 실제로 만들기 어렵고, 시스템을 손상시킬 수 있다.  
대신 **단위 계단 함수(Unit Step)** $u(t)$를 입력으로 사용한다.

$$\text{스텝 응답 } s(t) = h(t) \ast u(t) = \int_{-\infty}^{t} h(\tau)\, d\tau$$

### 스텝 응답 성능 지표

```
s(t)
 1+δ|  /‾‾\        ← 오버슈트
   1|_/    ‾‾‾‾‾‾  ← 목표값
 1-δ|
   0|
    +--+---+------→ t
       tr  ts
       ↑   ↑
    라이즈 정착
    타임  타임
```

**① 라이즈 타임 (Rise Time, $t_r$)**

목표값에 **처음 도달**하는 시간.  
짧을수록 좋음 → 빠른 응답

**② 오버슈트 (Overshoot)**

목표값을 초과하는 진동.  
작을수록 좋음 → 안정성

**③ 정착 시간 (Settling Time, $t_s$)**

출력이 목표값 $\pm\delta$ 범위 안에 안정화되는 시간.  
짧을수록 좋음

### 트레이드오프 (Trade-off)

$$\text{라이즈 타임 } \downarrow \iff \text{오버슈트 } \uparrow$$

라이즈 타임을 줄이면 오버슈트가 커지고, 오버슈트를 줄이면 라이즈 타임이 길어진다.  
둘 사이의 **최적 균형점**을 찾는 것이 필터 설계의 핵심.

## 10. 실제 필터 비교: 엘립틱 vs 버터워스

### 엘립틱 필터 (Elliptic Filter)

- 전이 대역이 **급격하게** 떨어짐 (sharp roll-off)
- 패스밴드/스탑밴드에 **리플(Ripple)** 존재
- 오버슈트 큼 → 안정화 느림

**장점**: 같은 차수로 더 날카로운 주파수 선택성  
**단점**: 위상 왜곡, 오버슈트 큼

### 버터워스 필터 (Butterworth Filter)

- 전이 대역이 **완만하게** 떨어짐 (smooth roll-off)
- 패스밴드가 **최대한 평탄** (Maximally Flat)
- 오버슈트 작음 → 빠른 안정화

**장점**: 위상 특성 우수, 오버슈트 작음  
**단점**: 동일한 선택성을 위해 더 높은 차수 필요

### 선택 기준

| 우선순위 | 적합한 필터 |
|---------|-----------|
| 빠른 주파수 전환 필요 | **엘립틱** |
| 안정성, 위상 특성 중요 | **버터워스** |
| 영상처리 에지 검출 | 엘립틱 계열 |
| 오디오 신호처리 | 버터워스 계열 |

## 11. 1차 시스템 (First-Order System)

### 미분 방정식

$$\tau \frac{dy(t)}{dt} + y(t) = x(t)$$

### 주파수 응답

$$H(j\omega) = \frac{1}{1 + j\omega\tau}$$

### 시상수 $\tau$ (Time Constant)의 역할

$$h(t) = \frac{1}{\tau} e^{-t/\tau} u(t)$$

스텝 응답:

$$s(t) = (1 - e^{-t/\tau}) u(t)$$

**$\tau$가 크면**: 변화가 느림 → 전이 구간 길어짐 (부드럽게 올라감)  
**$\tau$가 작으면**: 변화가 빠름 → 전이 구간 짧아짐 (빠르게 올라감)

### 시상수의 물리적 의미

$$s(\tau) = 1 - e^{-1} \approx 0.632$$

$\tau$는 스텝 응답이 **최종값의 약 63.2%에 도달하는 시간**.

## 12. 2차 시스템 (Second-Order System)

### 표준 형태

$$\frac{d^2y}{dt^2} + 2\zeta\omega_n \frac{dy}{dt} + \omega_n^2 y = \omega_n^2 x$$

### 핵심 파라미터

**고유 진동수 $\omega_n$ (Natural Frequency)**

시스템이 자유 진동할 때의 주파수.

**감쇠비 $\zeta$ (Damping Ratio)**

에너지 소산 정도.

### 주파수 응답

$$H(j\omega) = \frac{\omega_n^2}{(j\omega)^2 + 2\zeta\omega_n(j\omega) + \omega_n^2} = \frac{\omega_n^2}{(\omega_n^2 - \omega^2) + j2\zeta\omega_n\omega}$$

### 감쇠비에 따른 3가지 경우

| 케이스 | 조건 | 특성 |
|--------|------|------|
| 부족 감쇠 (Underdamping) | $\zeta < 1$ | 오버슈트 큼, 빠른 응답 |
| 임계 감쇠 (Critical Damping) | $\zeta = 1$ | 오버슈트 없음, 최소 시간 |
| 과도 감쇠 (Overdamping) | $\zeta > 1$ | 오버슈트 없음, 느린 응답 |

### 스텝 응답 특성

**언더댐핑 ($\zeta < 1$)**

에너지 소산이 적어 출렁임(Oscillation)이 크다. 라이즈 타임은 짧지만 오버슈트가 크고 안정화 느림.

**오버댐핑 ($\zeta > 1$)**

에너지 소산이 많아 출렁임이 적다. 오버슈트는 없지만 목표값 도달이 느림.

**크리티컬 댐핑 ($\zeta = 1$)**

오버슈트 없이 가장 빠르게 목표값 도달. 실용적으로 가장 선호.

### 레조넌스 (Resonance)

$\zeta$가 작을수록 스펙트럼에서 특정 주파수 근방의 피크가 날카롭고 높아진다.

$$\omega_r \approx \omega_n\sqrt{1 - 2\zeta^2} \quad (\zeta < 1/\sqrt{2})$$

레조넌스 주파수에서 이득이 최대. 피크가 좁고 날카로울수록 레조넌스가 심하다.

### 보데 플롯 (2차 시스템)

$\omega < \omega_n$: 수평  
$\omega > \omega_n$: $-40$ dB/decade로 감소  
$\omega = \omega_n$ 근방: $\zeta$ 값에 따라 피크 발생

## 13. 이산시간에서의 차이점

### 주파수 범위

| | 연속시간 | 이산시간 |
|--|---------|---------|
| 주파수 범위 | $-\infty \sim \infty$ | $-\pi \sim \pi$ (반복) |
| 의미 있는 구간 | 전체 | $-\pi \sim \pi$만 |

이산시간 보데 플롯은 $-\pi \sim \pi$ 구간에서만 그리면 됨. 나머지는 $2\pi$ 주기로 반복.

### 아이디얼 LPF (이산시간)

연속시간과 동일한 형태이나, $|\omega| \leq \pi$ 범위로 제한.

## 14. 핵심 요약

### 위상 관련 핵심 개념

| 개념 | 정의 | 의미 |
|------|------|------|
| 위상 딜레이 | $-\frac{\angle H}{\omega}$ | 각 주파수의 지연 시간 |
| 그룹 딜레이 | $-\frac{d}{d\omega}\angle H$ | 신호 포락선의 지연 |
| 선형 위상 | $\angle H = -\alpha\omega$ | 모든 주파수 동일 딜레이 |

### 필터 설계 트레이드오프

$$\text{라이즈 타임} \downarrow \longleftrightarrow \text{오버슈트} \uparrow$$

$$\text{엘립틱} \longleftrightarrow \text{버터워스}$$
$$(\text{sharp, 리플 있음}) \quad (\text{smooth, 평탄})$$

### 2차 시스템 감쇠비 요약

$$\zeta < 1: \text{ 오버슈트 큼, 빠른 응답}$$

$$\zeta = 1: \text{ 최적 (Critical Damping)}$$

$$\zeta > 1: \text{ 오버슈트 없음, 느린 응답}$$

### 데시벨 변환

$$[\text{dB}] = 20\log_{10}|H(j\omega)|$$

$$0 \text{ dB} = \text{이득 1} \quad -20 \text{ dB} = \text{이득 0.1} \quad +20 \text{ dB} = \text{이득 10}$$

### 보데 플롯 점근선 기울기

| 시스템 차수 | 기울기 |
|-----------|-------|
| 1차 | $-20$ dB/decade |
| 2차 | $-40$ dB/decade |
| n차 | $-20n$ dB/decade |
