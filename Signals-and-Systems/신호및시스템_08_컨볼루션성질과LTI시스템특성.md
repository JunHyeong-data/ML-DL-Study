## 1. 컨볼루션 예제 복습

### 예제 2.6 — 연속시간 컨볼루션

**임펄스 응답**: $h(t) = u(t)$ (단위 계단)  
**입력**: $x(t) = e^{-at}u(t)$, $a > 0$

컨볼루션 적분:

$$y(t) = \int_{-\infty}^{\infty} x(\tau)\, h(t-\tau)\, d\tau$$

$h(t-\tau) = u(t-\tau)$는 $\tau \leq t$일 때만 1 → 적분 구간 $[0, t]$로 단순화:

$$y(t) = \int_0^t e^{-a\tau}\, d\tau = \frac{1-e^{-at}}{a}\, u(t)$$

> $x(\tau)$와 $h(t-\tau)$가 겹치는 구간만 적분에 기여

## 2. 컨볼루션의 세 가지 성질

LTI 시스템에서 컨볼루션은 다음 세 가지 법칙을 만족한다.

### 2-1. 교환 법칙 (Commutativity)

$$\boxed{x[n] \ast h[n] = h[n] \ast x[n]}$$

$$\boxed{x(t) \ast h(t) = h(t) \ast x(t)}$$

**증명 (이산시간)**:

$$\sum_{k=-\infty}^{\infty} x[k]\,h[n-k]$$

$m = n-k$로 치환하면 $k = n-m$:

$$= \sum_{m=-\infty}^{\infty} x[n-m]\,h[m] = h[n] \ast x[n] \quad \checkmark$$

> 두 신호 중 계산하기 편한 쪽을 반전·이동시키면 된다

### 2-2. 분배 법칙 (Distributivity)

$$\boxed{x[n] \ast (h_1[n] + h_2[n]) = x[n] \ast h_1[n] + x[n] \ast h_2[n]}$$

**블록 다이어그램 해석:**

```
병렬 연결 (위):           등가 단일 시스템 (아래):
                              
x[n] → H₁ → (+) → y[n]   x[n] → (H₁+H₂) → y[n]
     → H₂ ↗
```

- 위: 두 개의 필터 설계 필요
- 아래: **하나의 필터**로 동일 결과 → 설계·구현 효율적

### 2-3. 결합 법칙 (Associativity)

$$\boxed{(x[n] \ast h_1[n]) \ast h_2[n] = x[n] \ast (h_1[n] \ast h_2[n])}$$

**블록 다이어그램 해석:**

```
직렬(캐스케이드) 연결:
x[n] → H₁ → H₂ → y[n]

등가:
x[n] → (H₁∗H₂) → y[n]
```

> **LTI 시스템이 직렬(캐스케이드) 연결**되어 있으면 **순서가 상관없다**  
> 교환 법칙에 의해 $H_1 \ast H_2 = H_2 \ast H_1$이므로 순서 자유

**캐스케이드(Cascade)** = 직렬 연결 시스템

## 3. LTI 시스템의 추가 성질

### 3-1. 메모리리스 LTI 시스템

메모리가 없으면 현재 입력에만 의존 → 임펄스 응답이 단순 스케일링:

$$h[n] = c\,\delta[n] \quad \Rightarrow \quad y[n] = c\,x[n]$$

$$h(t) = c\,\delta(t) \quad \Rightarrow \quad y(t) = c\,x(t)$$

> $h[n] = c\,\delta[n-1]$이면 $n=1$ (미래) 참조 → **메모리 있는 비인과 시스템**

### 3-2. 가역성 (Invertibility)

출력 → 원래 입력 복원 가능한 시스템.

역시스템 $h_{inv}$가 존재할 조건:

$$h[n] \ast h_{inv}[n] = \delta[n]$$

**예시 — 지연 시스템**:

$$h[n] = \delta[n - n_0] \quad \text{(}n_0\text{만큼 지연)}$$

역시스템:

$$h_{inv}[n] = \delta[n + n_0] \quad \text{(}n_0\text{만큼 전진, Advance)}$$

검증:

$$\delta[n-n_0] \ast \delta[n+n_0] = \delta[n] \quad \checkmark$$

**예시 — 누적합 시스템**:

$$h[n] = u[n] \quad \Rightarrow \quad y[n] = \sum_{k=-\infty}^{n} x[k]$$

역시스템 (차분):

$$h_{inv}[n] = \delta[n] - \delta[n-1] \quad \Rightarrow \quad x[n] = y[n] - y[n-1]$$

관계:

$$u[n] \ast (\delta[n] - \delta[n-1]) = \delta[n]$$

### 3-3. 인과성 (Causality)

LTI 시스템이 인과적 ↔ 임펄스 응답 조건:

$$h[n] = 0 \quad \text{for } n < 0$$

$$h(t) = 0 \quad \text{for } t < 0$$

**인과 LTI 시스템의 컨볼루션 단순화:**

이산시간:

$$y[n] = \sum_{k=0}^{\infty} h[k]\,x[n-k] = \sum_{k=-\infty}^{n} x[k]\,h[n-k]$$

연속시간:

$$y(t) = \int_0^{\infty} h(\tau)\,x(t-\tau)\,d\tau = \int_{-\infty}^{t} x(\tau)\,h(t-\tau)\,d\tau$$

**초기 정지 (Initial Rest):**

> 인과 **선형** 시스템에서: 입력이 특정 시간까지 0이면 출력도 그 시간까지 0

주의: 비선형 시스템에서는 성립하지 않음 (예: $y[n] = x[n] + 3$은 인과적이지만 초기 정지 불만족)

### 3-4. 안정성 (Stability) — BIBO

LTI 시스템이 안정적 ↔ 임펄스 응답의 절대 합/적분이 유한:

**이산시간:**

$$\sum_{k=-\infty}^{\infty} |h[k]| < \infty$$

**연속시간:**

$$\int_{-\infty}^{\infty} |h(\tau)|\, d\tau < \infty$$

## 4. 단위 계단 응답 (Unit Step Response)

### 4-1. 정의

단위 계단 함수 $u[n]$ (또는 $u(t)$)가 입력일 때의 출력:

$$s[n] = u[n] \ast h[n], \qquad s(t) = u(t) \ast h(t)$$

### 4-2. 임펄스 응답 ↔ 계단 응답 관계

**이산시간:**

$$s[n] = \sum_{k=-\infty}^{n} h[k]$$

$$h[n] = s[n] - s[n-1] \quad \text{(차분)}$$

**연속시간:**

$$s(t) = \int_{-\infty}^{t} h(\tau)\, d\tau$$

$$h(t) = \frac{d}{dt}s(t) \quad \text{(미분)}$$

| 연산 | 이산시간 | 연속시간 |
|------|---------|---------|
| $h \to s$ | 합산 ($\sum$) | 적분 ($\int$) |
| $s \to h$ | 차분 (뺄셈) | 미분 |

> **단위 임펄스 응답 = 단위 계단 응답의 1차 미분** (연속시간)

## 5. 블록 다이어그램

### 5-1. 기본 요소

| 기호 | 이산시간 의미 | 연속시간 의미 |
|------|------------|------------|
| $+$ | 신호 합산 | 신호 합산 |
| $\times a$ | $a$배 스케일링 | $a$배 스케일링 |
| $D$ | **1샘플 지연** $x[n] \to x[n-1]$ | **1차 미분** $x(t) \to \frac{d}{dt}x(t)$ |
| $\int$ | — | **적분기** |

> **⚠️ 핵심 차이**: $D$ 블록이  
> 이산시간 → 지연(Delay)  
> 연속시간 → 미분(Differentiator)

### 5-2. 이산시간 예제

다음 블록 다이어그램을 수식으로:

```
x[n] → (×b) ──────────────→ (+) → y[n]
                              ↑
y[n] → D → (×(-a)) ──────────┘
```

- 위 경로: $b\,x[n]$
- 아래 경로: $-a\,y[n-1]$ (출력이 피드백)

$$y[n] = b\,x[n] - a\,y[n-1]$$

이것은 **1차 차분 방정식** (1st order difference equation).

### 5-3. 연속시간 예제

```
x(t) → (×b) ──────────────→ (+) → dy/dt → y(t)
                              ↑
y(t) → (×(-a)) ──────────────┘
```

수식:

$$\frac{dy(t)}{dt} = b\,x(t) - a\,y(t)$$

$$\frac{dy(t)}{dt} + a\,y(t) = b\,x(t)$$

이것은 **1차 미분 방정식** (1st order ODE).

### 5-4. 적분기 형태 (구현 선호)

미분기 대신 **적분기** 사용이 실제 구현에 더 적합:

```
x(t) ─→ (+) ─→ ∫ ─→ y(t)
         ↑
     (×(-a)) ←─ y(t)
```

적분기 형태가 미분기 형태보다 수치적으로 안정적.

## 6. 2장 전체 정리

### LTI 시스템 핵심 요약

```
임펄스 입력 δ[n]
      ↓
   LTI 시스템
      ↓
임펄스 응답 h[n]  ← 시스템을 완전히 표현
```

임의 입력 $x[n]$에 대한 출력:

$$y[n] = x[n] \ast h[n] = \sum_{k=-\infty}^{\infty} x[k]\,h[n-k]$$

### 왜 LTI를 배우는가

1. **예측 가능**: 한 번 $h[n]$ 파악 → 어떤 입력에도 출력 예측
2. **컨볼루션 성립**: LTI 가정 → 컨볼루션으로 출력 계산
3. **주파수 분석 가능**: LTI → 푸리에 변환 적용 용이 (3~4장)
4. **디지털 시스템**: 실제 이산시간 시스템은 LTI 성립

### 다음 단계

```
2장: LTI 시스템, 컨볼루션
          ↓
3장: 푸리에 급수 (주기 신호의 주파수 분석)
          ↓
4장: 푸리에 변환 (비주기 신호의 주파수 분석)
```

## 7. 핵심 요약 & 시험 포인트

### ✅ 컨볼루션 세 가지 법칙

$$x \ast h = h \ast x \quad \text{(교환)}$$

$$x \ast (h_1 + h_2) = x \ast h_1 + x \ast h_2 \quad \text{(분배)}$$

$$(x \ast h_1) \ast h_2 = x \ast (h_1 \ast h_2) \quad \text{(결합)}$$

### ✅ 임펄스 응답 조건

| 성질 | 조건 |
|------|------|
| 메모리리스 | $h[n] = c\,\delta[n]$ |
| 인과 | $h[n] = 0$ for $n < 0$ |
| 안정 (BIBO) | $\sum |h[k]| < \infty$ |
| 가역 | $h[n] \ast h_{inv}[n] = \delta[n]$ |

### ✅ 계단 응답 관계

$$h[n] = s[n] - s[n-1] \qquad \text{(이산: 차분)}$$

$$h(t) = \frac{d}{dt}s(t) \qquad \text{(연속: 미분)}$$

### ✅ 블록 다이어그램 $D$ 블록

- 이산시간: **1샘플 지연** → $x[n-1]$
- 연속시간: **1차 미분** → $\frac{dx}{dt}$

### ✅ 자주 틀리는 포인트

- 컨볼루션 성질은 **LTI 시스템 가정**에서만 성립
- 직렬 연결 LTI: **순서 무관** (교환 법칙)
- 병렬 연결 LTI: 임펄스 응답의 **합** = 등가 단일 시스템
- 인과 + 비선형 → 초기 정지 불만족 가능
- $D$ 블록: 이산(지연) vs 연속(미분) 혼동 주의
