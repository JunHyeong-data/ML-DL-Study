## 0. 이 노트의 관점

44번 노트가 **"SR 네트워크를 어떻게 만드는가"** 에 집중했다면,  
이 노트는 **"현실에서 데이터가 불완전할 때 SR을 어떻게 학습하는가"** 에 집중한다.

- 이론 연구: (저화질, 고화질) 이미지가 **완벽한 쌍**으로 주어진다고 가정
- 현실(의료, 반도체 등): 쌍이 없거나, 한쪽만 있거나, 아예 없는 경우가 대부분
- ➡ **데이터셋 구성에 따라 5가지 시나리오**로 나누고, 각각의 대표 방법론을 정리

## 1. 저화질 이미지 vs 고화질 이미지

| 구분 | 저화질 (Low Resolution / Low Quality) | 고화질 (High Resolution / High Quality) |
|---|---|---|
| 픽셀 수 | **적음** → 원을 그려도 원 같지 않음(계단 모양) | **많음** → 형태를 정교하게 표현 |
| 픽셀 값 | 노이즈·블러로 부정확 | **정교함** → 이미지가 **선명** |

- 같은 대상(예: 원)을 표현하더라도 **픽셀 개수가 적으면** 저화질
- 단, **픽셀이 많다고 무조건 고화질은 아님**
  - 픽셀 수가 많으면서 **동시에** 픽셀 값이 정교해서 **선명해야** 고화질

➡ 즉 화질 = **해상도(픽셀 개수)** + **선명도(픽셀 값의 정확도, 노이즈 수준)**

## 2. 문제 상황: 의료 영상(Sodium MRI)의 저화질 문제

### 2.1 왜 저화질이 생기는가?

- 자문 대상은 **소듐(Sodium, ²³Na) MRI** 영상
- 체내 소듐은 일반 MRI가 보는 수소(¹H, 물 분자)에 비해 **양이 매우 적고** 자기공명 감도도 낮음
- ➡ 소듐에 대한 **MR 신호가 약함** → **SNR(Signal-to-Noise Ratio)이 낮음** → 노이즈 많은 저화질 영상

### 2.2 기존(하드웨어/촬영) 해결책과 한계

| 방법 | 내용 | 한계 |
|---|---|---|
| 자기장 세기 증가 | 더 강한 자기장의 장비 사용 → 신호 증가 | **천문학적인 비용** |
| 신호 평균 횟수 증가 (NEX/NSA ↑) | 같은 영상을 여러 번 촬영해 평균 → 노이즈 감소 | **촬영 시간이 배로 증가** → 현실적으로 적용 어려움 |

> 💡 **왜 촬영 시간이 크게 늘어나는가?**  
> 독립적인 노이즈를 $N$번 평균하면 노이즈 표준편차는 $\sigma / \sqrt{N}$ 으로 줄어든다.  
> 따라서 $\text{SNR} \propto \sqrt{N}$ → **SNR을 2배로 올리려면 4배의 촬영 시간**이 필요하다.

➡ 하드웨어가 아니라 **소프트웨어(AI)로 화질을 개선**하자는 것이 자문의 출발점

### 2.3 자문 요청 사항 → AI 관점으로 번역

| # | 자문 요청 (도메인 언어) | AI 관점의 의미 |
|---|---|---|
| 1 | 해상도를 **2배** 높일 것 | 이미지 크기 확대 = 이미지를 구성하는 **픽셀 개수 증가** |
| 2 | **SNR 개선** | 이미지의 **화질·선명도 개선** (노이즈 제거) |
| 3 | 전반적인 영상의 **신호 크기는 변화 없도록** | 이미지 안의 **콘텐트(형태, 구조, 강도 분포)는 유지** |

### 2.4 왜 Super Resolution인가?

**Super Resolution의 정의**: 전반적인 이미지 **형태는 그대로 유지**하면서, **해상도는 높이고**, **화질은 개선**하는 방법론

| 자문 요청 | Super Resolution 정의 |
|---|---|
| 해상도 2배 | 해상도를 높이고 |
| SNR 개선 | 화질을 개선하고 |
| 신호 크기 유지 | 이미지 형태는 유지 |

➡ 세 가지 요청과 **정확히 대응** → 가장 적합한 알고리즘은 **Super Resolution**

### 2.5 참고: SNR (Signal-to-Noise Ratio)

$$
\text{SNR} = \frac{\mu_{\text{signal}}}{\sigma_{\text{noise}}}
\qquad\text{또는 dB 단위로}\qquad
\text{SNR}_{\text{dB}} = 20\log_{10}\frac{\mu_{\text{signal}}}{\sigma_{\text{noise}}}
$$

- $\mu_{\text{signal}}$: 관심 영역(조직)의 평균 신호 세기
- $\sigma_{\text{noise}}$: 배경(신호가 없는 영역) 노이즈의 표준편차
- 클수록 신호 대비 노이즈가 적은 **깨끗한 영상**
- PSNR(44번 노트)은 **정답 이미지가 있을 때** 쓰는 지표, SNR은 **정답 없이 한 장의 영상만으로도** 계산 가능 → 정답(HR)이 없는 의료 영상 평가에 유용

## 3. AI 관점에서의 Super Resolution

### 3.1 데이터 구성

AI 모델은 데이터를 기반으로 학습되며, SR의 데이터는 $(x, y)$ 쌍으로 구성된다.

$$
x = \text{저화질 이미지}, \qquad y = \text{고화질 이미지}
$$

- 정의: **동일한 형태(콘텐트)** 를 가지지만, **서로 다른 픽셀 개수**와 **서로 다른 선명도**를 가지는 두 이미지

### 3.2 SR = 모르는 픽셀을 "예측"하는 문제

예: $160 \times 90$ 이미지를 2배 확대해 $320 \times 180$ 으로 만들기

$$
\underbrace{160 \times 90}_{14{,}400\text{개 (알고 있음)}}
\;\longrightarrow\;
\underbrace{320 \times 180}_{57{,}600\text{개}}
$$

- 원래 알고 있던 픽셀: 14,400개
- 새로 **예측해야 하는 픽셀**: $57{,}600 - 14{,}400 = 43{,}200$개 (전체의 **75%**)
- 단, 아무렇게나 예측하면 안 됨 → **이미지가 선명해지는 방향으로** 예측하도록 모델링하는 것이 SR의 목표

## 4. 이상(理想)과 현실의 차이

### 4.1 이론 연구의 가정

- $x$(저화질)와 $y$(고화질)가 **명확하게 대응되는 쌍**으로 주어진다고 가정
- 대부분의 SR 논문이 이 형태의 데이터셋(DIV2K 등)으로 연구

### 4.2 현실

- 사진을 찍을 때 **같은 대상을 서로 다른 화질로 두 장** 찍지 않음
- ➡ 완벽한 $(x, y)$ 쌍을 구하는 것은 **사실상 불가능**
- 현실의 데이터 구성은 문제 상황마다 매우 다름
  - 고화질만 있고 저화질은 없는 경우
  - 저화질만 있고 고화질은 없는 경우
  - 둘 다 있지만 서로 다른 대상을 찍은 경우 …

➡ 의료·반도체 같은 실제 도메인에 적용하려면 **불완전한 데이터셋으로 SR을 학습하는 방법론**이 필요

## 5. 데이터 구성에 따른 5가지 SR 시나리오

> 발표자가 개인적으로 정리한 분류 (공식 분류는 아님)  
> 기준: **저화질 이미지가 있는가? 고화질 이미지가 있는가? 서로 대응되는가?**

| Case | 저화질(LR) | 고화질(HR) | 대응(Paired) | 핵심 전략 | 연구 분야 키워드 | 대표 방법 | 기대 성능 |
|---|---|---|---|---|---|---|---|
| **1** | ✅ | ✅ | ✅ | 그대로 지도학습 | (Paired) Supervised SR | SRCNN, EDSR, RCAN, SAN | ⭐⭐⭐⭐⭐ |
| **2** | ✅ | ✅ | ❌ | LR의 노이즈를 HR에 입혀 **가짜 쌍** 생성 | Unpaired / Real-world SR | High-to-Low & Low-to-High GAN | ⭐⭐⭐⭐ |
| **3** | ❌ | ✅ | – | HR을 **다양하게 열화**시켜 LR 합성 | **Blind SR** | BSRGAN, Real-ESRGAN | ⭐⭐⭐ |
| **4** | ✅ | ❌ | – | 특정 태스크(사이클 일관성 등)로 **자기지도** | (용어 미정립) Self-supervised SR | Cycle 기반 SR | ⭐⭐ |
| **5** | ❌ | ❌ | – | 복원할 **이미지 한 장으로** 학습 | Zero-shot / Internal-learning SR | ZSSR | ⭐ ~ ⭐⭐ |

```
                       고화질(HR) 있음?
                     ┌───────┴────────┐
                    Yes               No
                     │                 │
            저화질(LR) 있음?      저화질(LR) 있음?
             ┌──────┴─────┐       ┌─────┴─────┐
            Yes           No     Yes          No
             │             │      │            │
         대응되는가?     Case 3  Case 4      Case 5
         ┌───┴───┐     (Blind) (LR only) (Zero-shot)
        Yes      No
         │        │
      Case 1   Case 2
     (Paired) (Unpaired)
```

➡ **정보가 줄어들수록(아래로 갈수록) 성능은 떨어진다.**  
➡ 그래서 "데이터를 어떻게든 Case 1에 가깝게 만드는 것"이 공통된 아이디어이다.

## 6. Case 1 — LR ✅ / HR ✅ / 대응 ✅ (Paired Supervised SR)

### 6.1 특징

- 동일한 콘텐트를 가진 저화질·고화질 이미지가 **쌍으로** 존재
- SR 이론 연구에서 **가장 활발하게** 연구되는 분야
- 저화질 이미지 내의 특성을 **가장 잘 학습**할 수 있음
- 데이터셋만 확보된다면 5가지 케이스 중 **가장 높은 성능** 보장

### 6.2 학습

$$
\min_\theta \; \mathbb{E}_{(x, y)} \big[\, \mathcal{L}(f_\theta(x),\, y) \,\big]
\qquad (\mathcal{L}: \text{L1, L2, Perceptual, Adversarial 등})
$$

- 네트워크 구조, Loss, 평가지표 등은 **44번 노트** 내용 그대로 적용

### 6.3 한계

- 현실에서는 이런 $(x, y)$ 쌍 구축이 **거의 불가능**
- 연구에서는 보통 HR을 Bicubic으로 줄여 LR을 "만드는데", 이렇게 만든 LR은 **실제 저화질(노이즈, 블러 등)과 다름**
  - ➡ Bicubic LR로 학습한 모델은 실제 영상에서 성능이 크게 떨어질 수 있음 (Domain Gap)
  - ➡ 이것이 Case 2, 3 연구가 등장한 배경

---

## 7. Case 2 — LR ✅ / HR ✅ / 대응 ❌ (Unpaired SR)

### 7.1 문제점

- 저화질과 고화질 이미지 모두 있음 (선명도 차이는 확실함)
- 하지만 두 이미지가 가리키는 **콘텐트가 대응되지 않음** (서로 다른 대상, 다른 환자, 다른 단면 등)
- 이 상태로 $x$ → $y$ 를 학습하면, 모델이 **화질 개선뿐 아니라 이미지 내용 변형까지** 학습해 버림
- ➡ 현실에 적용하기 어려움

### 7.2 핵심 아이디어

> **저화질 이미지의 "열화 특성(노이즈)"을 고화질 이미지에 옮겨, 대응되는 가짜 저화질 이미지를 만든다.**

1. 저화질 이미지 $x$ 에서 **노이즈(열화 패턴)를 어떻게든 추출**
2. 추출한 노이즈를 고화질 이미지 $y$ 에 **더해** 저화질 이미지 $x'$ 생성
3. $x'$ 와 $y$ 는 **콘텐트는 같고 화질만 다른** 쌍 → Case 1처럼 SR 학습

$$
(x,\ y) \text{: unpaired}
\;\xrightarrow{\ \text{노이즈 추출·주입}\ }\;
(x',\ y) \text{: paired}
$$

- 연구 분야: **Unpaired SR / Real-world SR** 등으로 불림
- 성능: 진짜 쌍이 아니므로 **Case 1보다는 다소 낮음**

### 7.3 대표 방법: High-to-Low & Low-to-High GAN

> A. Bulat, J. Yang, G. Tzimiropoulos, *To learn image super-resolution, use a GAN to learn how to do image degradation first*, ECCV 2018  
> (세미나에서는 편의상 "HLH-GAN"이라고 부름)

**두 개의 네트워크**로 구성: ① 저화질을 **만드는** 네트워크 → ② 그 데이터로 SR을 **학습하는** 네트워크

```
[High-to-Low Network]                               [Low-to-High Network]
 고화질 y (+ 랜덤 노이즈 z)                           x' (가짜 저화질)
        │                                                 │
   Generator G_HL ──▶ x' (가짜 저화질) ─────(x', y) 쌍───▶ Generator G_LH ──▶ ŷ (복원 고화질)
        │                                                 │
   Discriminator D_HL                               Discriminator D_LH
   "x'가 실제 저화질 x처럼 보이는가?"                  "ŷ가 실제 고화질처럼 보이는가?"
                                                     + 픽셀 손실 ‖ŷ − y‖
```

#### ① High-to-Low Network — 저화질 이미지 **만들기**

- 저화질 쌍이 없으므로 **고화질 → 저화질** 변환을 학습
- **GAN** 구조
  - **Generator**: 고화질 이미지(+ 노이즈 벡터)를 입력받아 저화질 이미지 생성
  - **Discriminator**: 생성된 저화질 이미지가 **실제 저화질 이미지(unpaired)** 와 구별되는지 판별
- 왜 Discriminator가 필요한가?
  - Generator만 쓰면 단순히 크기만 줄이거나 **단순한 형태의 노이즈**만 포함될 수 있음
  - Discriminator가 "실제 저화질처럼 보이는지"를 판별해 주므로 → **현실의 저화질 이미지와 비슷한 노이즈 패턴**을 학습
- 동시에 생성된 저화질 이미지가 원래 고화질 이미지의 콘텐트를 유지하도록 (축소한 고화질과의) 픽셀 손실도 함께 사용

#### ② Low-to-High Network — 슈퍼 레졸루션 **학습하기**

- ①에서 만든 $(x', y)$ 쌍으로 SR 학습 → 사실상 **Case 1과 동일**
- 역시 **GAN** 구조
  - **Generator**: 저화질 입력을 **같은 콘텐트의 고화질 이미지**로 변환
  - **Discriminator**: 복원 결과를 **더 고화질스럽게(사실적으로)** 만들기 위해 진짜 고화질과 판별
  - + 픽셀 단위 손실로 콘텐트 유지

## 8. Case 3 — LR ❌ / HR ✅ (Blind SR)

### 8.1 핵심 아이디어

- 고화질 이미지만 있으므로, 고화질 이미지를 **인위적으로 열화**시켜 저화질 이미지를 만든다.
- 그런데 우리가 실제로 복원하려는 저화질 이미지가 **어떤 열화를 겪었는지 모른다(blind)**.
- ➡ 현실에 존재할 법한 **다양한 저화질 이미지를 최대한 많이** 만들어 모두 학습
- 기대: "엄청 다양한 노이즈로 학습하면, **내가 가진 저화질 이미지의 노이즈도** 그 안에 포함되어 복원할 수 있지 않을까?"
- 성능: 실제 저화질 정보를 쓰지 못하므로 Case 2보다 **정보가 더 적고**, 성능도 **더 낮은** 경향

### 8.2 기존 방식 vs Blind SR

| 구분 | 기존 (Non-blind) | Blind SR |
|---|---|---|
| 열화 방식 | **한 가지** (예: Bicubic 축소 + 가우시안 노이즈) | **여러 가지**를 무작위 조합 |
| 생성되는 LR | HR 1장 → LR 1종류 | HR 1장 → **다양한 LR 여러 장** |
| 학습된 모델 | 가우시안 노이즈만 복원 가능 | 가우시안, 포아송 노이즈, 블러 등 **다양한 열화 복원** |

- 학습: 생성된 저화질 이미지 각각을 고화질 이미지와 **하나씩 대응**시켜 학습
  - (LR₁, HR), (LR₂, HR), (LR₃, HR), … → 모델이 다양한 노이즈를 제거하는 방법을 학습
- 데이터셋 구축 후 학습 방식은 **Case 1과 동일**

### 8.3 열화 모델 (Degradation Model)

전통적인 열화 모델은 다음 순서로 저화질 이미지를 만든다고 가정한다.

$$
x = \Big[ (y \otimes k)\downarrow_s + n \Big]_{\text{JPEG}}
$$

| 단계 | 기호 | 의미 | 예시 |
|---|---|---|---|
| ① Blur | $\otimes k$ | 블러 커널과의 합성곱 | 등방성/비등방성 가우시안 블러 |
| ② Downsampling | $\downarrow_s$ | $s$배 축소 | Nearest, Bilinear, Bicubic |
| ③ Noise | $+\,n$ | 노이즈 추가 | 가우시안 노이즈, 포아송 노이즈, 센서 노이즈 |
| ④ JPEG Compression | $[\cdot]_{\text{JPEG}}$ | 압축 손실 | 블록 아티팩트 |

### 8.4 대표 방법 ① BSRGAN

> K. Zhang, J. Liang, L. Van Gool, R. Timofte, *Designing a Practical Degradation Model for Deep Blind Image Super-Resolution*, ICCV 2021

- Blind SR 중 **가장 쉬우면서도 성능이 좋은** 알고리즘
- 문제 의식
  - 기존에는 Blur → Downsampling → Noise → JPEG **고정된 순서**로 열화
  - 이 순서대로만 학습하면, **이 순서대로 열화된 이미지만** 잘 복원하지 않을까?
- 해결: **Random Shuffle Degradation**
  1. Blur, Downsampling, Noise 각각에서 사용할 **기법을 무작위로 선택** (종류·강도)
  2. 선택된 연산들의 **순서를 무작위로 섞어서** 적용
  3. ➡ 같은 고화질 이미지로부터 **매우 다양한 형태의 저화질 이미지** 생성

```
Classical : HR ─▶ Blur ─▶ Down ─▶ Noise ─▶ JPEG ─▶ LR        (항상 같은 순서)
BSRGAN    : HR ─▶ Noise ─▶ Blur ─▶ Down ─▶ Blur ─▶ JPEG ─▶ LR₁
            HR ─▶ Down ─▶ Blur ─▶ Noise ─▶ JPEG ─▶ LR₂        (매번 다른 종류·강도·순서)
            ...
```

- 효과: 저화질 이미지의 **노이즈 공간(Degradation Space)이 확장** → 모델이 학습하는 노이즈 정보가 커짐
- ➡ 다양한 경우의 수를 학습했으므로 **우리 데이터의 노이즈도 잘 제거**하고 화질을 개선할 수 있을 것이라는 기대

### 8.5 대표 방법 ② Real-ESRGAN

> X. Wang, L. Xie, C. Dong, Y. Shan, *Real-ESRGAN: Training Real-World Blind Super-Resolution with Pure Synthetic Data*, ICCVW 2021

- 문제 의식: 열화 과정을 **한 번씩만** 적용해서 과연 **현실 세계의 복잡한 저화질 이미지**를 대변할 수 있을까?
  - 현실의 이미지는 촬영 → 압축 → 업로드 → 재압축 → 리사이즈 … 처럼 **여러 번 열화**됨
- 해결: **High-order Degradation** — 열화 과정(Blur → Down → Noise → JPEG)을 **두 번 반복** 적용

$$
x = \mathcal{D}^{(2)}\big(\mathcal{D}^{(1)}(y)\big)
\qquad (\text{각 } \mathcal{D}^{(i)} \text{는 Blur, Down, Noise, JPEG의 조합})
$$

- 실험적으로 BSRGAN보다 **더 좋은 성능**
- 현업에서 더 각광받아, 인용 수도 BSRGAN의 **약 2배** 수준

### 8.6 BSRGAN vs Real-ESRGAN

| 구분 | BSRGAN | Real-ESRGAN |
|---|---|---|
| 핵심 아이디어 | 열화 연산의 **순서·종류를 무작위로 섞기** | 열화 과정을 **두 번(고차) 적용** |
| 열화 다양성 확보 방식 | Random Shuffle | High-order (2nd-order) |
| 학습 방식 | 합성한 (LR, HR) 쌍으로 GAN 기반 SR 학습 | 동일 |
| 비고 | 간단하면서 강력한 Blind SR 베이스라인 | 현업에서 더 널리 사용 |

## 9. Case 4 — LR ✅ / HR ❌ (Self-supervised SR)

### 9.1 특징

- 저화질 이미지만 있고 고화질 이미지는 없음
- 고화질 정답이 없으므로 **어떤 방향으로 복원해야 하는지 알 수 없음**
- ➡ **특정 태스크(Pretext Task)를 정의**하여 스스로 지도 신호를 만들어 해결
- 아직 연구가 많이 진행되지 않았고, **키워드도 명확히 정립되지 않은** 분야
- 성능: 고화질 정보가 전혀 없으므로 **Case 1~3보다 많이 저조**

### 9.2 예시: Cycle(사이클) 일관성 기반 SR

**두 개의 네트워크**

- **Up** 네트워크 $U$: 해상도를 높이는 SR 네트워크 (우리가 원하는 것)
- **Down** 네트워크 $D$: 해상도를 낮추는 네트워크

**두 개의 경로**

1. **Up → Down**: $x \xrightarrow{U} \xrightarrow{D} \hat{x}_1$ (키웠다가 다시 줄임)
2. **Down → Up**: $x \xrightarrow{D} \xrightarrow{U} \hat{x}_2$ (줄였다가 다시 키움)

**학습 목표**: 두 결과가 모두 원래 입력과 같아지도록

$$
\mathcal{L}_{\text{cycle}} = \big\| D(U(x)) - x \big\| + \big\| U(D(x)) - x \big\|
$$

- 이렇게 학습된 $U$ 를 SR 네트워크로 사용

### 9.3 한계

- 아무것도 안 한 것보다는 낫지만, **다른 알고리즘(Case 1~3)에 비해 복원에 어려움**을 겪음
- 발표자의 해석: 지도 신호(정답 $y$)가 **실제 고화질 이미지가 아니라 저화질 이미지 자신**이기 때문
  - "원래로 돌아오는 것"만 강제할 뿐, "더 선명해지는 것"을 직접 강제하지 못함

## 10. Case 5 — LR ❌ / HR ❌ (Zero-shot SR)

### 10.1 특징

- 학습에 쓸 저화질·고화질 데이터가 **아예 없음** → 대규모 데이터 기반 학습 불가
- 가진 것: **복원하고자 하는 이미지 한 장**뿐
- ➡ **그 이미지 한 장으로 네트워크를 학습**하고, 학습된 네트워크에 **그 이미지를 다시 넣어** 복원
- 연구 분야: 세미나에서는 "Single Image SR"로 소개 (논문 용어로는 **Zero-shot SR**, **Internal Learning**)
  - 참고: 일반적으로 SISR(Single Image Super-Resolution)은 "입력이 이미지 한 장인 SR 전체"를 뜻하는 넓은 용어이므로 혼동 주의

### 10.2 장단점

- 장점: 외부 데이터 전혀 필요 없음, 이미지 고유의 패턴(자기 유사성)에 특화
- 단점
  - **이미지 한 장마다 학습** → **추론 시간이 매우 오래 걸림**
  - Case 4보다도 정보가 적어 성능이 **비슷하거나 더 낮은** 경향

### 10.3 대표 방법: ZSSR (Zero-Shot Super-Resolution)

> A. Shocher, N. Cohen, M. Irani, *"Zero-Shot" Super-Resolution using Deep Internal Learning*, CVPR 2018

**핵심 아이디어**: 이미지 내부에는 **같은 패턴이 여러 스케일로 반복**된다(자기 유사성, Self-similarity).  
➡ "작은 스케일 → 원래 스케일" 관계를 학습하면 "원래 스케일 → 더 큰 스케일"에도 적용할 수 있다.

**동작 과정**

```
[학습]  보유한 저화질 이미지 I  ──(s배 축소)──▶  I↓ (더 저화질)
        학습 쌍:  x = I↓ ,  y = I
        SR 네트워크 f 학습:  f(I↓) ≈ I         (+ 회전·뒤집기 등 증강으로 쌍을 늘림)

[추론]  학습된 f 에 원래 이미지 I 를 입력  ──▶  f(I) = 고화질 이미지 (s배 확대)
```

1. 원래 저화질 이미지 $I$ 를 **$y$(정답)로** 둔다.
2. $I$ 를 한 번 더 축소한 "더 저화질" 이미지 $I\!\downarrow_s$ 를 **$x$(입력)로** 둔다.
3. $(I\!\downarrow_s,\ I)$ 쌍으로 SR 네트워크를 학습한다.
4. 학습된 네트워크에 $I$ 를 넣어 고화질 이미지 $I\!\uparrow_s$ 를 얻는다.

$$
\min_\theta \;\big\| f_\theta(I\!\downarrow_s) - I \big\| \quad\Longrightarrow\quad \hat{I}_{HR} = f_{\theta^*}(I)
$$

## 11. 의료 영상 적용을 위한 추가 팁

### 11.1 2D 모델링 vs 3D 모델링

MRI·CT는 여러 장의 **단면(Slice)** 으로 구성된다. 예: 20장의 단면

| 구분 | 2D 모델링 | 3D 모델링 |
|---|---|---|
| 입력 단위 | 단면 1장 ($H \times W$) | 단면 20장 묶음 ($D \times H \times W$) |
| 추론 횟수 | **20번** (한 장씩) | **1번** (한꺼번에) |
| 단면 간 관계 | 반영 어려움 (각 장을 독립 처리) | 인접 단면 간 **교호작용(상호작용)** 까지 고려 |
| 연산 | `Conv2d` | `Conv3d` (메모리 사용량은 더 큼) |
| 추천 | | ✅ **3D 모델링 추천** |

- 2D로 한 장씩 처리하면 단면 사이의 연속성이 깨져 **slice 간 불연속(줄무늬)** 이 생길 수 있음
- 3D로 처리하면 볼륨 전체의 구조를 함께 학습 → 더 효과적

### 11.2 학습 데이터가 부족할 때: Vision Foundation Model 활용

- **Vision Foundation Model**: 수천만 장 이상의 대규모 이미지로 사전학습(Pre-training)된 모델 → 이미 우수한 복원/표현 능력 보유
- 주의: 대부분 **자연 이미지(강아지, 풍경 등)** 로 학습됨 → 의료 이미지와 **도메인이 달라** 잘 맞지 않을 가능성이 높음
- 추천 전략
  1. 가능하면 **의료 이미지에 특화되어 사전학습된 모델**을 찾아 사용
  2. 보유한 **소량의 데이터로 추가 학습(Fine-tuning)** → 우리 데이터에 맞게 성능 향상

```
대규모 (의료) 데이터로 사전학습된 모델 ──▶ 소량의 우리 데이터로 Fine-tuning ──▶ 최종 SR 모델
```

### 11.3 (정리) 자문 문제에 적용해 보기

> 아래는 세미나 결론을 바탕으로 한 정리이다.

- Sodium MRI는 **고화질 정답을 얻기 어려움** → 기본적으로 Case 4 또는 5에 해당 → 성능 기대치가 낮음
- 발표자의 제안: 고화질 이미지가 없는 경우 SR 성능을 크게 기대하기 어려우므로,  
  **고화질 이미지가 있는 비슷한 데이터**를 확보해 학습하는 것이 하나의 전략
  - 예) 비슷한 부위의 고화질 영상을 확보 → 보유한 저화질 영상과 함께 쓰면 **Case 2**,  
    고화질 영상만 열화시켜 쓰면 **Case 3** 으로 끌어올릴 수 있음
- "신호 크기 변화 없음" 요구사항 → 픽셀 손실(L1/L2)로 **강도 분포를 유지**하는 것이 중요 (GAN 손실만 쓰면 없는 구조를 만들어낼 위험)

## 12. 결론

1. **자문 요청**: 해상도 2배 이상 + SNR 개선 + 신호 크기 유지 → 가장 적절한 알고리즘은 **Super Resolution**
2. **Super Resolution**: 이미지 형태는 유지하되, 화질은 개선하면서 해상도를 높이는 방법론
3. **5가지 시나리오**: 저화질/고화질 이미지의 유무와 대응 여부에 따라 분류하고 대표 알고리즘 소개
   - Case 1 Paired → Case 2 Unpaired(High-to-Low GAN) → Case 3 Blind(BSRGAN, Real-ESRGAN) → Case 4 LR only(Cycle) → Case 5 Zero-shot(ZSSR)
4. **실무 제언**
   - 고화질 이미지가 없으면 SR 성능을 크게 기대하기 어려움 → **고화질 이미지가 있는 비슷한 데이터로 학습** 시도
   - 3D 데이터라면 2D보다 **3D 모델링** 추천
   - **사전학습 모델**, 특히 **의료 데이터에 특화된 모델**이 있다면 활용 + Fine-tuning

### 13.1 SNR 계산

```python
import numpy as np

def snr(img, signal_mask, noise_mask):
    """signal_mask: 조직 영역, noise_mask: 신호가 없는 배경 영역 (bool 배열)"""
    return img[signal_mask].mean() / img[noise_mask].std()

def snr_db(img, signal_mask, noise_mask):
    return 20 * np.log10(snr(img, signal_mask, noise_mask))
```

### 13.2 Case 3: BSRGAN 스타일 무작위 열화 (numpy 예시)

```python
import random
import numpy as np

def gaussian_kernel(size=7, sigma=1.5):
    ax = np.arange(size) - size // 2
    k = np.exp(-(ax ** 2) / (2 * sigma ** 2))
    return k / k.sum()

def blur(img, sigma):
    k = gaussian_kernel(sigma=sigma)
    pad = len(k) // 2
    x = np.pad(img, pad, mode="reflect")
    x = np.apply_along_axis(lambda r: np.convolve(r, k, mode="valid"), 1, x)  # 가로
    x = np.apply_along_axis(lambda c: np.convolve(c, k, mode="valid"), 0, x)  # 세로
    return x

def downsample(img, scale):
    h, w = img.shape[0] // scale * scale, img.shape[1] // scale * scale
    return img[:h, :w].reshape(h // scale, scale, w // scale, scale).mean(axis=(1, 3))

def add_gaussian_noise(img, sigma):
    return img + np.random.normal(0, sigma, img.shape)

def add_poisson_noise(img, peak=30.0):
    return np.random.poisson(np.clip(img, 0, 1) * peak) / peak

def random_degradation(hr, scale=2):
    """BSRGAN 스타일: 열화 연산의 종류·강도·순서를 무작위로 선택"""
    ops = [
        lambda x: blur(x, sigma=random.uniform(0.5, 3.0)),
        lambda x: add_gaussian_noise(x, sigma=random.uniform(0.01, 0.1)),
        lambda x: add_poisson_noise(x, peak=random.uniform(10, 100)),
    ]
    random.shuffle(ops)                    # 순서 섞기
    lr = hr.copy()
    for op in ops[:2]:
        lr = op(lr)
    lr = downsample(lr, scale)             # 최종 크기는 1/scale
    return np.clip(lr, 0, 1)

hr = np.random.rand(64, 64)                       # [0, 1] 범위의 고화질 이미지라고 가정
pairs = [(random_degradation(hr), hr) for _ in range(4)]  # HR 1장 → 다양한 (LR, HR) 쌍
```

- Real-ESRGAN 스타일(2차 열화)은 위 열화 과정을 **두 번** 적용하면 된다.

### 13.3 Case 4: Cycle 일관성 손실 (PyTorch 의사코드)

```python
import torch.nn.functional as F

def cycle_loss(up_net, down_net, x):
    x1 = down_net(up_net(x))   # Up → Down
    x2 = up_net(down_net(x))   # Down → Up
    return F.l1_loss(x1, x) + F.l1_loss(x2, x)
```

### 13.4 Case 5: ZSSR 학습 루프 (PyTorch 의사코드)

```python
import torch
import torch.nn.functional as F

def zssr(model, lr_img, scale=2, steps=3000, lr=1e-3):
    """lr_img: (1, C, H, W) — 복원하고 싶은 이미지 한 장"""
    opt = torch.optim.Adam(model.parameters(), lr=lr)
    for _ in range(steps):
        y = augment(lr_img)                                  # 회전/뒤집기/크롭 등
        x = F.interpolate(y, scale_factor=1 / scale,          # 한 번 더 축소 → "더 저화질"
                          mode="bicubic", align_corners=False)
        x = F.interpolate(x, size=y.shape[-2:],               # 원래 크기로 보간 후 입력
                          mode="bicubic", align_corners=False)
        loss = F.l1_loss(model(x), y)
        opt.zero_grad(); loss.backward(); opt.step()

    with torch.no_grad():                                     # 학습한 관계를 한 스케일 위로 적용
        up = F.interpolate(lr_img, scale_factor=scale, mode="bicubic", align_corners=False)
        return model(up)
```

## 14. 핵심 키워드 한눈에 보기

| 키워드 | 한 줄 설명 |
|---|---|
| 저화질 / 고화질 | 픽셀 수 + 픽셀 값의 정교함(선명도)으로 결정 |
| SNR | 신호 평균 / 노이즈 표준편차, 정답 없이도 계산 가능 |
| NEX(신호 평균 횟수) | SNR ∝ √NEX → SNR 2배에 촬영 시간 4배 |
| Paired SR (Case 1) | (LR, HR) 쌍으로 지도학습, 최고 성능, 현실에선 구축 어려움 |
| Unpaired SR (Case 2) | LR의 노이즈를 HR에 입혀 가짜 쌍 생성 |
| High-to-Low GAN | HR → 실제 같은 LR 생성 (Discriminator로 현실성 확보) |
| Low-to-High GAN | 생성된 쌍으로 SR 학습 |
| Blind SR (Case 3) | 열화를 모를 때, 다양한 열화로 LR 합성 |
| Degradation Model | Blur → Downsampling → Noise → JPEG |
| BSRGAN | 열화의 종류·순서를 무작위로 섞음 (Random Shuffle) |
| Real-ESRGAN | 열화 과정을 두 번 적용 (High-order Degradation) |
| Cycle 기반 SR (Case 4) | Up→Down, Down→Up 결과가 입력과 같도록 학습 |
| ZSSR (Case 5) | 이미지 한 장을 더 축소해 (I↓, I) 쌍으로 학습 후 I에 적용 |
| 3D 모델링 | 단면 간 상호작용 반영, 한 번에 추론 |
| Foundation Model + Fine-tuning | 대규모 사전학습 모델(가급적 의료 특화)을 소량 데이터로 추가 학습 |
