# 1️⃣ 기계학습이란 무엇인가? (본질적 관점)

## 📌 핵심 아이디어

기계학습은

> **Massive Data로부터 Knowledge / Insight를 발견하는 과정**

그리고 그 Knowledge는 보통 다음과 같이 표현된다:

* **Pattern (패턴 발견)**
* **Signal (신호 탐지)**
* **Structure (구조 발견)**
* **Reasoning (추론)**

최근(2025년 기준) 머신러닝은 단순 패턴 발견을 넘어서
→ **Uncertainty 하에서의 Reasoning**까지 확장되고 있음.

---

# 2️⃣ AI · Machine Learning · Deep Learning 관계

개념적으로는 다음과 같이 본다:

```
Artificial Intelligence (AI)
    ⬇
Machine Learning (ML)
    ⬇
Deep Learning (DL)
```

⚠️ 하지만 이 구분은 **절대적인 진리가 아니다.**
→ 개념적 분류일 뿐이며, 실제 기술은 유연하게 섞여 있다.

---

# 3️⃣ Machine Learning의 역사적 특징

머신러닝은 전통 학문(물리학, 화학 등)과 다르게

* 학계 → 산업 순서로 발전한 것이 아니라
* 산업에서 빠르게 확산되고 다시 학계로 환류됨

그래서:

* 체계적 이론 구조가 완전히 정립된 분야는 아님
* 데이터과학도 학교마다 정의가 다름

# 4️⃣ 🔥 기계학습의 본질적 정의 (시험 핵심)

## ① 🧠 Arthur Samuel (1959)

> "Machine Learning is the field of study that gives computers the ability to learn without being explicitly programmed."

### 핵심 문장

**명시적인 프로그램 없이 컴퓨터가 학습하도록 만드는 것**

### 기존 방식

```
Data + Program  → Output
```

사람이 if-else로 다 작성

### 머신러닝 방식

```
Data + Output → Program(=Model)을 스스로 만듦
```

즉,

* 사람이 프로그램을 직접 쓰는 게 아니라
* 컴퓨터가 데이터를 보고 **모형(Model)** 을 학습

---

## ② 🧠 Tom Mitchell (1998, CMU)

보다 실질적 정의 제시

> A computer program learns from experience E
> with respect to some task T
> and performance measure P
> if its performance at task T improves with experience E.

### 머신러닝의 3요소

| 요소 | 의미                          |
| -- | --------------------------- |
| T  | Task (무엇을 할 것인가?)           |
| E  | Experience (데이터)            |
| P  | Performance Measure (평가 지표) |

### 예: 이메일 스팸 분류

* T = 이메일 분류
* E = 과거 이메일 데이터
* P = Accuracy / F1-score 등

이 3요소가 있으면 → 기계학습 문제

---

# 5️⃣ 머신러닝 = 함수 추정 (매우 중요 ⭐)

현재 관점에서 머신러닝의 본질:

> **함수 f(x)를 추정하는 과정**

수식으로:

[
y = f(x)
]

* x = 입력 (데이터)
* y = 출력 (예측값)
* f = 우리가 추정해야 할 함수

---

## 딥러닝은 무엇인가?

딥러닝은

> 매우 복잡한 함수 공간에서 f(x)를 근사(approximation)하는 것

즉,

Neural Network = **Function Approximation**

있어 보이게 말하면:

> "Neural Networks are universal function approximators."

---

# 6️⃣ 지도학습 vs 비지도학습

### ① Supervised Learning

* y가 존재
* 함수 추정 문제
* 대부분 머신러닝은 이 범주

### ② Unsupervised Learning

* y가 없음
* 구조, 패턴, 잠재 표현 찾기

---

# 7️⃣ 머신러닝 응용 사례

# 8️⃣ 🔥 시험 대비용 정리 (서술형 답안 템플릿)

### Q. 머신러닝의 정의를 설명하시오.

**답안 구조 예시**

1. Arthur Samuel(1959)은 머신러닝을
   "명시적 프로그램 없이 컴퓨터가 학습할 수 있는 능력"이라고 정의하였다.
   이는 사람이 규칙을 직접 작성하는 대신 데이터와 정답을 통해 모델을 학습시키는 것을 의미한다.

2. Tom Mitchell(1998)은 머신러닝을
   경험 E로부터 특정 작업 T에 대해 성능 척도 P가 향상되는 컴퓨터 프로그램으로 정의하였다.
   즉, 머신러닝은 Task, Experience, Performance measure의 세 요소로 구성된다.

3. 현대적 관점에서 머신러닝은 입력 x에 대해 출력 y를 예측하는 함수 f(x)를 추정하는 과정으로 이해된다.
