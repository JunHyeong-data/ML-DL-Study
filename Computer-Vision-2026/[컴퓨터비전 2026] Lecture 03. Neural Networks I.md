# 뉴럴 네트워크 리뷰 (3주차 강의 노트)

## 1. 지난 시간 복습: 소프트맥스 분류기

- 입력 $x$를 선형으로 매핑하는 가중치(weight)를 학습 → **선형 분류기(Linear Classifier)**
- 출력값을 확률처럼 해석하기 위해 **시그모이드(sigmoid)**, **소프트맥스(softmax)** 사용
  - 스코어에 exponential을 씌우고 모든 클래스 합으로 나눔 → 합이 1, 항상 0~1 사이 값
- 학습 방법: **확률적 경사하강법(Stochastic Gradient Descent)** 으로 최적점을 찾아감

## 2. 선형 모델의 두 가지 한계

### 2.1 템플릿 문제

- 선형 모델의 가중치 $W$는 시각적으로 봤을 때 클래스별 **템플릿(template)** 을 배우는 것과 같음
- 한 클래스당 템플릿을 **한 장밖에** 학습하지 못함
  - 자동차처럼 형태가 비교적 일정한 클래스는 템플릿이 어느 정도 인식 가능한 형태로 나옴
  - 강아지, 새처럼 클래스 내 변동(intra-class variation)이 큰 경우 → 평균화되어 뭉개진 이미지가 나옴
- 클래스 내 다양한 변형들을 모두 평균 낸 모습만 학습 가능 → 좋은 feature 학습법인지 의문

### 2.2 선형 결정 경계(Linear Decision Boundary) 문제

- 선형 모델이므로 결정 경계(decision boundary)가 반드시 **직선(초평면)** 형태로만 나옴
- 클래스 간 분포가 비선형적으로 섞여 있으면 직선으로는 완벽히 구분 불가능
- 즉, 비선형 결정 경계가 필요한 모든 문제에서 선형 모델은 기본적으로 성능 페널티를 안고 시작함

## 3. 비선형성을 표현하는 초기 아이디어들

### 3.1 좌표계 변환 (극좌표 예시)

- 데카르트 좌표계($x, y$)에서는 분리 불가능한 데이터도 **극좌표계** $(r, \theta)$로 바꾸면 선형 분리 가능(linearly separable)해질 수 있음
  - $r$: 원점으로부터의 거리
  - $\theta$: 축으로부터의 각도
- 두 좌표계는 동일한 정보를 담고 있음(정보 손실 없이 변환 가능)하지만 표현 방식에 따라 선형 분리 가능성이 달라짐
- 한계: 실제 데이터는 매우 불규칙하게 섞여 있어 이런 예쁜 수학적 변환을 찾기 어려운 경우가 대부분

### 3.2 고차원으로의 매핑

- 저차원에서는 선형 분리가 어렵지만, **더 높은 차원으로 매핑**하면 선형 분리가 쉬워짐
- 극단적으로 데이터 포인트 개수만큼의 차원으로 보내면 반드시 선형 분리 가능
- 하지만 너무 고차원으로 보내면 각 데이터 포인트가 차원 하나씩을 차지하는 것과 다름없어 **일반화(대표성)** 가 떨어짐 → 성능 저하
- 이미지처럼 원래도 매우 고차원인 데이터에는 적합한 전략이 아님

## 4. 전통적인 피처 추출(Feature Engineering) 방식

이미지의 픽셀 단위 정보는 노이즈가 많고 변동이 크므로, **정해진(deterministic) 알고리즘**으로 차원을 줄여 핵심 정보만 추출하는 방식이 널리 쓰였음.

### 4.1 색상 히스토그램 (Color Histogram)

- 픽셀이 어느 위치에 있는지는 무시하고, 색상 분포만 카운팅
- 예: 개구리 이미지 → 초록색 계열이 많이 분포 → 비슷한 분포를 가진 이미지끼리 유사한 feature를 가짐
- 위치 정보는 잃고 전체적인 색 분포만 남음

### 4.2 방향 그래디언트 히스토그램류 (HOG 계열)

- 이미지를 작은 패치(patch)로 쪼갠 뒤, 각 패치에서 가장 지배적인(dominant) 그래디언트 방향(색이 변화하는 방향)을 계산
- 모양(shape) 정보를 담지만 색깔 정보는 잃음

### 4.3 파이프라인

$$
\text{이미지} \rightarrow \text{정해진 알고리즘(deterministic)} \rightarrow \text{피처 벡터 } Z \rightarrow \text{분류기(SVM, 로지스틱 회귀 등) 학습}
$$

- 피처 추출기는 고정되어 있고, **분류기 부분만 학습(training)** 하는 것이 1990년대 후반~2000년대 통계적 머신러닝의 주류 방식이었음

## 5. 엔드투엔드 학습(End-to-End Training)의 등장

### 5.1 핵심 아이디어

- 기존 방식의 문제의식: "피처 추출 방법 자체가 사람의 직관(intuition)으로 고정되어 있는데, 이것도 뒤에서 오는 loss를 받아서 함께 업데이트할 수 있지 않을까?"
- 피처 추출 함수 $F$도 분류기 $f$처럼 loss로부터 역전파(backpropagation)를 받아 학습 가능하게 만든 것 → **엔드투엔드 학습**
- 딥러닝이 이를 대규모로 처음 성공시킨 모델 → 세상을 바꿈

### 5.2 엔드투엔드 학습이 항상 최선은 아니다

- 장점: 사람의 직관을 배제하고 데이터의 힘으로 사람이 몰랐던 패턴까지 발견 가능
- 단점(비용):
  - 훨씬 많은 데이터 필요
  - 모델 크기 증가
  - 학습 시간·연산 비용 증가
- **이미 검증된 도메인 지식(domain knowledge)** 이 있다면, 그 지점부터 모델이 학습하도록 설계하는 것이 훨씬 효율적
  - 예: 생물학·물리학의 기존 법칙을 활용하면 라벨링해야 할 데이터량을 줄일 수 있음
- 결론: 머신러닝 파트 자체는 엔드투엔드 학습이 가능하도록 설계하되, 전체 문제를 풀 때는 도메인 지식 활용 여부를 항상 고려해야 함 (문제 해결 전문가로 가는 핵심 포인트)

## 6. 뉴럴 네트워크(Neural Network)

### 6.1 생물학적 모티브

- 인간의 뉴런(neuron) 구조를 모사 → 원래 명칭은 Artificial Neural Network, 이제는 그냥 Neural Network
- 생물학적 뉴런 동작:
  - **덴드라이트(dendrite)**: 다른 세포로부터 전기적 자극(신호)을 받는 가지
  - 자극이 특정 역치(threshold) 이상이면 다음 세포로 신호 전달(fire), 아니면 전달 안 됨

### 6.2 퍼셉트론(Perceptron) 수식

$$
y = f\left(\sum_i w_i x_i + b\right)
$$

- $x_0, x_1, x_2, \ldots$: 입력 벡터
- $w_0, w_1, w_2, \ldots$: 가중치(weight)
- $b$: 편향(bias) — 항상 존재해야 함
- $f$: **활성화 함수(activation function)**, 생물학적 역치 함수에 해당 — 입력이 무시할 만하면 무시하고, 전달할 만하면 지정된 출력을 내보냄
- 뉴런 하나(셀 하나)를 **퍼셉트론(perceptron)** 이라 부름

### 6.3 지난 시간 소프트맥스 분류기와의 관계

- 퍼셉트론은 $y = f(w^{\ast}x)$ 형태로, 입력 벡터 $x$와 가중치 벡터 $w$의 내적을 활성화 함수에 통과시킨 것
- 활성화 함수로 **시그모이드**를 쓰면 → 지난 시간의 소프트맥스 분류기와 수학적으로 동일
- 활성화 함수로 **항등 함수(identity function)** 를 쓰면 → 선형 회귀(linear regression)
- 즉, 지난 시간에 배운 내용은 뉴럴넷의 특수 사례(활성화 함수가 고정된 형태)였음

### 6.4 완전 연결 계층(Fully Connected Layer)

- 예: 입력이 3072차원, 출력(클래스)이 10개라면
  - 가중치 행렬 $W$의 크기 = (출력 개수) × (입력 크기) = $10 \times 3072$
- 모든 입력 뉴런과 모든 출력 뉴런이 화살표(가중치)로 전부 연결된 구조 → **완전 연결 계층(Fully Connected Layer)**
- 다음 시간부터는 완전 연결이 아닌 레이어들(합성곱 등)을 배울 예정

### 6.5 멀티레이어 퍼셉트론(Multi-Layer Perceptron)

- 여러 단계에 걸쳐 가중치를 곱해 나갈 수 있음:

$$
\text{입력} \xrightarrow{W_1} h \xrightarrow{W_2} \text{출력}
$$

- 예: $W_1$은 $100 \times 3072$, $W_2$는 $10 \times 100$ 크기

수식으로 쓰면:
- 1-레이어(linear): $\text{output} = Wx$
- 2-레이어: $h = W_1 x$, $\text{output} = W_2 h = W_2 W_1 x$

### 6.6 활성화 함수가 반드시 필요한 이유

- 행렬 곱셈은 결합 법칙이 성립하므로, 활성화 함수 없이 여러 층을 쌓아도

$$
W_2 W_1 x = W x \quad (\text{단, } W = W_2 W_1)
$$

즉 **결과적으로 1-레이어 선형 모델과 수학적으로 동일**해짐 → 여러 층을 쌓는 의미가 없음
- 각 레이어 사이에 **비선형 활성화 함수**를 넣어야만 층을 쌓는 것이 실질적 의미를 가짐
- 딥러닝(Deep Neural Network)에서 층수가 8층 → 19층 → 50층 → 100층으로 늘어나며 성능이 향상될 수 있었던 근본 이유가 바로 이 활성화 함수 덕분

## 7. 활성화 함수(Activation Function) 비교

### 7.1 시그모이드 (Sigmoid)

$$
\sigma(x) = \frac{1}{1 + e^{-x}}
$$

- 출력 범위: $(0, 1)$
- 미분:

$$
\sigma'(x) = \sigma(x)\bigl(1 - \sigma(x)\bigr)
$$

- 초창기 가장 많이 쓰인 이유: 분류(classification) 출력단에서 확률처럼 해석되는 0~1 값이 자연스럽게 필요했기 때문
- 2층 정도의 얕은 네트워크에서는 문제없었지만, 깊게 쌓을 때 아래 두 가지 심각한 문제 발생

**문제 1: 그래디언트 소실(Vanishing/Killed Gradient)**
- $x$의 절댓값이 커지면(예: $x = 10$ 또는 $x = -10$) $\sigma'(x) \approx 0$
- 역전파(backpropagation) 시 로컬 그래디언트(local gradient)를 계속 곱해서 앞으로 전달하는데, 중간에 한 번이라도 0에 가까운 값을 통과하면 그 이후 모든 앞쪽 노드의 그래디언트가 0이 되어버림
- 층이 깊을수록(예: 100층 중 75층에서 그래디언트가 죽으면) 그 앞쪽 파라미터는 전혀 업데이트되지 않음 → 학습 실패

**문제 2: 제로 센터드(Zero-Centered)가 아님**
- 시그모이드 출력은 항상 0~1 사이 → 항상 양수
- 입력 $x_i$가 모두 양수인 경우(실생활 데이터에서 흔함), 가중치에 대한 그래디언트의 부호가 모두 같은 방향으로만 나옴 (부호를 바꿀 수 없음)
- 결과적으로 업데이트 방향이 지그재그(zigzag) 형태로 비효율적으로 진행됨
- 단, 배치(batch) 단위로 평균을 내면 어느 정도 상쇄되므로 그래디언트 소실 문제보다는 덜 심각함

**부가적 문제**: exponential 연산이 상대적으로 느림 (하지만 이는 큰 문제는 아님)

### 7.2 하이퍼볼릭 탄젠트 (tanh)

- 출력 범위: $(-1, 1)$ — 시그모이드의 제로 센터드 문제를 해결하기 위해 고안
- 하지만 여전히 큰 입력값에서 기울기가 0에 수렴 → **그래디언트 소실 문제는 해결하지 못함**
- 수학적으로 시그모이드를 2배 스케일하고 1을 뺀 것과 동일한 형태

### 7.3 ReLU (Rectified Linear Unit)

$$
\text{ReLU}(x) = \max(0, x)
$$

**장점**
- 양의 영역에서 saturation(포화) 되지 않음 → 그래디언트가 0으로 죽지 않음 (양수 입력에서는 기울기가 항상 1)
- 계산이 매우 빠름 (양수면 기울기 1, 음수면 기울기 0 — 별도 미분 계산 불필요)

**단점**
1. **제로 센터드가 아님** — 다만 시그모이드만큼 치명적인 문제는 아님
2. $x = 0$ 지점에서 미분 불가 — 실무적으로는 큰 문제가 아니며, 서브그래디언트(subgradient)로 0, 1, 또는 그 사이 값을 임의로 정해 사용해도 잘 동작함
3. **Dead ReLU 문제**: 한 번 음수 영역으로 들어간 뉴런은 기울기가 계속 0이 되어 다시는 업데이트되지 않음(영구적으로 죽어버림)
   - 해결책: 초기화 시 편향(bias)을 살짝 양수 쪽으로 주어 처음에는 양수 영역에서 시작하게 함

- **가장 기본적으로 사용하는 활성화 함수**로 권장됨

### 7.4 Leaky ReLU

- 음수 영역에서 기울기를 0이 아닌 작은 값으로 설정 (완전히 죽지 않고 서서히 내려감)
- Dead ReLU 문제 해결, saturation 없음, 계산도 여전히 빠름
- 단점: 기울기 하이퍼파라미터를 직접 정해야 함 → 튜닝 필요 (오버헤드)

### 7.5 ELU (Exponential Linear Unit)

- 음수 영역이 무한히 커지지 않고 특정 값으로 수렴하도록 설계
- 양쪽 영역의 적분(넓이)이 비슷해지도록 $\alpha$ 값을 조정하면 근사적으로 제로 센터드 효과 달성
- ReLU 계열의 장점은 대부분 유지하면서 문제들을 해결하지만, exponential 연산으로 계산이 다소 느림

### 7.6 최신 활성화 함수 (GELU, SiLU, Swish 등)

- 트랜스포머(Transformer) 이후 널리 사용
- ReLU와 유사한 형태이지만 좀 더 부드럽게(smooth) 수렴하도록 설계됨
- 세부 구현마다 감소·증가 구간의 형태가 조금씩 다를 뿐 전체적인 컨셉은 유사

## 8. 정리 및 실무 가이드

| 활성화 함수 | 사용 권장 여부 |
|---|---|
| 시그모이드 (Sigmoid) | 중간 레이어에서 절대 사용 금지. **분류기 최종 출력단**에서만 사용 |
| tanh | 사용 금지 (그래디언트 소실 문제 여전) |
| ReLU | **기본(default) 선택** |
| Leaky ReLU / ELU / GELU 등 | ReLU로 어느 정도 성능을 낸 후, 추가 개선용으로 튜닝하며 시도 |

- 학습률 스케줄링(learning rate scheduling)도 함께 고려해야 함 (다음 시간 예정) — ReLU 계열은 saturation이 없기 때문에 특히 중요

## 참고: 용어 정리

- **Intra-class variation**: 동일 클래스 내에서의 형태·색상 등 변동
- **Decision boundary**: 클래스 간 결정 경계
- **Backpropagation (역전파)**: 출력단에서 발생한 loss를 체인 룰(chain rule)로 앞쪽 레이어까지 전달하며 파라미터를 업데이트하는 알고리즘
- **Local gradient**: 각 노드(연산)를 통과할 때 계산되는 국소 미분값
- **Saturation (포화)**: 입력값이 커질수록 활성화 함수의 출력이 특정 값에 수렴하여 기울기가 0에 가까워지는 현상
- **Dead ReLU**: ReLU 뉴런이 음수 영역에 갇혀 영구적으로 업데이트되지 않는 현상
